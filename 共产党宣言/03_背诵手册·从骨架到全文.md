# 03｜背诵手册·从骨架到全文

> **这份文档为实现你的第 3 个要求：把《宣言》有逻辑地捋下来（乃至背下来）。**
>
> 核心方法：**不要从头到尾顺着背。** 背文章的正确顺序是**从骨架到血肉**——先装钢筋，再填混凝土。
>
> ```
> L0  六字钥匙      ← 30 秒能念完，装的是全书的方向感
> L1  38 节点钩子链 ← 3 分钟念完，装的是全书的骨架
> L2  节点详卡      ← 每节点记"触发句 + 落点句"，这是真正的承重结构
> L3  整段必背区    ← 三处需要逐字原文的地方
> ```
>
> 配 `04` 的锚句表使用；自测请打开 `背诵台.html`。

---

# 引子：为什么说《宣言》特别适合背？

不是因为它短。是因为**它的写法本来就为"被记住"设计过**：

| 特征 | 对你背书的好处 |
|---|---|
| 每节开头有一个**总起句**，逻辑连接词密集（"由此可见""但是""于是""现在我们眼前"） | 触发句就能带出一整段 |
| 每节末尾有一个**可独立成句的金句** | 每节有一个明确的"停下来"的点（= 记忆钩子） |
| 大量**排比三连 / 十连** | 节奏本身就是记忆线索，漏一句会"感觉到"缺了 |
| 大量**反问** | 答案短，好记 |
| 大量**对称句**（过去支配现在 / 现在支配过去） | 记住一半，另一半自动出来 |
| 全文只有**一条主线**（生产力 vs 生产关系）在反复出现 | 迷路时能靠主线找回来 |
| 没有生僻术语、没有脚注 | 口头性强，可以念出声来背 |

> **一个关键建议：出声背。** 《宣言》是口头文本（见 `02` 第一部分第 3 节），默读背对它吃亏。

# L0｜六字钥匙（全书的方向感）

**先把这六个字和它们的顺序刻进去。它们是六个问题，四章加引言加结尾，全部对应：**

```
        凭  →  为  →  要  →  答  →  别  →  做
        │      │      │      │      │      │
       引言   第一章  第二章  第二章  第三章  第四章
                     前半    后半
     （为什么  （为什  （我们  （我们  （我们  （现在
      要出这   么必然  要什么） 怎么    不是    怎么
      份文件） 到来）          答辩）  谁）    做）
```

**连成一句话（第一行熟)：**

> **"凭为要答别做"** —— 或者更好记的说法：
> **"我们先证明必然，再宣布主张，然后堵回反对意见，接着划清界限，最后给出策略。"**

## 一句话流：把全书讲成一个故事（用于通背时的导航）

> 一个**幽灵**被全欧洲围剿 → 先从**历史**说起：一切历史都是**阶级斗争**史 → 于是追问**资产阶级**是怎么来的 → 承认它立下过**十桩大功** → 然后掏出**同一把尺**宣布它**装不下**自己的生产力了 → 它造出了**掘墓人** → 这个掘墓人说：**我们只要一件事——消灭私有制** → 于是挨个**回怼**六顶帽子 → 给出**十条措施**和一个**终点** → 回过头**清扫**所有冒牌社会主义 → 最后**排兵布阵**、喊出**口号**。

**练法**：这一长句先念熟，你会发现自己已经知道"下一站是哪儿"了——**背书最大的恐惧是不知道下一句是什么，而不是忘了这一句。**

# L2｜逐节点详卡（真正的承重结构）

**每节点只背两样东西：**
- **触发句**：原文开头，用来启动这一段
- **落点句**：该节的结论/金句，是这一段必须停住的地方

中间的部分你可以用自己的话讲出来再逐步替换成原文——**这是最快的路径**。

## 【引言】

> **触发句**：一个幽灵，共产主义的幽灵，在欧洲游荡。
> **中间**：一切旧势力联合起来 **→** 两个反问 **→** 两个结论
> **落点句**：**共产主义已经被欧洲的一切势力公认为一种势力。**

**必背的一问：** "有哪一个反对党不被它的当政的敌人骂为共产党呢？又有哪一个反对党不拿共产主义这个罪名去回敬更进步的反对党人和自己的反动敌人呢？"
→ **这两个反问是全引言的发动机，建议整句背。**

## 【1】资产者和无产者

### 1.1 阶级斗争是历史的常态
- **触发句**：**至今一切社会的历史都是阶级斗争的历史。**
- **中间四组对子**：自由民和奴隶、贵族和平民、领主和农奴、行会师傅和帮工
- **落点句**：**它使阶级对立简单化了。整个社会日益分裂为两大敌对的阵营，分裂为两大相互直接对立的阶级：资产阶级和无产阶级。**

> 🧠 **记法**：开头一句立"一切历史"，结尾一句立"两个阵营"。**从"多"到"二"，这就是 1.1。**

### 1.2 资产阶级的生成史
- **触发句**：从中世纪的农奴中产生了初期城市的市民（自由民）；
- **中间四个箭头**：地理大发现 → 工场手工业 → 蒸汽和机器 → 世界市场
- **落点句**：**现代资产阶级本身是一个长期发展过程的产物，是生产方式和交换方式的一系列变革的产物。**

### 1.3 资产阶级的政治进程
- **触发句**：资产阶级每一个阶段的这种发展，都伴随着在政治上取得相应的进展。
- **中间五个台阶**：被压迫阶级 → 公社 → 城市共和国/第三等级 → 君主国的抗衡势力 → 独占统治
- **落点句**：**现代的国家政权只不过是管理整个资产阶级的共同事务的一个委员会罢了。**

### 1.4 资产阶级的革命作用（十段排比）
- **触发句**：**资产阶级在历史上，也曾经起过非常革命的作用。**
- **中间的十个"它……了"**：破坏旧关系 / 抹去职业光环 / 撕下家庭面纱 / 证明人的力量 / 不断革命 / 世界市场 / 卷入文明 / 农村屈服于城市 / 政治集中 / 生产力总账
- **落点句**：**资产阶级在不到一百年的阶级统治中所创造的生产力，比过去一切世代所创造的全部生产力加起来还要大，还要多。**

> 🧠 **记法（十 → 四组）**：`拆掉旧的`（3段）`证明人能`（1段）`停不下来`（1段）`连成一片`（5段）。**记住"3-1-1-5"就记住了这一节。**

### 1.5 模板①：封建制怎么死的
- **触发句**：由此可见，资产阶级赖以形成的生产资料和交换手段，**是在封建社会里造成的**。
- **中间四步**：旧社会里产生新生产力 → 旧关系不再适应 → 变成桎梏 → 被打破
- **落点句**：取而代之的是自由竞争以及与自由竞争相适应的社会制度和政治制度、资产阶级的经济统治和政治统治。

### 1.6 模板②：套回你自己
- **触发句**：**现在，在我们眼前又进行着类似的运动。**
- **中间**：魔法师与魔鬼 → 危机周期性 → 生产过剩的瘟疫 → 为什么？文明过度 → 你怎么办？消灭生产力+夺取市场 → 那只是下一次危机
- **落点句**：**资产阶级的关系已经太狭窄了，再容纳不了它本身所创造的财富。**

> 🧠 **记法**：这一节的全部推导是**围绕一个荒谬现象**——东西太多所以穷。抓住"生产过剩的瘟疫"五个字，全节能顺出来。

### 1.7 两个转折句（**全书转轴，必须逐字背**）
> **资产阶级用来推翻封建制度的武器，现在却对准资产阶级自己。**
>
> **但是，资产阶级不仅锻造了置自身于死地的武器；同时它还造就了将要运用这种武器来反对它的人——现代的工人，即无产者。**

### 1.8 无产阶级的处境
- **触发句**：随着资产阶级即资本愈发展，无产阶级即现代工人阶级也在同一程度上愈得到发展；
- **中间六层层层加深**：商品化 → 去技能化 → 军事化 → 同质化 → 二次剥夺 → 中间等级补充进来
- **落点句**：**无产阶级的队伍就是这样从居民的所有阶级中得到补充。**

### 1.9 斗争的五阶段
- **触发句**：无产阶级经历了各个不同的发展阶段。它反对资产阶级的斗争是和它的存在同时开始。
- **中间五阶**：捣毁机器 → 同敌人的敌人作斗争 → 同盟 → 汇合为全国斗争 → 组织成为政党
- **落点句**：**他们斗争的真正成果并不是直接取得实际利益，而是工人的越来越大的团结。**

> 🧠 **记法**：五阶段 = `打机器 → 帮别人打 → 抱团 → 连成一片 → 建党`。**记住这个 5 字链条。**

### 1.10 发展的三个来源
- **触发句**：**旧社会内部的所有冲突在许多方面都促进了无产阶级的发展。**
- **中间三条**：资产阶级求援时传授武器 / 统治阶级成员被抛下来 / 决战期思想家转过来
- **落点句**：**正像过去贵族中有一部分人转到资产阶级方面一样，现在资产阶级中也有一部分人，转到无产阶级方面来。**

### 1.11 阶级鉴定
- **触发句**：**在当前同资产阶级对立的一切阶级中，只有无产阶级是真正革命的阶级。**
- **中间三个判定**：中间等级 = 保守甚至反动（要使历史车轮倒转）；流氓无产阶级 = 更甘心被收买
- **落点句**：关于中间等级的那句补充判定，背这句即可：
  > **说他们是革命的，那是指他们行将转入到无产阶级的队伍里来。**

### 1.12 为什么要摧毁一切
- **触发句**：在无产阶级的生活条件中，旧社会的生活条件已经被消灭。
- **中间三组对比**：挥别旧一切 vs 必须废除占有方式 / 少数人的运动 vs 绝大多数人的运动 / 必须摧毁上层建筑
- **落点句**：**无产阶级的运动是绝大多数人为绝大多数人的独立自主谋利益的运动。**

### 1.13 为什么它统治不下去了
- **触发句**：我们已经看到，至今的一切社会都是**建立在压迫阶级和被压迫阶级的对立之上**。
- **中间的大门坎**：要压迫一个阶级，**至少**要让它能维持奴隶般的生存 → 过去还能上升 → 现在工人**只能向下**
- **落点句**：**资产阶级再无法统治下去……社会再不能在它们统治下继续运转下去，就是说，它的存在不再同社会相容。**

### 1.14 结论：掘墓人（**第一章的答案，必背**）
- **触发句**：资产阶级赖以生存和统治的根本条件，是财富在私人手里的积累，是资本的形成和增殖；
- **中间的前提链**：资本 ← 雇佣劳动 ← **工人之间的竞争** ← **被结社取代了**
- **落点句**：
  > **随着大工业的发展，资产阶级赖以生产和占有产品的基础本身也就从它的脚下被挖掉了。它首先生产的是它自身的掘墓人。**
  > **资产阶级的灭亡和无产阶级的胜利是同样不可避免的。**

> 🧠 **第一章收束口令**：`由此（1.2）→ 口诀（1.3）→ 功劳（1.4）→ 裂开（1.6）→ 掘墓人（1.14）`

## 【2】无产者和共产党人

### 2.1 党的定位
- **触发句**：共产党人同全体无产者的关系是怎样的呢？
- **中间三条否定启动**：不是特殊政党 / 没有不同利益 / 不提特殊原则 → 然后两方面的不同 + 实践/理论两方面
- **落点句**：**这些原理不过是现在正在进行的阶级斗争和我们眼前的历史运动的真实关系的一般表述。**

### 2.2 消灭私有制（**全书的核心五字，必背**）
- **触发句**：这些原理不过是现在正在进行的阶级斗争和我们眼前的历史运动的真实关系的一般表述。**（可直接从 2.1 的落点句接过来！）**
- **中间三层铺垫**：所有制本就在更替 → 法国革命的例子 → 不是废除一般的所有制
- **落点句**：**共产党人可以把自己的理论概括为一句话：消灭私有制。**

> 🧠 **串联技巧**：2.2 的触发句就是 2.1 的落点句。**在两节之间搭桥，能消灭一半的卡顿。**

### 2.3—2.5 第一组反驳：财产（拆成三小段）
- **2.3 触发句**：有人责备我们共产党人，说我们要消灭个人挣得的、自己劳动得来的财产……
  > 落点：**这种劳动所创造的是资本，即剥削雇佣劳动所得到的财产。**
- **2.4 触发句**：做一个资本家，这就是说，他在生产中不仅占有一种纯粹个人的地位……
  > 落点：**这时所改变的只是财产的社会性质。它将失掉它的阶级性质。**
- **2.5 触发句**：现在，我们来看看**雇佣劳动**。
  > 落点（**两条对称，务必成对背**）：
  > **在资产阶级社会里，活的劳动只是增殖已经积累起来的劳动的一种手段。在共产主义社会里，已经积累起来的劳动只是扩大、丰富和提高工人的生活的一种手段。**
  > **在资产阶级社会里是过去支配现在，在共产主义社会里是现在支配过去。**

### 2.6 反驳②：个性与自由
- **触发句**：我们要消灭私有制，你们就惊慌起来。
- **中间的四刀**：自由=自由贸易 → 买卖消失自由就消失 → 这自由只对中世纪才有意义 → 十分之九的人早就没有了
- **落点句**：**共产主义并不剥夺任何人占有社会产品的权力，它只剥夺利用这种占有去奴役他人劳动的权力。**

### 2.7 反驳③：懒惰（最短，建议整小节背）
- **触发句**：有人反驳说，私有制一消灭，一切活动就会停止，懒惰之风就会兴起。
- **落点句**：这样说来，资产阶级社会早就应该因懒惰而灭亡，**因为在这个社会里是劳者不获，获者不劳。**
  （原文：**"因为在这个社会里是劳者不获，获者不劳。"**）

### 2.8 反驳④：教育（**核心句所在地**）
- **触发句**：所有这些对共产主义的物质产品的占有方式和生产方式的责备，也被扩及到精神产品的占有和生产方面。
- **中间的过渡短钉**：**资产者唯恐失去的那种教育，对绝大多数人来说是把人训练成机器。**
- **落点句（历史唯物主义的经典表述，逐字背）**：
  > **你们的观念本身是资产阶级的生产关系和所有制关系的产物，正像你们的法不过是被奉为法律的你们这个阶级的意志一样，而这种意志的内容是由你们这个阶级的物质生活条件来决定的。**

### 2.9 反驳⑤：家庭
- **触发句**：消灭家庭！连极端的激进派也对共产党人的这种"可耻"的意图表示愤慨。
- **中间的反问**：现代的、资产阶级的家庭是建立在什么基础上的呢？→ **资本、私人发财** → 无产者的独居和卖淫是它的补充
- **落点句**：**共产党人并没有发明社会对教育的影响；他们仅仅是要改变这种影响的性质，要使教育摆脱统治阶级的影响。**
  （其中最好用的钉子句是：**"你们是责备我们要消灭父母对子女的剥削吗？我们承认这种罪状。"**）

### 2.10 反驳⑥：公妻制
- **触发句**：但是，你们共产党人是要实行公妻制的啊，——整个资产阶级异口同声地向我们这样叫喊。
- **中间心理拆解**：你们把自己的妻子看作**生产工具** → 所以你们才会这么想 → 而"公妻制无需共产党人来实行，它差不多是一向就有"
- **落点句**：**资产阶级的婚姻实际上是公妻制。**

### 2.11 反驳⑦：祖国与民族
- **触发句**：还有人责备共产党人，说他们要取消祖国，取消民族。
- **落点句（两条对称，成对背）**：
  > **人对人的剥削一消灭，民族对民族的剥削就会随之消灭。**
  > **民族内部的阶级对立一消失，民族之间的敌对关系就会随之消失。**

### 2.12 反驳⑧：意识形态总清算
- **触发句**：从宗教的、哲学的和一般意识形态的观点对共产主义提出的种种责难，都不值得详细讨论。
- **中间**：意识随社会存在改变 → 统治思想是统治阶级的思想 → 三个历史佐证 → 对方说有永恒真理 → 答：因为剥削一直在
- **落点句**：**共产主义革命就是同传统的所有制关系实行最彻底的决裂；毫不奇怪，它在自己的发展进程中要同传统的观念实行最彻底的决裂。**

> 🧠 **八组反驳的串记口诀**：
> **"财 / 自 / 懒 / 教 / 家 / 妻 / 国 / 意"** —— 八字，从物质到精神。
> 念熟这八个字，第二章的一半结构就站住了。

### 2.13 行动纲领
- **触发句**：前面我们已经看到，工人革命的第一步就是使无产阶级上升为统治阶级，争得民主。
- **中间**：夺取全部资本 → 集中在国家手里 → 尽快增加生产力总量 → 必须实行强制性干涉（且措施会超出本身）→ 各国不同
- **十条措施（分组记）**：
  ```
  剥夺类  ①②③④  地产 / 累进税 / 继承权 / 流亡分子财产
  集中类  ⑤⑥⑦    信贷 / 运输 / 工厂与土地
  改造类  ⑧⑨⑩    劳动义务制 / 工农结合 / 公共教育
  ```
  🧠 **口诀：先断财路，再集中命脉，最后改造人。**
- **落点句**（先用这句收）：**这些措施在不同的国家里当然会不同。**

### 2.14 终点：自由人联合体（**全书最后的理论句，必背**）
- **触发句**：当阶级差别在发展进程中已经消失而全部生产集中在联合起来的个人的手里的时候……
- **中间的国家消亡逻辑**：政治权力是一个阶级压迫另一个阶级的有组织暴力 → 消灭生产关系的同时也消灭了阶级的存在条件 → 从而消灭了它自己这个阶级的统治
- **落点句（一字不能差）**：
  > **代替那存在着阶级和阶级对立的资产阶级旧社会的，将是这样一个联合体，在那里，每个人的自由发展是一切人的自由发展的条件。**

## 【3】社会主义和共产主义的文献

> 🧠 **全章只用先记一个框架：三类 = 倒退 / 停住 / 跳过。**
> **每一类的名字就是它的判决书。**

### 3.1 反动的社会主义（向后）
| 小类 | 触发句思路 | 落点/钉子句 |
|---|---|---|
| （甲）封建的 | 法英贵族被打败了只剩文字斗争 | **半是挽歌，半是谤文；半是过去的回音，半是未来的恫吓**<br>**他们的臀部带有旧的封建纹章** |
| （乙）小资产阶级的 | 西斯蒙第；透彻分析矛盾但结论错误 | **企图恢复旧的生产资料……它在这两种场合都是反动的，同时又是空想**<br>**工业中的行会制度，农业中的宗法经济，——这就是它的最后结论** |
| （丙）德国的"真正的" | 法国文献搬到德国但生活条件没搬过来 | **不代表无产者的利益，而代表人的本质的利益**<br>**是这些政府用来镇压德国工人起义的毒辣的皮鞭和枪弹的甜蜜的补充** |

### 3.2 保守的或资产阶级的社会主义（停住）
- **触发句**：资产阶级中的一部分人想要消除社会的弊病，以便保障资产阶级社会的生存。
- **中间的招牌平行句（必背）**：
  > **他们愿意要现代社会的生存条件，但是不要由这些条件必然产生的斗争和危险。他们愿意要现存的社会，但是不要那些使这个社会革命化和瓦解的因素。他们愿意要资产阶级，但是不要无产阶级。**
- **落点句**：**资产阶级的社会主义就是这样一个论断：资产者之为资产者，是为了工人阶级的利益。**

### 3.3 批判的空想的社会主义和共产主义（跳过）
- **触发句**：本来意义的社会主义和共产主义的体系，圣西门、傅立叶、欧文等人的体系，在无产阶级和资产阶级之间的斗争还不发展的最初时期出现。
- **中间三条（看见 / 看不见 / 于是）**：看到了对立，看不到无产阶级的历史主动性，于是去发明社会计划；因此拒绝革命；但也有批判成分值得肯定
- **落点句（三条判语，连背）**：
  > **批判的空想的社会主义和共产主义的意义，是同历史的发展成反比。**
  > **虽然这些体系的创始人在许多方面是革命的，但是他们的信徒总是组成一些反动的宗派。**
