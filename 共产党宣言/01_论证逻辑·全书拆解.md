# 【引言】先把"被围剿"变成"被承认"

## 这一步干什么

不是开场立论，而是**先解决发言资格**。1847 年的共产主义者同盟是秘密团体，外界对"共产主义"只有谣言。所以在开口讲道理之前，必须先回答一个问题：**你们凭什么讲话？**

## 论证结构

```
【事实】  一个幽灵，共产主义的幽灵，在欧洲游荡
          旧欧洲的一切势力联合起来围剿它
              ↓  （引出一个普遍事实）
【反诘】  有哪一个反对党不被当政的敌人骂为共产党呢？
          又有哪一个反对党不拿共产主义这个罪名去回敬更进步的反对党人和自己的反动敌人呢？
              ↓  （两个反问暴露了"共产主义"这个词已被滥用——它被当棍子使）
【结论①】 共产主义已经被欧洲的一切势力公认为一种势力
【结论②】 现在是公开说明观点、拿出宣言来批驳关于共产主义幽灵的神话的时候了
【行动】  各国共产党人集会于伦敦 → 拟定宣言 → 用六种文字公布于世
```

## 逻辑要害

**这一段是一次漂亮的反转（inversion）。**

通常的写法是："我们很弱小，但我们有真理。" 马克思不这么写。他从**敌人的动作**说起：

> 你们兴师动众地围剿一个"幽灵"——**这本身就证明它不是幽灵。**

如果共产主义真是不值得理会的玩意儿，教皇、沙皇、梅特涅、基佐、法国激进派、德国警察，会联合起来对付它吗？**围剿的规模 = 对手实际力量的度量。** 于是"被敌人攻击"这个最不利于自己的事实，被翻转成了最有力的论据。

这是《宣言》全文第一次、也是最著名的一次**反向利用对手**。记住这个动作，后面第二章会大量重复它。

## 论据盘点

| 论据 | 原文 | 用途 |
|---|---|---|
| 神圣的围剿阵营 | 教皇和沙皇、梅特涅和基佐、法国的激进派和德国的警察 | 用敌人的"全家出动"证明我们已是势力 |
| 敌对阵营内部互不搭界 | 教皇↔法国激进派、沙皇↔基佐本是对头 | 说明这一次是"全欧洲联合"，反证分量 |

**注意**：这一串名字是刻意选的——**首尾两端分别是宗教领袖和政治警察，中间包含自由派**。它们平时毫无共同点，唯一的公约数就是反对共产主义。这个"最大公约数"越大，论据越强。

## 抓手句（原文）

> 一个幽灵，共产主义的幽灵，在欧洲游荡。

> 有哪一个反对党不被它的当政的敌人骂为共产党呢？

> 共产主义已经被欧洲的一切势力公认为一种势力。

## 为什么放在这里

因为**它给全文定了调、也给全文定了敌我**。引言决定了读者读完的预期：这份文件不是恳求承认，而是回应挑战。有了这个开头，第一章那种斩钉截铁的语气（"现代的国家政权只不过是管理整个资产阶级的共同事务的一个委员会罢了"）才不显得突兀。

# 【1】资产者和无产者

**整章任务**：证明"两个不可避免"。
**整章写法**：先给历史，再给机制，最后给结论。**全部建立在"资产阶级确实伟大"这个己方承认的前提上。**

---

## 1.1 总前提：至今一切社会的历史都是阶级斗争的历史

### 这一步干什么
立**全书的公理**。在讲资本主义之前，先讲一切社会都如此。

### 论证结构
```
【总命题】至今一切社会的历史都是阶级斗争的历史
【列举】  自由民和奴隶、贵族和平民、领主和农奴、行会师傅和帮工
【抽象】  一句话：压迫者和被压迫者，始终处于相互对立的地位，进行不断的、有时隐蔽有时公开的斗争
【结局】  每一次斗争的结局——或是整个社会受到革命改造，或是斗争的各阶级同归于尽
【补充】  过去各时代都能看到社会被划分为不同阶级、多种多样的等级
          （古罗马：贵族、骑士、平民、奴隶；中世纪：封建主、臣仆、行会师傅、帮工、农奴）
【转折】  资产阶级社会并没有消灭阶级对立。它只是用新的阶级、新的压迫条件、新的斗争形式代替了旧的
【落点】  资产阶级时代的特点：它使阶级对立简单化了 → 分裂为两大阵营：资产阶级和无产阶级
```

### 三个关键动作
1. **用四组对子砸下来**（奴隶→封建→封建→工场手工业），节奏短促，不给读者反驳空隙。
2. **先说"没有变化"再说"发生了变化"**：资产阶级社会并没有消灭阶级对立（这否定了"现代文明超越了野蛮"的自我感觉）→ 但它确实变了一样东西：**简单化了**。
3. `但是` 是这一节的路标：**前面所有铺垫都是为了"简单化"这三个字。** 因为只有简化为两大阵营，才有后面"一个挖掉另一个"的对称结构。

### 抓手句
> 至今一切社会的历史都是阶级斗争的历史。

> 压迫者和被压迫者，始终处于相互对立的地位，进行不断的、有时隐蔽有时公开的斗争。

> 从封建社会的灭亡中产生出来的现代资产阶级社会并没有消灭阶级对立。它只不过是用新的阶级、新的压迫条件、新的斗争形式代替了旧的。

> 资产阶级时代……使阶级对立简单化了。整个社会日益分裂为两大敌对的阵营，分裂为两大相互直接对立的阶级：资产阶级和无产阶级。

### 为什么放在这里
这是**公理**。没有它，1.14 的"必然灭亡"就没有着落——如果社会不是被内部矛盾推动的，灭亡就只能是偶然事件，或者只能靠道德审判来说明。所以马克思必须先让读者接受"历史是被内在矛盾推动的"这件事，并把这句话摆在全篇正文的第一句。

## 1.2 资产阶级的生成史：它不是从天上掉下来的

### 这一步干什么
把资产阶级**历史化**。它看起来是永恒的、自然的秩序，马克思要证明它是一个**特定历史阶段的产物**。

### 论证结构（一条四拍的因果链）
```
① 中世纪的农奴 → 初期城市的市民（自由民）→ 最初的资产阶级分子
② 地理大发现（美洲、绕过非洲的航线）→ 新天地
   东印度和中国的市场、美洲的殖民化、对殖民地的贸易、交换手段和商品的增加
   → 商业、航海业、工业空前高涨 → 封建社会内部的革命因素迅速发展
③ 需求增长 → 封建的/行会的经营方式不能满足
   → 工场手工业代替行会经营；行会师傅被工业的中间等级排挤
④ 市场还在扩大 → 工场手工业也不够了
   → 蒸汽和机器引起工业革命 → 现代大工业代替工场手工业
   → 工业中的百万富翁（产业大军的首领、现代资产者）代替工业的中间等级
⑤ 反馈环：世界市场 → 交通发展 → 工业扩展 → 资产阶级同程度发展 → 资本增加
   → 把中世纪遗留下来的一切阶级都尽情地排挤掉
【结论】现代资产阶级本身是一个长期发展过程的产物，是生产方式和交换方式的一系列变革的产物。
```

### 逻辑要点
**这条链子的每一个箭头都指向同一方向：市场扩大 → 逼出新的生产方式 → 逼出新的阶级。** 这是马克思要让读者记住的唯一机制：**需求推着生产工具变，生产工具变出新阶级。**

这条链子还有一个关键特征：**资产阶级既是这一连串变革的结果，又是它的推动者**——它先是被推出来的，一旦出场就开始主动推别人。正因为它本身是"产物"，它就不可能是永恒的。
**这条链子的每一个箭头都是"扩大的市场 → 逼出新的生产方式"。** 这是马克思要读者记住的唯一机制：**需求推着生产工具变，生产工具变出新阶级。**


### 为什么必须"从源头讲一遍"
因为这是**釜底抽薪**。要证明资产阶级会灭亡，最省事的办法是控诉它残暴——但那不够。马克思选了更狠的一条：**先证明你是被某个东西生产出来的，再证明那个东西现在转向反对你了。** 一个东西既然有起因，就必然有终结。**把某个东西的来历讲清楚，就等于同时宣判了它的有限性。**

### 抓手句
> 美洲和绕过非洲的航海线路的发现，给新兴的资产阶级开辟了新天地。

> 蒸汽和机器引起了工业生产的革命。现代大工业化代替了工场手工业。

> 由此可见，现代资产阶级本身是一个长期发展过程的产物，是生产方式和交换方式的一系列变革的产物。

### 为什么放在这里
必须先讲"资产阶级怎么来的"，1.3 才能讲"它怎么一步步夺权"，1.4 才能讲"它上台后干了什么"。**生成 → 夺权 → 执政**，这三节是不可颠倒的三部曲。

## 1.3 资产阶级的政治进程：国家不过是它的管理委员会

### 这一步干什么
接上 1.2 的经济史，补上政治史——**经济地位变了，政治地位跟着变，一步不落**。

### 论证结构（五个台阶）
```
封建主统治下       ：被压迫的阶级
公社里             ：武装的和自治的团体
某些地方           ：独立的城市共和国（如德国和意大利）
另一些地方         ：君主国中的纳税的第三等级（如法国）
工场手工业时期     ：等级制君主国或专制君主国用以同贵族抗衡的势力，而且是各大君主国的主要基础
大工业和世界市场   ：在现代的代议制国家里夺得了独占的政治统治权力
【结论】现代的国家政权只不过是管理整个资产阶级的共同事务的一个委员会罢了。
```

### 逻辑要害
这一节的全部意义在那句结论里：**国家被降格了。**

通常人们认为国家是中立的、代表"全体国民"的。马克思用五个台阶的上升史证明：国家权力的每一次扩张，都恰好对应资产阶级经济力量的每一次扩张。**相关性被呈现为同一性。** 于是"现代国家"= 资产阶级的办公室。

**战略后果**：这一句一旦站住，后面 2.13 的"无产阶级必须夺取政权、把生产工具集中到自己手里"就顺理成章——既然国家只是个委员会，那么换了这个委员会的主人，国家就换了性质。这在《宣言》里是自洽的。

### 为什么放在这里
放在 1.2 之后、1.4 之前，位置极讲究：
- **承接 1.2**：经济基础 → 上层建筑，顺序不可倒（倒过来就成唯心史观了）；
- **导出 1.4**：既然已经夺了独占的统治权，那么它掌权后到底干了什么？——下一节回答。

### 抓手句
> 最后，从大工业和世界市场建立的时候起，它在现代的代议制国家里夺得了独占的政治统治权力。

> 现代的国家政权只不过是管理整个资产阶级的共同事务的一个委员会罢了。

## 1.4 资产阶级的革命作用：全书最慷慨的一段赞美

> **这一节是理解《宣言》的第一道关。** 很多读者在这里困惑：马克思怎么突然唱起了赞歌？答案是：**这段赞美不是让步，是整个论证的地基。**

### 这一步干什么
承认资产阶级在历史上的**全部正当性**，同时把这份正当性的**唯一来源**锁定为"它解放了生产力"。

### 论证结构（十个"它……了"段落，可分四组）

**第一组：它拆掉了旧关系赋予了什么（1—3 段）**
1. 破坏了封建的、宗法的、田园诗般的关系 → 只剩赤裸裸的利害关系和冷酷无情的"现金交易" → 把人的尊严变成交换价值
   > 它用赤裸裸的、公开的、无耻的、直接的、露骨的和残忍的剥削代替了由宗教和政治带着欺骗的假面具掩盖着的剥削
2. 抹去了职业的神圣光环 → 医生、律师、教士、诗人和科学家变成出钱雇佣的仆役
3. 撕下了家庭关系的温情面纱 → 变成纯粹的金钱关系

**第二组：它证明了人能干什么（4 段）**
4. 揭示了中世纪崇尚人力的野蛮勇武 = 极端怠惰因循的补充；**首次证明了人的活动能够取得什么样的成就**；创造了不同于埃及金字塔、罗马水道、哥特式教堂的奇迹；完成了不同于民族大迁徙和十字军东征的远征

**第三组：它使生产永不停歇（5 段）**
5. 必须对生产工具、生产关系、全部社会关系不断革命才能生存；过去一切工业阶级的首要条件恰恰是原封不动保持旧生产方式
   > 生产的不断变革，一切社会状况不停的动荡，永远的不安定和变动，这就是资产阶级时代不同于过去一切时代的地方

**第四组：它把世界连成一片（6—9 段）**
6. 奔走全球 → 生产和消费成为世界性的 → 挖掉了工业脚下的民族基础 → 世界文学
7. 交通便利 + 商品价格低廉（重炮）→ 迫使一切民族采用资产阶级生产方式 → **它按照自己的形象为自己创造出一个世界**
8. 农村屈服于城市 → 创立巨大城市 → 使东方从属于西方
9. 消灭分散状态 → 人口密集、生产资料集中、财产聚集 → **政治的集中** → 统一政府/法律/民族阶级利益/关税

**第五组：生产力的总报账（10 段）**
10. > 资产阶级在不到一百年的阶级统治中所创造的生产力，比过去一切世代所创造的全部生产力加起来还要大，还要多。
    自然力的征服、机器、化学、轮船、铁路、电报、大陆的开垦、河川的通航……

### 逻辑要害：这段赞美是一枚"定时炸弹"

表面上是颂词，实际上每一句都在**设定一个尺度**。马克思在这里干的事是：

> **把评判标准从"善恶"换成"解放生产力的能力"。**

而这是**对自己最有利的尺**：
- 用"生产力"的尺量封建制 → 封建制输了（这是已经发生的事实，没人能否认）
- 用**同一把尺**量资本主义 → 下一节（1.6）就要宣布：资本主义在生产力的尺上，现在也开始不及格了

**所以 1.4 是给 1.6 递刀。** 没有 1.4 的"资产阶级在生产力的尺上一度拿了满分"，1.6 的"现在它在这个尺上要不及格了"就毫无杀伤力。**作者先给了对手一块金牌，然后告诉对手：你的金标准是同样的一个，而你现在已经开始掉分了。**

这是全书最重要的一次**自我否定结构**：不是外部敌人打倒了它，是它自己的标准处决了它。

### 抓手句
> 资产阶级在历史上，也曾经起过非常革命的作用。

> 它迫使一切民族——如果它们不想灭亡的话——采用资产阶级的生产方式……一句话，它按照自己的形象为自己创造出一个世界。

> 资产阶级在不到一百年的阶级统治中所创造的生产力，比过去一切世代所创造的全部生产力加起来还要大，还要多。

### 为什么放在这里
夹在"政治进程"和"第一次由此"之间，是**从褒到贬的转轴**。没有它，全文会变成单纯的控诉书；《宣言》之所以"科学"而非"道义"，靠的就是这一节。

## 1.5 第一次"由此可见"：封建制是怎么死的（模板首次出现）

### 这一步干什么
**推出全书的核心机制模板——"生产力 vs 生产关系"。**

### 论证结构（四步，务必背熟这个模板）
```
① 资产阶级赖以形成的生产资料和交换手段，是在封建社会里造成的
        （关键：新生产力诞生在旧社会的子宫里）
② 到一定阶段，封建的所有制关系就不再同已经发展的生产力相适应
③ 它不再是促进生产，而是阻碍生产 → 变成了束缚生产的桎梏
④ 它必须被打破，而且已经被打破
【结论】取代它的是自由竞争以及与自由竞争相适应的社会制度和政治制度、资产阶级的经济统治和政治统治
```

### 逻辑要害
这个四步模板，马克思要读两遍用两次：
- **第一遍（本节点）**：用在封建制身上，得到——封建制死了
- **第二遍（1.6）**：把这个模板原样套到资产阶级身上，得到——资产阶级也要死

**结构完全对称。** 这就是《宣言》最核心的推理机关：**同一个规律，先在别人身上演示一次（让你默认它成立），再回到你自己身上（你无法否认）。**

请特别注意第一步——"新的生产力是在旧社会里长出来的"。这句话是后面"掘墓人"命题的根：资产阶级不仅在亡期内产生了自己的敌人，甚至这个敌人的产生恰恰是在资产阶级**最成功的时刻**。

### 抓手句
> 资产阶级赖以形成的生产资料和交换手段，是在封建社会里造成的。

> 封建的所有制关系……已经……不能再同已经发展的生产力相适应……它变成了束缚生产的桎梏。它必须被打破，而且已经被打破。

---

## 1.6 资产阶级自身的危机：魔法师唤出了自己支配不了的魔鬼

### 这一步干什么
把 1.5 的模板**套回资产阶级自己身上**。这是第一圈的高潮。

### 论证结构
```
【过渡句】  现在，在我们眼前又进行着类似的运动
【类比】    这个曾经仿佛用魔术创造了如此庞大生产资料和交换手段的现代资产阶级社会，
            现在像一个魔法师一样不能再支配自己用法术呼唤出来的魔鬼了
【因果】    几十年来的工业和商业的历史，只不过是现代生产力反抗现代生产关系、
            反抗作为资产阶级及其统治的存在条件的所有制关系的历史
【实证】    证据：周期性重复且越来越凶猛、越来越危及整个资产阶级社会生存的商业危机
            危机现象：大量产品被毁灭 + 大量生产力被毁灭
            荒谬之处：生产过剩的瘟疫——社会突然转瞬回到一时的野蛮状态
                      仿佛一次饥荒、一场普遍的毁灭性战争夺去了全部生活资料
【归谬反诘】这是什么缘故呢？因为社会上"文明"过度，生活资料"太多"，工业和商业太发达
【结论】    生产力已经强大到这种生产关系所不能适应的地步，已经受到这种生产关系的阻碍；
            生产力一着手突破这种障碍，就使整个资产阶级社会陷入混乱
            → 资产阶级的关系已经太狭窄了，再容纳不了它本身所创造的财富
【反问解决】资产阶级用什么办法克服危机？一方面消灭大量生产力，另一方面夺取新市场、更彻底利用旧市场
【判定】    这不过是资产阶级准备更全面更猛烈的下一次危机的办法，
            不过是使防止危机的手段越来越少的办法
```

### 逻辑要害

**（1）"类似的运动"四个字是全文的效率之最。** 只需这四个字，1.5 的整个模板被整块调用：当年封建制被自己的新生产力撑破，现在你资产阶级也被自己的新生产力撑破。**读者在心理上已经接受过一次这个推理了，第二次无 сил 抵抗。**

**（2）"生产过剩"是马克思选的致命武器。** 为什么？因为它无法被反驳：
- 你不能说它是因为生产得不够（恰恰是太多）
- 你不能说它是技术问题（技术空前发达）
- 你不能说它是偶然的（它周期性复发，且越来越猛）
- 最狠的一击：**富裕导致匮乏**——这在常识上是荒谬的，但事实摆在眼前。**一个体系如果在它最成功的时刻崩溃，那它的问题就不是失败，而是它的成功本身。**

**（3）最后那个追问是无解的陷阱。** "你用什么办法克服危机？" 答：消灭生产力 + 夺取新市场。马克思立刻指出：这恰恰是下一次危机的准备。**这是一个无法逃出的循环——每次自救都是下一次病发的准备。** 所以危机不是意外，是慢性病，且无法治愈。

### 抓手句
> 现在，在我们眼前又进行着类似的运动。

> 现在像一个魔法师一样不能再支配自己用法术呼唤出来的魔鬼了。

> 几十年来的工业和商业的历史，只不过是现代生产力反抗现代生产关系……的历史。

> 在危机期间，发生一种在过去一切时代看来都是非常荒唐的社会瘟疫，即生产过剩的瘟疫。

> 资产阶级的关系已经太狭窄了，再容纳不了它本身所创造的财富。

> 这不过是资产阶级准备更全面更猛烈的下一次危机的办法，不过是使防止危机的手段越来越少的办法。

### 为什么放在这里
它是第一章的**顶点**。往下就开始讲"谁来埋它"。而且它必须在 1.4（赞美）之后——**先让资产阶级站到荣誉的最高点，再在这一刻推它。** 位置的戏剧性是刻意设计的。

## 1.7 两个转折句：全书最重要的两句话

就在同一处，马克思连着甩出两句——它们是**从"资产阶级的悲剧"转向"无产阶级的出场"的铰链**：

> **资产阶级用来推翻封建制度的武器，现在却对准资产阶级自己。**

> **资产阶级不仅锻造了置自身于死地的武器；同时它还造就了将要运用这种武器来反对它的人——现代的工人，即无产者。**

### 为什么这两句必须强背
它们完成了两件事，缺一不可：
1. **第一句**确立"自我否定"（它死于自己的武器，不是死于外敌）
2. **第二句**确立"掘墓人"（执行者也是它自己生产的）

合起来就是 1.14 那句结论的全部内容。**把这两句背下来，1.14 就自动浮出来了。**

### 为什么放在这里
它处在**第一章的黄金分割点**（约 0.5 处）。前面全是资产阶级，后面全是无产阶级。**这两个短段落是全书的转轴。** 它之后，叙事视角正式从"它们"转为"他们"。

## 1.8 无产阶级的处境：被"回召回降"

### 这一步干什么
用同样的严格方式，把无产阶级**生产出来**——不是描述苦难，而是描述**地位**。

### 论证结构（六层）
```
① 同步性：随着资产阶级即资本愈发展，无产阶级即现代工人阶级也在同一程度上愈得到发展
② 商品化：现代的工人只有当他们找到工作的时候才能生存，并且只有当他们的劳动给资本带来
           增殖的时候才能找到工作 → 不得不把自己零星出卖 → 像其他任何货物一样也是一种商品
           → 避免不了受到竞争的一切变化、市场的一切波动的影响
③ 去技能化：机器的推广和分工 → 劳动失去了任何独立的性质和吸引力 → 工人变成机器的单纯附属品
            → 花在工人身上的费用只限于维持工人生活和延续工人后代所必需的生活资料
            → 劳动的价格同它的生产费用相等 → 劳动越令人厌恶，工资也就越减少
            且机器越推广、分工越细致，劳动量也就越增加
④ 军事化：大工厂里工人像士兵一样被组织起来 → 受各级"军士"和"军官"的层层监视
⑤ 同质化：男工越受女工和童工排挤；性别和年龄的差别再没有什么社会意义 → 都只是劳动工具
⑥ 二次剥夺：厂主剥削告一段落 → 房东、小店主、当铺老板向他们扑来
⑦ 补充来源：以前的中间等级的下层——小工业家、小商人、小食利者、手工业者和农民——都降落到
            无产阶级队伍里来 → 无产阶级的队伍从居民的所有阶级中得到补充
```

### 逻辑要害
这一节**没有一个形容词诉苦**。全部是结构性描述：
- 关键词是**商品**：工人不是"可怜的人"，是**一种会受市场波动影响的商品**
- 关键词是**附属品**：工人不是"被压榨的人"，是**失去了独立性质的机器零件**
- 关键词是**降落到**：中间等级不是"变穷了"，是**整个阶层被抛下来**

**为什么要这么写？** 因为如果写成"工人很苦"，读者可以回答"那我们改善一下"。写成"工人在结构上是商品"，读者就没法回答了——你不能对一个统计学事实施舍同情。**《宣言》从头到尾都避免道德论证，这是它区别于空想社会主义的根本。**

注意最后的"补充"：`无产` 的队伍在扩大，而且**从原来属于"中间"的阶层里扩大**——这为社会矛盾加剧提供了经验证据（后面 1.11 会回收）。

### 抓手句
> 资产阶级即资本愈发展，无产阶级即现代工人阶级也在同一程度上愈得到发展。

> 现代的工人只有当他们找到工作的时候才能生存，并且只有当他们的劳动给资本带来增殖的时候才能找到工作。

> 工人变成了机器的单纯的附属品。

> 无产阶级的队伍就是这样从居民的所有阶级中得到补充。

## 1.9 无产阶级斗争的五个递进阶段

### 这一步干什么
证明无产阶级**不是一堆受难者，而是一个正在成形的主体**。五个阶段是"组织化"的进程。

### 论证结构（五阶段递进表）

| 阶段 | 斗争主体 | 斗争对象 | 斗争手段 | 成果/局限 |
|---|---|---|---|---|
| ① 自发反抗 | 单个工人 → 某工厂 → 某地方某部门 | 单个资产者 | **攻击生产工具本身**：毁坏外国商品、捣毁机器、烧毁工厂 | **想回到中世纪**；被竞争分裂，无法联合 |
| ② 被利用 | 集结的工人群众（但"还不是他们自己联合的结果，而是资产阶级联合的结果"） | 敌人的敌人（专制君主制残余、地主、非工业资产阶级、小资产者） | 政治运动 | 每一个胜利**都是资产阶级的胜利** |
| ③ 真正起步 | 更大群体（人数增加、结合更紧、感觉到自己的力量） | 资产阶级整体 | 同盟（工会）、经常性团体、起义 | 工资趋同、利益趋同；冲突具有两个阶级冲突的性质 |
| ④ 质变关键 | 各地方工人彼此联系 | 全国范围 | 利用铁路等大工业创造的交通工具 | **斗争的真正成果并不是直接取得实际利益，而是工人的越来越大的团结** → 汇合成**阶级斗争**，而**一切阶级斗争都是政治斗争** |
| ⑤ 组织化 | 组织成为阶级 → 组织成为政党 | 资产阶级 | 利用资产阶级内部的分裂，迫使其用法律形式承认个别利益 | 反复因工人自相竞争而破坏，但**一次又一次更强大、更坚固、更有力**（例：英国十小时工作日法案） |

### 逻辑要害

**阶段④是全书最值钱的一句之一：**
> **他们斗争的真正成果并不是直接取得实际利益，而是工人的越来越大的团结。**

这句话把"失败"重新定义为"成功"——工人们常常是失败的（ §113 "工人有时也得到胜利，但这种胜利只是暂时的"），但如果每次失败都留下了更广的组织，那么**每一次战术失败都是战略胜利**。这是极其有力的修辞：**把失败也解释为进步的证据。**

**顺便一句：** "中世纪的市民由于交通不便，靠乡间小道需要几百年才能达到的联合，现代的无产者利用铁路的便捷，只要几年就可以达到"——这句是历史对比的妙用：**同一个"联合"任务，条件不同，速度差百倍。** 它暗示革命时间表在缩短。

### 抓手句
> 工人并不是同自己的敌人作斗争，而是同自己的敌人的敌人作斗争……因此，在这种条件下取得的每一个胜利都是资产阶级的胜利。

> 斗争的真正成果并不是直接取得实际利益，而是工人的越来越大的团结。

> 只要有了这种联系，就能把许多性质相同的地方性的斗争汇合成全国性的斗争，汇合成阶级斗争。而一切阶级斗争本质都是政治斗争。

> 中世纪的市民由于交通不便，靠乡间小道需要几百年才能达到的联合，现代的无产者利用铁路的便捷，只要几年就可以达到。

### 为什么放在这里
接 1.8（无产阶级的客观处境），补上它的**主观发展**。没有这一节，无产阶级就只是一个被压迫的客体，不能成为历史的行动者；没有它，也无法解释后面 2.1 为什么会突然冒出一个"共产党"。

## 1.10 促成无产阶级发展的三个来源

### 这一步干什么
解释一个尖锐的质疑：**无产阶级既然被剥夺得一干二净，它凭什么长得大、斗得赢？** 马克思给三条来源，而且**每一条都来自资产阶级本身**。

### 论证结构
```
来源① 资产阶级处于不断的斗争中：
       最初反对贵族 → 后来反对同工业进步有利害冲突的那部分资产阶级 → 经常反对一切外国的资产阶级
       ↓ 它们都不得不向无产阶级呼吁、要求无产阶级援助
       ↓ 把无产阶级卷进了政治运动
       ↓ "于是，资产阶级就把自己的一部分经验知识传授给无产阶级，也就是把反对资产阶级的武器给予了无产阶级"
来源② 工业的进步把统治阶级的一批批成员抛到无产阶级队伍里去，或者至少使他们的生活条件受到威胁
       ↓ 他们也给无产阶级带来了大量的经验知识
来源③ 阶级斗争接近决战的时期，统治阶级内部的、整个旧社会内部的瓦解过程达到非常强烈、非常尖锐的程度
       ↓ 统治阶级中的一小部分人脱离统治阶级而归附于革命的阶级，即掌握着未来的阶级
       ↓ "正像过去贵族中有一部分人转到资产阶级方面一样，现在资产阶级中也有一部分人，转到无产阶级方面来"
       ↓ 这就是水平已经提高到从理论上认识整个历史运动进程的一部分资产阶级思想家
```

### 逻辑要害
**来源③极其重要，也极其容易被漏掉——它是马克思对"知识分子为什么会革命"的回答，也是对他自己的回答。**

马克思恩格斯本人正是"转到无产阶级方面来的资产阶级思想家"。所以这段话既是理论，也是自我定位。它说明：《宣言》的写作本身就遵循它宣示的规律——**理论是资产阶级在其瓦解过程中输送给无产阶级的武器。**

**三条的共同句式是同一个：** 资产阶级在为自己争取胜利时，无意地把自己的本领教给了敌人。**这是 1.7"锻造武器/造就持武器的人"的展开版。**

### 抓手句
> 旧社会内部的所有冲突在许多方面都促进了无产阶级的发展。

> 资产阶级就把自己的一部分经验知识传授给无产阶级，也就是把反对资产阶级的武器给予了无产阶级。

> 正像过去贵族中有一部分人转到资产阶级方面一样，现在资产阶级中也有一部分人，转到无产阶级方面来。

### 为什么放在这里
它紧接 1.9 五个阶段，补上另外三条"外在助力"。**没有它，无产阶级的成长只有内部解释；有了它，连资产阶级自己也成了无产阶级的教官。** 逻辑上彻底闭合——现在敌对阵营的每一个动作都在壮大我们。

## 1.11 阶级鉴定：谁才是真正革命的阶级

### 这一步干什么
**排除法。** 在当时，"无产阶级"和"穷人"是混为一谈的。马克思必须先把圈子圈干净。

### 论证结构（三类判定）

| 对象 | 判定 | 判据 |
|---|---|---|
| **无产阶级** | **真正革命的阶级** | 其余的阶级都随着大工业的发展而日趋没落和灭亡，无产阶级却是大工业本身的产物 |
| **中间等级**（小工业家、小商人、手工业者、农民） | 不是革命，是**保守**；甚至是**反动** | 他们斗争是为了维护其继续存在，以免于灭亡；力图使历史的车轮倒转<br>（附带条件：若他们行将转入无产阶级，那是革命的——因为他们维护的已是将来的利益） |
| **流氓无产阶级**（旧社会最下层中消极的腐化的部分） | 会被卷进来，但**更甘心于被人收买，去干反动的勾当** | 由其整个生活状况决定 |

### 逻辑要害

**这里的判据只有一个：这个阶级是否站在大工业发展的方向上。**

- 无产阶级 = 大工业本身的产物 → 与方向一致 → 革命
- 中间等级 = 要保住正在被大工业摧毁的小生产方式 → 与方向相反 → 反动
- 流氓无产阶级 = 无阶级地位可以依托 → 可被收买

**判据不是"穷不穷"，而是"是否承接未来"。** 这条判据后来被反复使用（也是它最被广泛争论的地方）。注意马克思给中间等级留了一条门："如果说他们是革命的，那是指他们行将转入到无产阶级的队伍里来"——**革命性是可以获得的，但必须是放弃原有立场换来的。**

### 抓手句
> 在当前同资产阶级对立的一切阶级中，只有无产阶级是真正革命的阶级。

> 他们不是革命，而是保守。不仅如此，他们甚至是反动的，因为他们力图使历史的车轮倒转。

> 由于他们的整个生活状况，他们更甘心于被人收买，去干反动的勾当。

## 1.12 无产阶级为什么必须摧毁一切

### 这一步干什么
回答"为什么无产阶级不能像以前所有阶级那样，取代统治者然后享受特权"。

### 论证结构（四层对比）
```
① 无产阶级的处境已虚无化：
   无产者没有财产；和妻子儿女的关系与资产阶级的家庭关系再没有任何共同之处；
   现代的工业劳动、现代的资本压迫，无论在英国或法国、美国或德国都是一样的
   → 使无产者失去了任何民族性
   → 法律、道德、宗教本质都是后面隐藏着资产阶级利益的资产阶级的偏见
② 过去的阶级：争得统治后，企图巩固自己的生活地位，使全社会服从于保障它们发财致富的条件
   无产阶级：只有废除自己现存的占有方式、进而废除全部现存的占有方式，才能取得社会生产力
   → 无产者没有什么必须加以保护的东西，他们必须摧毁至今保护和保障私有财产的一切
③ 过去的运动：都是少数人的运动，或者说都是为少数人谋利益的运动
   无产阶级的运动：绝大多数人为绝大多数人的独立自主谋利益的运动
④ 无产阶级是现代社会的最下层，如果不摧毁压在自己头上的、全部由官方阶层构成的上层建筑，
   就不能抬起头来，挺起胸来
【补充限定】"如果不就内容而就形式来说"，斗争首先是一国范围内的斗争；
            每个国家的无产阶级当然首先应该打倒本国的资产阶级
【推进】然后 —— 直到这个战争爆发为公开的革命，无产阶级用暴力推翻资产阶级而建立自己的统治
```

### 逻辑要害

**注意②这个句式共享：** "争得统治"→"巩固自己" vs "必须废除占有方式才能取得生产力"。**这是对比法的核心。** 无产阶级的"无产"不是一个可怜的缺陷，而是一个**革命的条件**：因为一无所有，所以不可能通过改良得到满足；因为不可能妥协，所以只能彻底。

**注意③是全书被广泛引用的一句，且它是数量论证：** 过去所有运动都是少数人的/为少数人的，这次是绝大多数人的/为绝大多数人的。**数量对比取代了道德正当性论证。**

**注意"这是一国范围内的斗争"这个限定词很重要。** 它预先处理了"既然无产阶级没有祖国，为什么还要在本国革命"这个表面矛盾。答案是：形式上一国，内容上国际。

### 抓手句
> 现代的工业劳动，现代的资本压迫，无论在英国或法国，无论在美国或德国，都是一样的，都使无产者失去了任何民族性。

> 无产者没有什么必须加以保护的东西，他们必须摧毁至今保护和保障私有财产的一切。

> 无产阶级的运动是绝大多数人为绝大多数人的独立自主谋利益的运动。

> 如果不就内容而就形式来说，无产阶级反对资产阶级的斗争首先是一国范围内的斗争。每个国家的无产阶级，当然首先应该打倒本国的资产阶级。

## 1.13 为什么资产阶级再也不能统治下去

### 这一步干什么
**这是第一章的最后一击，也是最容易被漏掉的一节。** 马克思问了一个非常具体、非常尖锐的问题：**一个阶级要统治，最低条件是什么？**

### 论证结构
```
【公 理】  至今的一切社会都是建立在压迫阶级和被压迫阶级的对立之上
【必要条件】为了有可能压迫一个阶级，就必须保证这个阶级至少能够有勉强维持它奴隶般生存的条件
【历史对比】农奴曾经在农奴制度下挣扎到公社社员的地位
            小资产者曾经在封建专制制度的束缚下挣扎到资产者的地位
            → 被压迫阶级至少还能"上升"
【反 转】  现代的工人却正相反，他们并不是随着工业的进步而上升，而是每况愈下，
            越来越降到本阶级原有的生存条件以下
【判 定】  工人变成赤贫者，贫困的速度比人口和财富增长的速度还要快
【结 论】  资产阶级再不能做社会的统治阶级，再不能把本阶级的生存条件当做支配一切的规律强加于全社会
            资产阶级再无法统治下去，因为它的疯狂榨取已经不能保证被自己统治的阶级
            能维持奴隶般生存，因为它们让被统治阶级落到无力养活它们，反而还要它们来养活的地步
            社会再不能在它们统治下继续运转下去，就是说，它的存在不再同社会相容
```

### 逻辑要害

**这一节用的是"最低门槛法"，极其凶狠：**

> 统治不需要让奴隶过好日子，**只需要让奴隶活得下去**。可是资本主义现在连这个最低门槛都守不住了。

它不是说"工人阶级很惨"（那是 1.8），而是说**统治关系的必要条件已经失效**。一个维持不了最低条件的体系，是**逻辑上**无法继续的，不是道义上应当被推翻的。

**" reverse" 这个对比也很妙：** 农奴能升为公社社员、小资产者能升为资产者，说明过去的体系包含某种上升通道。现代工人不但没有通道，反而向下降。这里的力度在于：**连奴隶制都比现在的处境好一点点**——这是对"历史的进步"最辛辣的反讽。

### 抓手句
> 为了有可能压迫一个阶级，就必须保证这个阶级至少能够有勉强维持它奴隶般生存的条件。

> 现代的工人却正相反，他们并不是随着工业的进步而上升，而是每况愈下，越来越降到本阶级原有的生存条件以下。

> 工人变成赤贫者，贫困的速度比人口和财富增长的速度还要快。

> 资产阶级再无法统治下去……社会再不能在它们统治下继续运转下去，就是说，它的存在不再同社会相容。

### 为什么放在这里
因为它是**从"不得不推翻"到"推翻了会成功"的桥梁**。前面论证了无产阶级要革命，1.14 要论证革命必然胜利。中间需要一节 доказать：**对手已经不具备继续存在的条件了。** 没有这一节，1.14 的"必然"会显得突兀。

## 1.14 结论：两个不可避免

### 这一步干什么
**收拢第一章全部线索，给出全书第一个、也是最重要的结论。**

### 论证结构
```
【必要条件】资产阶级赖以生存和统治的根本条件 = 财富在私人手里的积累 = 资本的形成和增殖
【资本的前提】资本存在的前提条件是雇佣劳动
【雇佣劳动的前提】雇佣劳动完全是建立在工人为了生存的相互间的竞争之上
【但现在】      工业进步（资产阶级为了获取更多资本而无意为之、且无力抵抗的）
                → 使工人通过结社而达到的革命联合，代替了他们之间为了生存而相互竞争所造成的分散状态
【推论】        于是，随着大工业的发展，资产阶级赖以生产和占有产品的基础本身
                也就从它的脚下被挖掉了
【总结】        它首先生产的是它自身的掘墓人
【最终结论】    资产阶级的灭亡和无产阶级的胜利是同样不可避免的
```

### 逻辑要害

**这一段的关键是"前提链条被抽掉"：**

```
资本的增殖 ← 需要雇佣劳动 ← 需要工人之间的相互竞争
                                    ↓（工业进步反而造成工人结社）
                            竞争被革命联合所取代
                                    ↓
                        最底下的一块砖被抽掉了
```

抽掉的是**最基础的那块砖**。工人之间的竞争是雇佣劳动的存在条件，而大工业偏偏把工人赶到一起、教会他们组织。**资产阶级为了追求更多资本而做的每一件事，都在拆自己地基上的砖。**

**这就是为什么"两个不可避免"是"同样"的。** 不是先有资产阶级灭亡、再有无产阶级胜利，而是同一个过程的两个面：基础一旦被挖掉，上面的建筑就塌，而下面站立的人就赢了。**一句话讲完一件事。**

### 抓手句（必背，这是第一章的最终落点）
> 雇佣劳动完全是建立在工人为了生存的相互间的竞争之上。

> 随着大工业的发展，资产阶级赖以生产和占有产品的基础本身也就从它的脚下被挖掉了。它首先生产的是它自身的掘墓人。

> **资产阶级的灭亡和无产阶级的胜利是同样不可避免的。**

## 2.1 党的定位：六条定义，全部用否定句开头

### 这一步干什么
让读者先相信：**共产党不是凌驾于工人之上的另一批人。**

### 论证结构（六条，注意全部是"不是…而是…"句式）
```
① 共产党人不是同其他工人政党相对立的特殊政党
② 他们没有任何同整个无产阶级的利益不同的利益
③ 他们不提出任何特殊的原则，用以塑造无产阶级的运动
④ ─── 唯一的不同之处 ───
   一方面：在各国无产者的斗争中，强调和坚持整个无产阶级共同的不分民族的利益
   另一方面：在无产阶级和资产阶级的斗争所经历的各个发展阶段上，始终代表整个运动的利益
⑤ 实践方面：各国工人政党中最坚决的、始终起推动作用的部分
⑥ 理论方面：胜过其余无产阶级群众的地方在于了解无产阶级运动的条件、进程和一般结果
【最近目的】和其他一切无产阶级政党一样：使无产阶级形成为阶级，推翻资产阶级的统治，由无产阶级夺取政权
【理论来源】共产党人的理论原理，决不以这个或那个世界改革家所臆想或发现的思想、原则为根据
            这些原理不过是现在正在进行的阶级斗争和我们眼前的历史运动的真实关系的一般表述
```

### 逻辑要害

**（1）前三句全是"不是"。** 这是极讲究的开场：一个宣称要领导全阶级的党，第一件事必须是**否认自己的特殊性**——否则读者立刻会问"你们凭什么指挥我们"。三条否定之后才敢说"我们不同的地方只有……"。**顺序不能倒：先消解怀疑，再说明区别。**

**（2）理论来源是全章的哲学根基：**
> **这些原理不过是现在正在进行的阶级斗争和我们眼前的历史运动的真实关系的一般表述。**

这句话在方法论上非常重要：**马克思否认自己"发明"了什么。** 理论不是从脑子里想出来的方案，而是对正在进行的事情的描述。**这直接把《宣言》和第三章要批判的"空想社会主义"区分开了**——空想社会主义者"发明"社会计划，马克思"表述"现实运动。这个区分在第二章埋下，到第三章才清算。

### 抓手句
> 共产党人不是同其他工人政党相对立的特殊政党。

> 他们没有任何同整个无产阶级的利益不同的利益。

> 共产党人的理论原理，决不以这个或那个世界改革家所臆想或发现的思想、原则为根据。

> 这些原理不过是现在正在进行的阶级斗争和我们眼前的历史运动的真实关系的一般表述。

## 2.2 核心命题：共产党人可以把自己的理论概括为一句话——消灭私有制

### 这一步干什么
推出全书唯一被压缩到五个字的核心主张。

### 论证结构（三层铺垫，然后一句话落地）
```
【铺垫①】废除先前存在的所有制关系，并不是共产主义所独具的特征
          → 一切所有制关系都经历了经常发生的历史更替和历史变更
          → 例证：法国革命废除了封建的所有制，代之以资产阶级的所有制
【铺垫②】现代资产阶级的私有制是建立在阶级对立上面、建立在一些人对另一些人的剥削上面的
          产品生产和占有的最后而又最完备的表现
【判  定】共产主义的特征并不是要废除一般的所有制，而是要废除资产阶级的所有制
【结  论】从这个意义上说，共产党人可以把自己的理论概括为一句话：消灭私有制
```

### 逻辑要害

**铺垫①是一次"降维打击"。** 读者的第一反应是："私有财产自古以来天经地义，你们居然要废它？" 马克思的第一步回答是：**别激动，私有制从来就在被废除。** 法国革命才过没多久，昨天刚废除封建所有制今天就有了你们的这种——**你们自己就是靠"废除所有制"起家的。**

这个招法叫 **"以子之矛"**：资产阶级历史上的革命行为，恰恰证明了"所有制可以被废除"。那么现在轮到你了。

**铺垫②的措辞要准确**：废的不是"一般的所有制"，而是**资产阶级的**所有制的阶级内容。**这是一个限定句，也是最常被外界误读的地方——所以必须连限定词一起背。**

### 抓手句（三层铺垫+结论，四句连背）
> 废除先前存在的所有制关系，并不是共产主义所独具的特征。

> 法国革命废除了封建的所有制，代之以资产阶级的所有制。

> 共产主义的特征并不是要废除一般的所有制，而是要废除资产阶级的所有制。

> **共产党人可以把自己的理论概括为一句话：消灭私有制。**

## 2.3 反驳①：你们要消灭个人挣得的、自己劳动得来的财产吗？

> **从这里开始一直到 2.12，是全书最精妙的段落群：八组反驳。读懂它们的排列，就读懂了马克思的论战方法。**

### 论证结构
```
【对方指控】要消灭个人挣得的、自己劳动得来的财产，要消灭构成个人的一切自由、
            活动和独立的基础的财产
【马克思先反问】好一个劳动得来的、自己挣得的、自己赚来的财产！
【二分法】  你们说的是哪一种？
            (A) 资产阶级所有制以前的那种小资产阶级的、小农的财产？
                → 那种财产用不着我们去消灭，工业的发展已经把它消灭了，而且每天还都在消灭
            (B) 现代的资产阶级的私有财产？
                → 难道雇佣劳动、无产者的劳动，会给无产者创造出财产来吗？没有的事
                → 这种劳动所创造的是资本，即剥削雇佣劳动所得到的财产，
                  也即只有在不断产生出新的雇佣劳动用来提供重新加以剥削的条件下，才能增加起来的财产
【转入下节】现今这种财产正在资本和雇佣劳动的对立运动中演进 → 让我们来看看这种对立的两个方面
```

### 逻辑要害
**这一节的核心是"拆分同一个词"。** "私有财产"这一个词，被拆成两种完全不同的东西：

| | (A) 小资产阶级/小农的财产 | (B) 资产阶级私有财产 |
|---|---|---|
| 来源 | 自己劳动挣得 | 剥削雇佣劳动 |
| 马克思的态度 | **不需要我去消灭——大工业已经消灭了它** | 这才是要消灭的 |

**最狠的是 (A) 那一枪：** 你们哭着要保护的"诚实劳动所得的小财产"，**已经被你们自己消灭了**。你们的工厂早就杀掉了它。既然如此，你们拿"保护劳动所得"来攻击我，就是虚伪的。

**然后把这两个选项架在资产阶级面前：你只能选 B，而 B 是剥削来的。**

### 抓手句
> 这种劳动所创造的是资本，即剥削雇佣劳动所得到的财产。

## 2.4 资本是集体产物：把资本从"个人"手里拿回来

### 论证结构
```
【第一步】做一个资本家 = 在生产中不仅占有一种纯粹个人的地位，而且占有一种社会的地位
【第二步】资本是集体的产物，它只有通过社会许多成员的共同活动，
          而且归根到底只有通过社会全体成员的共同活动，才能运动起来
【第三步】因此，资本不是一种个人力量，而是一种社会力量
【第四步】因此，把资本变为公共的、属于社会全体成员的财产，这并不是把个人财产变为社会财产
          这时所改变的只是财产的社会性质。它将失掉它的阶级性质
```

### 逻辑要害
这是一个**"你本来就偷了东西"式的论证**：

> 你（资本）本来就是全社会的共同劳动创造出来的力量，只是被一套制度记到了个人的账上。现在把它收归公共，**不是没收，是认领。**

**关键是最后一句的精确性：**"……**这并不是**把个人财产变为社会财产。这时所改变的只是**财产的社会性质**。它将失掉它的**阶级性质**。" 注意马克思在这里做了两个转换：
- 从"谁占有"转为"占有是什么性质"（问题被重新定义了）
- 从"剥夺个人"转为"去除阶级性"（动作被重新定义了）

**背诵时背这个"重新定义"的动作，比背整段更有效。**

## 2.5 雇佣劳动：把工人立场的"最低工资"摆出来

### 论证结构
```
【定义】  雇佣劳动的平均价格是最低限度的工资，即工人为维持其工人的生活所必需的生活资料的数额
【推论】  雇佣工人靠自己的劳动所占有的东西，只够勉强维持他的生命的再生产
【划界线】我们决不打算消灭这种供直接生命再生产用的劳动产品的个人占有
          ——因为这种占有并不会留下任何剩余的东西使人们有可能支配别人的劳动
【真正的目标】我们要消灭的只是这种占有的可怜的性质，
              在这种占有下，工人仅仅为增殖资本而活着，只有在统治阶级的利益需要他活着的时候才能活着
【对比金句】在资产阶级社会里，活的劳动只是增殖已经积累起来的劳动的一种手段
            在共产主义社会里，已经积累起来的劳动只是扩大、丰富和提高工人的生活的一种手段
【哲学总结】在资产阶级社会里是过去支配现在，在共产主义社会里是现在支配过去
            在资产阶级社会里，资本具有独立性和个性，而活动着的个人却没有独立性和个性
```

### 逻辑要害
**这一节再次使用"精确划线"战术：明确说出我们不反对什么。** 我们不反对"工人拿工资糊口这件事"，我们反对的是"这种占有使人仅仅为了资本增殖而活着"。

这种"划线"动作在论战上极其有效：**它把对手可能占据的道德高地预先接管了。**

**最后那两句对偶是全书最漂亮的对称句：**
```
资产阶级社会：活的劳动     → 增殖 已经积累起来的劳动     的手段
共产主义社会：已经积累的劳动 → 扩大工人阶级的生活         的手段
```
主语和宾语**完全调转**。这是一种"镜像修辞"：**同一个关系被翻转过来。** 背诵时把这两句一起背，只记"谁是为谁服务的"就够了：
- 资本主义：**过去的死劳动**（资本）统治现在的活人
- 共产主义：**现在的活人**支配过去的死劳动

### 抓手句
> 雇佣劳动的平均价格是最低限度的工资。

> 我们要消灭的只是这种占有的可怜的性质。

> 在资产阶级社会里，活的劳动只是增殖已经积累起来的劳动的一种手段。在共产主义社会里，已经积累起来的劳动只是扩大、丰富和提高工人的生活的一种手段。

> **在资产阶级社会里是过去支配现在，在共产主义社会里是现在支配过去。**

> 在资产阶级社会里，资本具有独立性和个性，而活动着的个人却没有独立性和个性。

## 2.6 反驳②：你们要消灭个性和自由吗？（定义权争夺）

### 论证结构
```
【对方的恐慌】消灭私有制 = 消灭个性和自由
【马克思承认】而资产阶级却把消灭这种关系说成是消灭个性和自由！说对了。
              的确，正是要消灭资产者的个性、独立性和自由
【第一刀：定义"自由"】在现今的资产阶级生产关系的范围内，所谓自由就是自由贸易，自由买卖
【第二刀：这自由会消失】但是，买卖一旦消失，自由买卖也就会消失
【第三刀：这自由本就有限】关于自由买卖的言论，也像资产阶级其他一切关于自由的大话一样，
              仅仅对于不自由的买卖来说、对于中世纪被奴役的市民来说，才有意义
              而对于共产主义要消灭买卖这一点来说，却是毫无意义
【第四刀：多数人早就没有了】你们为什么要恐慌，我们要消灭私有制？
              但是，在你们的现存社会里，私有财产对十分之九的成员来说已经被消灭了；
              这种私有制之所以存在，正是因为私有财产对十分之九的成员来说已经不存在
【判定】      你们指责我们要消灭的，是以社会上的绝大多数人没有财产为必要条件的所有制
【归结点】    你们是承认，你们所理解的个性，不外是资产者、资产阶级私有者。
              这样的个性确实应当被消灭
【总原则】    共产主义并不剥夺任何人占有社会产品的权力，
              它只剥夺利用这种占有去奴役他人劳动的权力
```

### 逻辑要害

**这是全书"定义权争夺"最典型的一段。** 马克思的战术是：**不否认对方的指控，而是重新定义被指控的那个词。**

```
"自由"  ──► 不是抽象原则，而是"自由贸易、自由买卖"
"个性"  ──► 你们的个性 = 资产者、资产阶级私有者的个性
"占有"  ──► 我们只剥夺"奴役他人劳动的权力"，不剥夺"占有产品的权力"
```

一旦这些词被重新定义，对方的指控就自动失效了——**"消灭资产者的自由"这句话听上去就不再是罪行，而是解放的清单。**

**"十分之九"这个数字是全段的炸药：** 你们说私有财产是普遍的、人皆有权的东西？可你们的社会里十分之九的人已经没有了。**你们维护的只是一小撮人靠多数人无产才成立的所有制。** 道德优势被彻底反转。

### 抓手句
> 在现今的资产阶级生产关系的范围内，所谓自由就是自由贸易，自由买卖。

> 在你们的现存社会里，私有财产对十分之九的成员来说已经被消灭了。

> 你们所理解的个性，不外是资产者、资产阶级私有者。这样的个性确实应当被消灭。

> **共产主义并不剥夺任何人占有社会产品的权力，它只剥夺利用这种占有去奴役他人劳动的权力。**

## 2.8 反驳④：你们要消灭教育吗？（引出历史唯物主义的核心表述）

### 论证结构
```
【扩大化的指控】所有对物质产品的占有方式和生产方式的责备，也被扩及到精神产品的占有和生产方面
                （资产者看来：阶级的所有制终止 = 生产本身终止；阶级的教育终止 = 一切教育终止）
【反击】        资产者唯恐失去的那种教育，对绝大多数人来说是把人训练成机器
【切入根本】    你们既然用你们资产阶级关于自由、教育、法等等的观念来衡量废除资产阶级所有制的主张，
                那就请你们不要同我们争论了
                → 你们的观念本身是资产阶级的生产关系和所有制关系的产物，
                  正像你们的法不过是被奉为法律的你们这个阶级的意志一样，
                  而这种意志的内容是由你们这个阶级的物质生活条件来决定的
【深层揭露】    你们的利己观念使你们把自己的生产关系和所有制关系从历史的、在生产过程中是暂时的
                关系变成永恒的自然规律和理性规律
                这种利己观念是你们和一切灭亡了的统治阶级所共有的
                → 谈到古代所有制的时候你们所能理解，谈到封建所有制的时候你们所能理解，
                  可一谈到资产阶级所有制的时候，你们就再也不愿理解了
```

### 逻辑要害

**（1）核心句（必须逐字背）：**
> **"你们的观念本身是资产阶级的生产关系和所有制关系的产物，正像你们的法不过是被奉为法律的你们这个阶级的意志一样，而这种意志的内容是由你们这个阶级的物质生活条件来决定的。"**

这是**历史唯物主义关于上层建筑的经典表述**。它可以拆成三段：
```
观念 ← 生产关系/所有制关系 的产物
法   ← 被奉为法律的 阶级意志
意志 ← 由 物质生活条件 决定
```
三者是同一个方向：**存在决定意识**。

**（2）第二段揭露的是一个普遍的心理变态：** 资产阶级能理解"奴隶制的所有制被废除了"，能理解"封建所有制被废除了"，唯独轮到自己时不理解。**这不是认知问题，是利益问题。** 这一刀砍的位置很准——它把对手从"讲道理的人"降格为"掩饰利益的人"。

**（3）在《宣言》内部的作用：** 这一段是 2.12（意识形态总反驳）的"预告片"，也是 3（社会主义文献批判）的方法论基础——既然一切观念都是阶级利益的产物，那么任何"社会主义"文献都要先问：**它代表哪个阶级的利益？**

### 抓手句
> 资产者唯恐失去的那种教育，对绝大多数人来说是把人训练成机器。

> 你们的观念本身是资产阶级的生产关系和所有制关系的产物……而这种意志的内容是由你们这个阶级的物质生活条件来决定的。

> 谈到古代所有制的时候你们所能理解，谈到封建所有制的时候你们所能理解，可一谈到资产阶级所有制的时候，你们就再也不愿理解了。

## 2.9 反驳⑤：你们要消灭家庭吗？

### 论证结构
```
【对方的愤慨】"消灭家庭！连极端的激进派也对共产党人的这种'可耻'的意图表示愤慨"
【第一步反问】现代的、资产阶级的家庭是建立在什么基础上的呢？
【回  答】    是建立在资本上面，建立在私人发财上面
【揭露补充】  这种家庭只是在资产阶级那里才以充分发展的形式存在着，
              而无产者的被迫独居和公开的卖淫则是它的补充
【推  论】    资产者的家庭自然会随着它的这种补充的消失而消失，两者都要随着资本的消失而消失
【反守为攻】  你们是责备我们要消灭父母对子女的剥削吗？我们承认这种罪状
【反击】      你们说，我们用社会教育代替家庭教育，就是要消灭人们最亲密的关系
              但是，你们的教育不也是由社会决定的吗？不也是由你们进行教育的那种社会关系
              决定的吗？不也是由社会通过学校等等进行的直接的或间接的干涉决定的吗？

              要使教育摆脱统治阶级的影响
【补  刀】    无产者的一切家庭联系越是由于大工业的发展而被破坏，他们的子女越是被变成
              单纯的商品和劳动工具，资产阶级关于家庭和教育、关于父母和子女的亲密关系的
              空话就越是令人作呕
```

### 逻辑要害
**战术：不接受对方设定的辩论框架。**

对方问："你们要消灭家庭吗？" 普通人会急着回答"不不不"。马克思不回答这个问题——他先反问：**"你说的家庭是哪种家庭？"** 然后给出三个层面的拆解：

| 层面 | 拆解 |
|---|---|
| 基础 | 资产阶级家庭建立在**资本**、**私人发财**上 |
| 现实 | 它在无产者身上的表现是**被迫独居和公开卖淫** |
| 未来 | 两者随资本的消失而消失 |

**"我们承认这种罪状"（明示 admitting the charge）是马克思的招牌动作：** 把对方的指控用精确措辞重述一遍，然后承认——**承认的瞬间，指控的道德力量就消失了。** "消灭父母对子女的剥削"——谁敢反对这句话？

**后面那三个连续"不也是……吗？"** 说明：你们的教育本来就已经是社会化的了（学校、社会关系决定），我们只是要**改变它的性质**（使教育摆脱统治阶级的影响）。这又是"重新定义"战术：**从"有没有社会教育"改成"社会教育由谁来主导"。**

### 抓手句
> 现代的、资产阶级的家庭是建立在什么基础上的呢？是建立在资本上面，建立在私人发财上面。

> 你们是责备我们要消灭父母对子女的剥削吗？我们承认这种罪状。

> 共产党人并没有发明社会对教育的影响；他们仅仅是要改变这种影响的性质，要使教育摆脱统治阶级的影响。

## 2.10 反驳⑥：你们要实行公妻制吗？（最辛辣的一节）

```
【对方叫喊】你们共产党人是要实行公妻制的啊，——整个资产阶级异口同声地向我们这样叫喊

            那是再可笑不过了。公妻制无需共产党人来实行，它差不多是一向就有

```

### 逻辑要害
**这是全书修辞杀伤力最高的一节。它的手法是"投射反转"：**

```
你们指控我们要共妻
        ↓
但"把妻子当生产工具"这个观念，恰恰是你们自己的
        ↓
所以你们之所以会想到"共妻"，是因为你们先这样看女人
        ↓
那么真正的公妻制，是你们已经实行着的那个（把工人妻女当可支配的资源）
        ↓
我们顶多是想把它从伪善的形式，变成公开的形式
        ↓
而最终要消灭的，是产生这件事的生产关系
```

**"你们之所以会产生这个指控，是因为你们自己就是这么想的"**——这是一个心理层面的论证，杀伤力极大，也最招恨。注意马克思的措辞是**基于事实的两条**：一是资产者对无产者妻女的支配，二是正式的卖淫制度存在。这两条一旦成立，"你们才是共妻制"这个结论在逻辑上就跳不掉。

### 抓手句
> 资产者把自己的妻子，看作单纯的生产工具。

> 资产阶级的婚姻实际上是公妻制。

## 2.11 反驳⑦：你们要取消祖国、取消民族吗？

### 论证结构
```
【对方指控】共产党人要取消祖国，取消民族
【第一句】  工人没有祖国。决不能剥夺他们所没有的东西
【精确化】  因为无产阶级首先必须取得政治统治，上升为民族的阶级，把自身组织成为民族，
            所以它本身还是民族的，虽然完全不是资产阶级所理解的那种意思
【历史趋势】随着资产阶级的发展，随着贸易自由的实现和世界市场的建立，
            随着工业生产以及与之相适应的生活条件的趋于一致，
            各国人民之间的民族隔绝和对立日益消失
【无产阶级的作用】无产阶级的统治将使它们更快地消失
【国际主义条件】联合的行动，至少是各文明国家的联合的行动，是无产阶级获得解放的首要条件之一
【对称结论】人对人的剥削一消灭，民族对民族的剥削就会随之消灭
            民族内部的阶级对立一消失，民族之间的敌对关系就会随之消失
```

### 逻辑要害

**"工人没有祖国。决不能剥夺他们所没有的东西。"** 这一句常被断章取义，必须连下一句一起背：

> 工人没有祖国（因为祖国作为"有阶级内容的共同体"，工人在其中没有份额）
> **但是**无产阶级必须首先上升为民族的阶级、把自身组织成为民族（**这是策略，不是原则的倒退**）

**第二段的论证方向极重要：** 马克思说的是——**民族对立已经在被资本主义自己消灭了**（贸易自由、世界市场、生活条件一致化）。也就是说：
- 民族隔绝不是什么需要保卫的永恒价值，它正在被现实消解
- 无产阶级统治只是**加速这个已经在进行的过程**

**两段对称结语是"同一件事的两个面"，务必成对背诵：**
```
剥削：  人对人的剥削     消灭 → 民族对民族的剥削 消灭
对立：  民族内部的阶级对立 消失 → 民族之间的敌对关系 消失
```
**注意方向的一致性：内部的决定外部的。** 这体现了马克思一贯的思路——国际关系的根源在国内的阶级关系。

### 抓手句
> 工人没有祖国。决不能剥夺他们所没有的东西。

> 人对人的剥削一消灭，民族对民族的剥削就会随之消灭。

> 民族内部的阶级对立一消失，民族之间的敌对关系就会随之消失。

## 2.12 反驳⑧：宗教、哲学、一般意识形态的责难（总清算）

### 这一步干什么
前面七组都是"具体指控"，这一组是**总根子**：把前面所有的反驳提升到方法论高度。

### 论证结构
```
【起手轻蔑】从宗教的、哲学的和一般意识形态的观点对共产主义提出的种种责难，都不值得详细讨论
【总原则】  人们的观念、观点和概念，一句话，人们的意识，
            随着人们的生活条件、人们的社会关系、人们的社会存在的改变而改变
【核心命题】任何一个时代的统治思想始终都不过是统治阶级的思想
【历史唯物主义的观察法】当人们谈到使整个社会革命化的思想时，他们只是表明了一个事实：
            在旧社会内部已经形成了新社会的因素，
            旧思想的瓦解同旧生活条件的瓦解步调一致
【三个史料佐证】
            古代世界灭亡时 → 古代各种宗教被基督教战胜
            18 世纪基督教思想被启蒙思想击败时 → 封建社会正同革命的资产阶级殊死斗争
            信仰自由和宗教自由的思想 → 不过是表明自由竞争在信仰的领域里占统治地位
【对方的终极诘问】虽然有变化，但宗教、道德、哲学、政治、法始终保存着；
                  还存在着一切社会状态所共有的永恒真理，如自由、正义等等
【马克思的回答（关键推理）】
            至今的一切社会的历史，都在阶级对立中运动，而这种对立在不同时代具有不同形式
            但是，不管对立具有什么样的形式，社会上一部分人对另一部分人的剥削
                却是过去各个世纪所共有的事实
            因此，毫不奇怪，各个世纪的社会意识，尽管形形色色、千差万别，
                总是在某些共同的形式中运动
            这些形式、这些意识形式，只有当阶级对立完全消失的时候才会完全消失
【结论】    共产主义革命就是同传统的所有制关系实行最彻底的决裂；
            毫不奇怪，它在自己的发展进程中要同传统的观念实行最彻底的决裂
```

### 逻辑要害

**（1）"都不值得详细讨论"不是傲慢，是判定了讨论层级。** 前面已经论证了"观念由物质生活条件决定"，那么跟一位坚持"自由是永恒真理"的人继续辩论，等于在不承认前提的情况下辩论。所以马克思直接给出**元层面的解释**：为什么你们会觉得有永恒真理。

**（2）那个回答非常有力：** 你说宗教、道德、法的内容在变，但"宗教、道德、法"这个形式始终存在，所以有永恒真理？——马克思答：**对，因为"剥削"这件事始终存在。** 形式是变化的、多样的，但共同性来自一个不光彩的共同事实：**每个世纪都有人在剥削另一些人。** 一旦这个事实消失，那些共同形式才会跟着消失。

> **换言之：你引以为傲的"永恒真理"，不过是"永恒的剥削"在观念上的投影。**

**（3）两个"最彻底的决裂"是全书最常被引用的一句：**
```
同传统的所有制关系 实行最彻底的决裂   ← 物质的
同传统的观念       实行最彻底的决裂   ← 精神的（"毫不奇怪"，因为是前者的必然跟随）
```
注意**顺序**：先是所有制的决裂，然后才是观念的决裂。**这个顺序本身就是唯物主义。** 背诵时务必保持这个先后。

**（4）"好像Attribution" 那三个史料是典型的"一秒钟讲完一部思想史"：** 三个短句，把从古代到18世纪的意识形态更迭讲完，全部对应到社会形态的更迭。**这是马克思写作的经济手段——用三个例子代替一整本书的论证。**

### 抓手句
> 人们的观念、观点和概念，一句话，人们的意识，随着人们的生活条件、人们的社会关系、人们的社会存在的改变而改变。

> **任何一个时代的统治思想始终都不过是统治阶级的思想。**

> 旧思想的瓦解同旧生活条件的瓦解步调一致。

> 这些形式，这些意识形式，只有当阶级对立完全消失的时候才会完全消失。

> **共产主义革命就是同传统的所有制关系实行最彻底的决裂；毫不奇怪，它在自己的发展进程中要同传统的观念实行最彻底的决裂。**

### 为什么放在 2.13 之前
因为它是**全部反驳的收束和总结**：它把前面六组具体指控（财产/自由/教育/家庭/公妻/民族）统一理解为"同一类意识形态现象"。放它之后再讲行动纲领，逻辑上就干净了：**先把话说尽，再动手。**

## 2.13 行动纲领：十条措施

### 论证结构（四层包裹，注意外层比内层重要）
```
【第一层：前提】工人革命的第一步就是使无产阶级上升为统治阶级，争得民主
【第二层：任务】无产阶级将利用自己的政治统治，一步一步地夺取资产阶级的全部资本，
                把一切生产工具集中在国家即组织成为统治阶级的无产阶级手里，
                并且尽可能快地增加生产力的总量
【第三层：方法论】要做到这一点，当然首先必须对所有权和资产阶级生产关系实行强制性的干涉，
                  也就是采取这样一些措施——
                  这些措施在经济上似乎是不够充分的和没有力量的，
                  但是在运动进程中它们会超出本身，而且作为变革全部生产方式的手段必不可少
【第四层：限定】这些措施在不同的国家里当然会不同
【第五层：清单】但是，最先进的国家几乎都可以采取下面的措施：
                1. 剥夺地产，把地租用于国家支出
                2. 征收高额累进税
                3. 废除继承权
                4. 没收一切流亡分子和叛乱分子的财产
                5. 通过拥有国家资本和独享垄断权的国家银行，把信贷集中在国家手里
                6. 把全部运输业集中在国家手里
                7. 按照总的计划增加国营工厂和生产工具，开垦荒地和改良土壤
                8. 实行普遍劳动义务制，成立产业军，特别是在农业方面
                9. 把农业和工业结合起来，促使城乡对立逐步消灭
                10. 对所有儿童实行公共的和免费的教育。取消现在这种形式的儿童的工厂劳动。
                    把教育同物质生产结合起来
```

### 逻辑要害

**第一层是全书最重要的行动命题，务必逐字背：**
> **"工人革命的第一步就是使无产阶级上升为统治阶级，争得民主。"**

**第三层是马克思留给自己的退路，也是关键的思想方法：**
> "这些措施在经济上**似乎是不够充分的和没有力量的**，但是在运动进程中**它们会超出本身**，而且作为变革全部生产方式的手段**必不可少**。"

这句话的意思是：**不要拿这些措施本身来衡量它们。——它们是杠杆，不是成品。** 马克思预见到了"这几条太少了吧"的质疑，所以在清单之前先把它堵住。

**结合 1872 年序言**（见 `00` 钥匙三）：马克思恩格斯自己后来承认这十条"根本没有特别的意义"、"在许多方面都会有不同的写法"。

> **背诵建议：十条措施按三类分组记，不必死磕顺序。**
> - **剥夺类**（①②③④）：地产、累进税、继承权、流亡分子财产 —— 都是在切断财富的代际传递和聚集
> - **集中类**（⑤⑥⑦）：信贷、运输、工厂与土地 —— 都是把"社会的命脉部门"集中到国家手里
> - **改造类**（⑧⑨⑩）：劳动义务制、工农结合、公共教育 —— 都是改造**人本身**和**城乡关系**

> 记一句口诀：**"先断财路，再集中命脉，最后改造人。"**

### 抓手句
> 工人革命的第一步就是使无产阶级上升为统治阶级，争得民主。

> 这些措施在经济上似乎是不够充分的和没有力量的，但是在运动进程中它们会超出本身，而且作为变革全部生产方式的手段必不可少。

> 这些措施在不同的国家里当然会不同。

## 2.14 终点：自由人联合体

### 论证结构（最后四步）
```
【条件】  当阶级差别在发展进程中已经消失而全部生产集中在联合起来的个人的手里的时候
【结果】  公共权力就失去政治性质
【定义 shift】原来意义上的政治权力，是一个阶级用以压迫另一个阶级的有组织的暴力
【消亡逻辑】如果说无产阶级在反对资产阶级的斗争中一定要联合为阶级，
            如果说它通过革命使自己成为统治阶级，并以统治阶级的资格用暴力消灭旧的生产关系，
            那么它在消灭这种生产关系的同时，也就消灭了阶级对立和阶级本身的存在条件，
            从而消灭了它自己这个阶级的统治
【最终图景】代替那存在着阶级和阶级对立的资产阶级旧社会的，将是这样一个联合体，
            在那里，每个人的自由发展是一切人的自由发展的条件
```

### 逻辑要害

**这一段完成了一个极精妙的"自我消解"结构：**

```
无产阶级 ──夺取政权──► 成为统治阶级
                          │
                          ├──► 消灭旧的生产关系
                          │         │
                          │         └──► 消灭了阶级对立的存在条件
                          │                    │
                          └──────────────────┴──► 从而消灭了它自己这个阶级的统治
```

**无产阶级的统治是唯一会自我取消的统治。** 其他一切阶级掌权后都要巩固自己的地位（1.12 已经讲过），无产阶级掌权的目的是创造使自己不再作为阶级存在的条件。这就回答了"你们夺取政权之后不就变成新的压迫者了吗"这个永恒质疑。

**最后一句是全书最著名的一句，要注意它的精确结构：**
> **每个人的自由发展是一切人的自由发展的条件。**

注意方向：**不是**"一切人的自由发展是每个人的条件"（那会被读成集体压个人），**而是**"每个人的自由发展"是"一切人的自由发展"的**条件**。**个人的自由是前提，整体的自由是结果。** 这是马克思对"个人 vs 集体"这个问题的正式回答，常被误读，务必一字不差地背。

**还要注意"联合体"这个译法：** 它的德语是 Assoziation，强调的是"自由人的联合"，不是"国家"。这说明 2.14 的终点与 2.13 的"把生产工具集中在国家手里"并不是同一层——**国家是过渡，联合体是终点。**

### 抓手句
> 原来意义上的政治权力，是一个阶级用以压迫另一个阶级的有组织的暴力。

> 代替那存在着阶级和阶级对立的资产阶级旧社会的，将是这样一个联合体，在那里，每个人的自由发展是一切人的自由发展的条件。

# 【3】社会主义和共产主义的文献

**整章任务**：**划界。** 回答"你们跟那些社会主义有什么区别"。
**整章写法**：**分类学**——给当时所有社会主义流派做一次"阶级归属 + 方向判定"。

## 先搞懂第三章的"统一判据"（3.0′）

**这一章最容易被读成一堆人名和嘲讽，那就全白读了。真正的钥匙在这里——马克思不是按学说内容分类，而是按两个坐标判定：**

```
坐标一：它代表哪个阶级的利益？（这是根源）
坐标二：它要把历史推向哪个方向？（这是后果）
        向后 ──► 反动
        停住 ──► 保守
        跳过 ──► 空想
```

**三类的名字本身就泄露了这个判据：**

| 类别 | 名字 | 时间取向 | 代表谁 | 致命缺陷 |
|---|---|---|---|---|
| **1 反动** | 封建的 / 小资产阶级的 / 德国的"真正的" | **向后**（回到过去） | 贵族 / 小市民 / 德国小市民 | 完全不能理解现代历史的进程 |
| **2 保守** | 资产阶级的社会主义 | **停住**（维持现状） | 资产者中的改良派 | 要资本主义不要无产阶级 |
| **3 空想** | 圣西门、傅立叶、欧文 | **跳过**（跑到条件不具备的未来） | 无（自称超阶级） | 看不到解放的物质条件 |

**三类的共同点：都不站在"生产力发展这个真实动力"上。** 而这也正是《宣言》自己的定位：**既不回头、也不停住、也不空跳，而是站在现实的运动之上。**

## 3.1 反动的社会主义

### （甲）封建的社会主义

**论证**：法国和英国的贵族在政治斗争中失败后，只能做文字斗争 → 为了激起同情，装作是为工人利益说话 → 于是产生了"半是挽歌，半是谤文；半是过去的回音，半是未来的恫吓"

**判据**：
- 它的控告罪状暴露了它是反动的：**"在资产阶级的统治下有一个将把整个旧社会制度炸毁的阶级发展起来"**——他们责备资产阶级，与其说是因为它产生了无产阶级，不如说是因为它产生了**革命的**无产阶级
- 在政治实践中，他们参与镇压工人的一切暴力措施；在日常生活中屈尊拾取金苹果（做羊毛、甜菜、烧酒的买卖）
- 最精妙的一处：**"每当人民跟着他们走的时候，都发现他们的臀部带有旧的封建纹章，于是就哈哈大笑，一哄而散。"**

**附：基督教的社会主义** —— " **基督教的社会主义，只不过是牧师用来使贵族的怨愤神圣化的圣水罢了。**"

### （乙）小资产阶级的社会主义

**论证**：新形成的小资产阶级摇摆于无产阶级和资产阶级之间，不断被竞争抛到无产阶级里去 → 西斯蒙第是这类作家的首领（法国、英国）

**先肯定后否定：** 这种社会主义**非常透彻地分析了现代生产关系中的矛盾**（机器和分工的破坏作用、资本和地产的积聚、生产过剩、危机、必然没落、贫困、生产无政府状态、财富分配极不平均、工业战争、旧风尚旧家庭旧民族性的解体）

**判据（反动+空想的双重性）：**
> 按其实际内容来说，**或者是企图恢复旧的生产资料和交换手段，从而恢复旧的所有制关系和旧的社会，或者是企图重新把现代的生产资料和交换手段硬塞到已被它们突破而且必然被突破的旧的所有制关系的框子里去。它在这两种场合都是反动的，同时又是空想。**

**最后结论："工业中的行会制度，农业中的宗法经济，——这就是它的最后结论。"**

### （丙）德国的或"真正的"社会主义

**论证（重要，这是马克思讲"翻译"的方法论）：**
```
法国文献搬到德国时，法国的生活条件却没有同时搬过去
      ↓
这些文献完全失去了直接实践的意义，而只具有纯粹文献的形式
      ↓
于是必然表现为关于真正的社会、关于实现人的本质的无谓思辨
```
**辛辣比喻**：就像牧师在古代异教经典手抄本上写荒诞的天主教圣徒传，德国著作家在法国原著下面写上自己的哲学胡说——"人的本质的外化"、"抽象普遍物的统治的扬弃"

**判据**：这种文献被彻底"阉割"了；它不代表真实的要求，而代表"真理的要求"；不代表无产者的利益，而代表"人的本质的利益"，即那种**不属于任何阶级、根本不存在于现实世界、只存在于云雾弥漫的哲学幻想的太空**的一般人。

**严重后果**：它成了德意志各邦专制政府吓唬资产阶级的稻草人，是"这些政府用来镇压德国工人起义的毒辣的皮鞭和枪弹的甜蜜的补充"。它代表的反动利益 = **德国小市民的利益**（"在德国，16 世纪遗留下来的小资产阶级，是现存制度的真实的社会基础"）。

**核心的教学点**：这一段是全书讲"**理论脱离物质条件会变成什么**"的经典案例。同一份法国文献，在法国是阶级斗争的表达，搬到德国就变成哲学垃圾——**因为德国缺的是法国那样的现实阶级斗争。** 这是"社会存在决定社会意识"最生动的一次演示。

### 抓手句（3.1）
> 封建的社会主义，半是挽歌，半是谤文；半是过去的回音，半是未来的恫吓。

> 为了拉拢人民，贵族们把无产阶级的乞食袋当做旗帜来挥舞……**他们的臀部带有旧的封建纹章**。

> 德国人就认为：他们不代表真实的要求，而代表真理的要求，不代表无产者的利益，而代表人的本质的利益。

> 这种社会主义是这些政府用来镇压德国工人起义的毒辣的皮鞭和枪弹的甜蜜的补充。

---

## 3.2 保守的或资产阶级的社会主义

**论证**：资产阶级中的一部分人想要消除社会的弊病，**以便保障资产阶级社会的生存**（经济的、慈善的、改良的、动物保护、戒酒协会；蒲鲁东《贫困的哲学》为例）

**全章最精炼的一把刀（必背）：**
> **社会主义的资产者愿意要现代社会的生存条件，但是不要由这些条件必然产生的斗争和危险。他们愿意要现存的社会，但是不要那些使这个社会革命化和瓦解的因素。他们愿意要资产阶级，但是不要无产阶级。**

这是典型的**三重平行句**，一句比一句紧：条件 → 社会 → 阶级。**剥到最后一层就是"要资产阶级不要无产阶级"，这是不可能的，所以它是自相矛盾的。**

**另一种形式**（行政改良派）：主张只改变物质生活条件而不触及生产关系 → "丝毫不会改变资本和雇佣劳动的关系，至多只能减少资产阶级的统治费用和简化它的财政管理"

**最后的反讽（必背）：**
> 自由贸易！为了工人阶级的利益；保护关税！为了工人阶级的利益；单身牢房！为了工人阶级的利益。——这才是资产阶级的社会主义唯一认真的最后要说的话。

> **资产阶级的社会主义就是这样一个论断：资产者之为资产者，是为了工人阶级的利益。**

**注意这里用了"归谬"**：自由贸易和保护关税是**互相矛盾**的两种政策，却都打着"为了工人"的旗号——**这本身就证明这个旗号是假的。**

---

## 3.3 批判的空想的社会主义和共产主义

**论证（结构清晰，是全章最有分量的一节）：**

```
【历史条件】无产阶级还没有足够发展，解放的物质条件还不具备（这些条件只是资产阶级时代的产物）
【所以失败】无产阶级最初的尝试必然遭到失败；当时的革命文献就其内容来说必然是反动的
            （普遍的禁欲主义和粗陋的平均主义）
【正题：圣西门、傅立叶、欧文】
   ✓ 看到了阶级对立、看到了统治社会本身中的瓦解因素
   ✗ 看不到无产阶级方面的任何历史主动性，看不到它所特有的任何政治运动
   ✗ 由于阶级对立的发展同工业的发展步调一致，所以他们也不可能看到无产阶级解放的物质条件
   → 于是他们就去探求某种社会科学、社会规律，以便创造这些条件
   → 社会的活动要由他们个人的发明活动来代替
   → 今后的世界历史不过是宣传和实施他们的社会计划
【他们的自我定位】以为自己高高超乎这种阶级对立之上 → 总是不加区别地向整个社会呼吁，
                  而且主要是向统治阶级呼吁
【他们的路线】拒绝一切政治行动，特别是一切革命行动；想通过和平途径达到目的；
              通过小型试验、通过示范的力量来开辟道路（肯定是不会成功的）
【马克思的公允评价——批判成分】
   ✓ 也含有批判的成分：抨击现存社会的全部基础
   ✓ 提供了启发工人觉悟的极为宝贵的材料
   ✓ 积极主张（消灭城乡对立、消灭家庭、消灭私人营利、消灭雇佣劳动、提倡社会和谐、
      把国家变成纯粹的生产管理机构）表明要消灭阶级对立——但只是早期的、不明显的、
      不确定的形式，所以本身还带有纯粹空想的性质
【核心判语（必背）】
   ★ 批判的空想的社会主义和共产主义的意义，是同历史的发展成反比
   ★ 虽然这些体系的创始人在许多方面是革命的，但是他们的信徒总是组成一些反动的宗派
   ★ 于是就有了那些试验：法伦斯泰尔、国内移民区、小伊加利亚（袖珍版的新耶路撒冷）
      ——为了建造空中楼阁，不得不呼吁资产阶级发善心和慷慨解囊
      ——他们逐渐地堕落到上述反动的或保守的社会主义者的一伙中去
   ★ 他们激烈地反对工人的一切政治运动，认为这种运动只是由于盲目地不相信新福音才发生
```

### 逻辑要害

**（1）"意义同历史的发展成反比"是全书最深刻的一句判语之一。**
它说的是：**一个学说不是由它的内容好坏决定的，而是由它所处的历史阶段决定的。** 阶级斗争越发展，超乎阶级斗争的幻想就越失去实践意义和理论根据。**同一套理论，在 1800 年是天才，在 1848 年就成了障碍。**

这一句同时也是马克思对自己理论的态度：**它同样要接受历史条件的检验**（这正是 1872 年序言的精神）。

**（2）注意马克思在这里是给出的一记宽恕：** "这些体系的创始人在许多方面是革命的"——他没有把圣西门、傅立叶、欧文一笔抹杀，而是区分了**创始人 vs 信徒**、**历史条件 vs 当下**。这与第三章整体尖锐的风格相比是难得的公允，也是这条 "意义与历史成反比" 的自洽应用：**创始人处在那个阶段，所以他们是伟大的；信徒处在今天还死守旧观点，所以是反动的。**

**（3）第三种错位"跳过"的定位要准确：空想社会主义不是"太超前"，**而是"没有物质条件的超前"**。马克思在同一个判据下既批评了向后看（反动）、又批评了停住（保守）、又批评了跳过（空想）——**三种错位，一个标准：是否与现实的物质运动同步。**

### 抓手句（3.3）
> 这种对未来社会的幻想的描绘，是在无产阶级还很不发展、因而对本身的地位的认识还基于幻想的时候，同无产阶级对社会普遍改造的最初的本能的渴望相适应的。

> 批判的空想的社会主义和共产主义的意义，是同历史的发展成反比。

> 虽然这些体系的创始人在许多方面是革命的，但是他们的信徒总是组成一些反动的宗派。

---

## 第三章为什么存在（一句话）

**因为一个纲领，光说"我要什么"不够，还必须说"我跟你以为的那帮人不一样"。** 少了这一章，读者就会把拉萨尔、蒲鲁东、德国真正的社会主义者、甚至是空想社会主义者当成同类，到时候"社会主义"这个词会被他们占走。

# 【4】共产党人对各种反对党派的态度

**整章任务**：把一切都落到"今天在你的国家，具体该怎么办"。
**整章写法**：**由具体到抽象，最后保守地收束到口号。** 最短的一章，但不能删。

---

## 4.1—4.4 四个国家（四国策略表）

| 国家 | 联合谁 | 保留什么（批判/清醒） |
|---|---|---|
| **法国** | 同**社会主义民主党**联合起来，反对保守的和激进的资产阶级 | **不放弃**对那些从革命传统中承袭下来的**空谈和幻想**采取批判态度的权利 |
| **瑞士** | 支持**激进派** | **不忽略**这个政党是由互相矛盾的分子组成的（一部分是法国式的民主社会主义者，一部分是激进的资产者） |
| **波兰** | 支持那个**把土地革命当做民族解放的条件**的政党（1846 年克拉科夫起义的政党） | —— |
| **德国** | 只要资产阶级采取革命的行动，共产党就同它一起去反对**专制君主制、封建土地所有制和小市民的反动性** | **共产党一分钟也不忽略教育工人尽可能明确地意识到资产阶级和无产阶级的敌对**；以便在推翻德国的反动阶级之后**立即开始反对资产阶级本身的斗争** |

### 四国的共同句式：支持 ＋ 但是（不放弃批判）
**这是本章的方法论骨架：**
> **"联合，但绝不融化。"**

每一条策略都用了同一个结构：**前半句说"跟谁一起斗争"，后半句说"但不要忘了我们最终要对谁斗争"。** 这个句式是"原则和策略"这对关系的最简洁的表达，也直接呼应 2.1 那句"始终代表整个运动的利益"。

### 4.4 德国为什么是重点（单独拎出来）
```
德国正处在资产阶级革命的前夜
       ↓
同 17 世纪的英国和 18 世纪的法国相比，德国将在整个欧洲文明更进步的条件下，
拥有发展得多的无产阶级去实现这个变革
       ↓
因而德国的资产阶级革命只能是无产阶级革命的直接序幕
```
**这就是后来被称为"不断革命"思想的雏形。** 它的推理很硬：革命的领导者取决于当时当地无产阶级的成熟程度；德国比英法晚起步，所以德国革命时无产阶级更成熟；所以德国的资产阶级革命不会停在资产阶级革命上。

---

## 4.5 三条总则（从具体国家里抽出普遍原则）

```
原则①  共产党人到处都支持一切反对现存的社会制度和政治制度的革命运动
原则②  在所有这些运动中，他们都特别强调所有制问题，把它作为运动的基本问题，
        不管这个问题当时的发展程度怎样
原则③  共产党人到处都努力争取全世界的民主政党之间的团结和协调
```

**这三条是从四国具体策略里抽象出来的，务必连起来背。** 其中原则②"所有制问题是基本问题"**呼应了恩格斯在 1890 年序言重申的那句"《共产党宣言》的任务，是宣告现代资产阶级所有制必然灭亡"**——首尾贯通。

---

## 4.6 收尾：最后两句

```
【态度】  共产党人不屑于隐瞒自己的观点和意图。他们公开宣布：
          他们的目的只有用暴力推翻全部现存的社会制度才能达到
【第一层：警告统治者】让统治阶级在共产主义革命面前发抖吧
【第二层：动员无产者】无产者在这个革命中失去的只是锁链。他们获得的将是整个世界
【口号】  全世界无产者，联合起来！
```

### 逻辑要害
**"不屑于隐瞒"三个字是回到引言的闭合：** 引言里说"现在到了公开说明自己观点的时候了"，结尾说"我们不屑于隐瞒"——**承诺兑现了。** 这份文件从"被围剿的幽灵"开始，到"公开的宣战"结束。

**"锁链 / 世界"这个对偶是全书最强的修辞收束：**
```
失去的 ──► 锁链      （极小，而且是本来就不该有的东西）
获得的 ──► 整个世界  （极大）
```
**用最小的损失换最大的所得，比例悬殊到荒谬。** 而且这个比喻本身是从第一章来的：工人的处境被描述为"像士兵一样被组织起来"的奴役、被机器奴役——**锁链不是修辞夸张，是第一张说的那个结构。**

**最后六个字是整个《宣言》被传播最广的部分——它是《宣言》的记忆抓手。** 在《宣言》的逻辑里，它也不是空喊：**回到 1.9 的"斗争的真正成果并不是直接取得实际利益，而是工人的越来越大的团结"、2.11 的"联合的行动……是无产阶级获得解放的首要条件之一"。** **"联合"是全书的落点，不是情绪。**

### 抓手句（结尾四句，连背）
> 共产党人不屑于隐瞒自己的观点和意图。

> 他们的目的只有用暴力推翻全部现存的社会制度才能达到。

> 无产者在这个革命中失去的只是锁链。他们获得的将是整个世界。

> **全世界无产者，联合起来！**
