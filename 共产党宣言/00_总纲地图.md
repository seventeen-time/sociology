## 一、一句话概括全书

> 《宣言》不是一本控诉资本主义有多坏的书，而是一份**判决书**：它用资本主义自己创造出来的生产力作为唯一尺度，宣判资产阶级所有制必然灭亡；并指出执行这一判决的人，正是资本主义自己生产出来的无产阶级。

恩格斯在 1890 年德文版序言里重引的那句话，是全书的定盘星：

> **"《共产主义宣言》的任务，是宣告现代资产阶级所有制必然灭亡。"**

注意关键词是**宣告**（declaration），不是"论证要不要"或"设计以后怎么生活"。《宣言》要解决的是**"为什么必然"** 和 **"因此现在做什么"**，不是"未来社会长什么样"。

## 二、全书一句话骨架（这就是最小版的背诵稿）

如果把两万五千字压成一句，顺着读下来就是——

> **因为** 一切社会的历史都是阶级斗争的历史（1.1）；
> **而** 资产阶级时代把阶级对立简化成了资产者与无产者两大阵营（1.1）；
> **而** 资产阶级自己造成的生产力，已经大到它的所有制装不下了，危机反复发作（1.6）；
> **于是** 资产阶级锻造了置自己于死地的武器，并且生产了拿这个武器的人——无产阶级（1.7）；
> **于是** 资产阶级的生存基础被从脚下挖掉，它首先生产的是它自身的掘墓人（1.14）；
> **所以** 共产党人的理论可以概括为一句话：**消灭私有制**（2.2）；
> **并且** 一切反对这个结论的责难，都不过是资产阶级利益的意识形态外衣（2.3—2.12）；
> **因此** 无产阶级必须上升为统治阶级，把生产工具集中到自己手里，尽快增加生产力总量（2.13）；
> **直到** 阶级差别消失时，国家作为阶级压迫的工具也就消失，代之以**每个人的自由发展是一切人的自由发展的条件**的联合体（2.14）；
> **但** 在这之前必须先分清谁是朋友、谁是被误导的同路人、谁是敌人（3）；
> **所以** 今天就到处支持一切革命运动，且在所有运动中始终把所有制问题作为基本问题（4.5）；
> **最终**——失去的只是锁链，获得的将是整个世界；**全世界无产者，联合起来！**（4.6）

**练法**：先把上面这一段读顺。它每一句对应原文的一个节点编号，你是带着门牌号进城的，不会迷路。

## 三、作者自述的三条"钥匙"（最强一手依据）

研究《宣言》为什么这样写，不能靠猜。马克思恩格斯自己在再版序言里说过三次。

### 钥匙一：贯穿全书的基本思想（恩格斯 1883 年德文版序言）

> "**贯穿《宣言》的基本思想**：每一历史时代的经济生产以及必然由此产生的社会结构，是该时代政治的和精神的历史的基础；因此（从原始土地公有制解体以来）全部历史都是阶级斗争的历史……而这个斗争现在已经达到这样一个阶段，即被剥削被压迫的阶级（无产阶级），如果不同时使整个社会永远摆脱剥削、压迫和阶级斗争，就不再能使自己从剥削它压迫它的那个阶级（资产阶级）下解放出来，——**这个基本思想完全是属于马克思一个人的**。"

这段话是**《宣言》论证逻辑的官方三层浓缩**，它和本文拆出的结构一一对应：

| 恩格斯概括的三层 | 对应《宣言》节点 | 作用 |
|---|---|---|
| ① 经济生产和社会结构 → 是政治史、精神史的**基础** | `1.1`—`1.14`（唯物史观的展开） | **公理** |
| ② 因此全部历史是**阶级斗争**的历史 | `1.1`、`1.9` | **定理** |
| ③ 无产阶级不同时解放全社会就不能解放自己 | `1.12`、`2.14` | **结论** |

**记住这张表，你脑子里就有了一个三格的抽屉。** 遇到任何一段，问自己：这段属于哪一层？90% 的段落会立刻归位。

### 钥匙二：它不是书，是党纲（恩格斯 1888 年英文版序言）

> 《宣言》是"作为**共产主义者同盟的纲领**发表的……1847 年 11 月在伦敦举行的同盟代表大会，**委托马克思和恩格斯起草一个准备公布的完备的理论和实践的党纲**。"

**"理论和**实践**的党纲"**——这五个字决定了第四章为什么存在。如果只是理论著作，写到第二章结尾的"自由人联合体"就够了。正因为它是**行动纲领**，才必须回答"今天在法国、瑞士、波兰、德国分别做什么"。所以第四章虽然最短，却不能删。

### 钥匙三：十条措施是可以改的（马恩 1872 年德文版序言）

> "不管最近 25 年来的情况发生了多大的变化，这个《宣言》中所阐述的**一般原理**整个说来直到现在还是完全正确的。某些地方本来可以作一些修改。这些原理的**实际运用，随时随地都要以当时的历史条件为转移**，所以**第二章末尾提出的那些革命措施根本没有特别的意义**。如果是在今天，这一段在许多方面都会有不同的写法了。"

这条极重要，它划定了《宣言》内部**哪部分是"原理"、哪部分是"处方"**：

- **原理**（不可动摇）：生产力—生产关系的矛盾运动、阶级斗争、两个必然性
- **处方**（随历史条件变）：第二章末尾那十条措施

**背诵时的直接结论**：十条措施要理解其逻辑归类，不必逐字死磕——连作者自己都说要改。而它的**引出语**（"这些措施在不同的国家里当然会不同"）才是原理部分，必须背。

## 四、四章的角色：WHY → WHAT → WHO → HOW

这是理解全书顺序的一把总钥匙。四章不是平铺的四个话题，而是**四个递进的问句**：

```
引言   ┃ 凭什么要出这份文件？  ┃ 合法性论证 ┃ 从"敌人承认我们有力量"切入
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第一章 ┃ WHY 必然？            ┃ 规律       ┃ 历史 + 经济 + 阶级分析
第二章 ┃ WHAT 我们主张什么？   ┃ 纲领+答辩  ┃ 正面主张 + 六组反驳
第三章 ┃ WHO 我们不是谁？      ┃ 划界       ┃ 给社会主义文献分类定位
第四章 ┃ HOW 现在怎么做？      ┃ 策略       ┃ 国别策略 + 三条总则
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
结尾   ┃ 召唤                  ┃ 记忆锚点   ┃ 锁链 / 世界 / 联合起来
```

**为什么这个顺序不能变**（详见 `02` 文档）：

- 不先解决 WHY，WHAT 就是空喊口号；
- 不先亮出 WHAT，WHO（划界）就没有参照物——你没法说"我跟张三不同"，除非你先说清"我是什么"；
- 不先划清 WHO，HOW（策略）里的"联合谁、批判谁"就无从判断；
- 没有 HOW，前面全是书斋里的清谈，不成其为党纲。

## 五、全书结构全景树（带全局编号）

```
【引言】幽灵与合法性
  └ 事实：旧欧洲一切势力联合围剿
  └ 反诘：有哪一个反对党不被骂为共产党？
  └ ↳ 结论①：共产主义已被公认为一种势力   ← 反转：把"被围剿"读作"被承认"
  └ ↳ 结论②：该公开说明自己的观点了       ← 由此获得发言资格
  └ 行动：伦敦集会 → 拟定宣言 → 六国文字公布

【1】资产者和无产者                                    论证核心规律
  1.1   总前提：至今一切社会的历史都是阶级斗争的历史
  1.2   资产阶级的生成史（农奴→市民→资产者；市场→工场手工业→大工业）
  1.3   资产阶级的政治进程（被压迫阶级→公社→共和国→第三等级→独占统治）
  1.4   资产阶级的革命作用（十段"它……了"）
  1.5   第一次"由此可见"：封建制为何灭亡（生产力 vs 生产关系模板第一次出现）
  1.6   资产阶级自身的危机：魔法师唤出了自己支配不了的魔鬼
  1.7   两个转折句：武器对准了自己 / 造就了使用武器的人
  1.8   无产阶级的处境（商品化、机器附属、工资=最低生活资料）
  1.9   无产阶级斗争的五个递进阶段（捣毁机器→地方性→全国性→政治斗争）
  1.10  促成无产阶级发展的三个来源
  1.11  阶级鉴定：谁才是真正革命的阶级（中间等级 / 流氓无产阶级）
  1.12  无产阶级为什么必须摧毁一切（过去运动是少数人的，这次是绝大多数人的）
  1.13  为什么资产阶级再也不能统治下去（劳动者落到连奴隶般生存都保不住）
  1.14  结论：它首先生产的是它自身的掘墓人 → 两个不可避免

【2】无产者和共产党人                                  主张 + 答辩
  2.1   党的定位（六条：不是特殊政党/无不同利益/不提特殊原则/…）
  2.2   核心命题：共产党人的理论可以概括为一句话——消灭私有制
  2.3   反驳①：你们要消灭个人挣得的财产吗？
  2.4   └ 资本是集体产物，不是个人力量
  2.5   └ 雇佣劳动的平均价格 = 最低限度的工资
  2.6   反驳②：你们要消灭个性与自由吗？（定义权争夺）
  2.7   反驳③：私有制一消灭，懒惰之风就会兴起？（归谬）
  2.8   反驳④：你们要消灭教育吗？
  2.9   反驳⑤：你们要消灭家庭吗？
  2.10  反驳⑥：你们要实行公妻制吗？
  2.11  反驳⑦：你们要取消祖国、取消民族吗？
  2.12  反驳⑧：宗教、哲学、一般意识形态的责难（意识形态总根源）
  2.13  行动纲领：上升为统治阶级 → 十条措施
  2.14  终点：自由人联合体

【3】社会主义和共产主义的文献                          划界（分类矩阵）
  3.1   反动的社会主义      （甲）封建的 /（乙）小资产阶级的 /（丙）德国的"真正的"
  3.2   保守的或资产阶级的社会主义（蒲鲁东）
  3.3   批判的空想的社会主义和共产主义（圣西门、傅立叶、欧文）
  3.0′  统一判据：向哪个方向错位（倒退/停住/跳步）+ 代表哪个阶级的利益

【4】共产党人对各种反对党派的态度                      策略
  4.1   法国：同社会主义民主党联合，但保留批判的权利
  4.2   瑞士：支持激进派，但不忽略其成分复杂
  4.3   波兰：支持把土地革命当作民族解放条件的政党
  4.4   德国：同资产阶级一起反专制，但一分钟也不忽略教育工人
  4.5   三条总则（支持一切革命运动 / 强调所有制 / 争取国际团结）
  4.6   收尾：暴力推翻 → 锁链与世界 → 全世界无产者，联合起来
```

## 六、贯穿全书的三条"暗线"

背到中后段容易断，往往是因为只记住了段落，没抓住那几条从头串到尾的线。全书其实只有三条主线在反复出现：

### 暗线 A：**生产力 vs 生产关系**（经济引擎）
出场 4 次，一次比一次推进：
1. `1.5` 封建所有制 → 桎梏 → 被打破（讲别人的灭亡）
2. `1.6` 资产阶级关系"已经太狭窄了，再容纳不了它本身所创造的财富"（讲你的灭亡）
3. `2.13` 夺取资本后"尽可能快地增加生产力的总量"（讲我们怎么办）
4. `2.14` 全部生产集中在联合起来的个人手里 → 阶级消失（讲终点）

> **一句话记住它**：封建制是被资本主义炸开的，资本主义将被它自己的生产力炸开。

### 暗线 B：**利益 vs 意识形态**（观念都是产品的争论）
出场 3 次：
1. `1.3` "现代的国家政权只不过是管理整个资产阶级的共同事务的一个委员会"
2. `2.12` "任何一个时代的统治思想始终都不过是统治阶级的思想" / "你们的观念本身是资产阶级的生产关系和所有制关系的产物"
3. `3` 整章：所有社会主义文献，都要按"它代表哪个阶级的利益"来还原

### 暗线 C：**物质 → 意识 / 切身 → 抽象**（表达顺序）
这是第二章反驳的排列原则：从**财产**（最切身）→ **个性自由** → **教育** → **家庭** → **公妻** → **祖国民族** → **一般意识形态**（最抽象）。第二章的六个反驳不是随便排的，是**从柴米油盐排到哲学**。这条线同时也是唯物主义的**自我演示**——用物质先于意识的顺序，来讲述物质先于意识的道理。

## 七、开头的"幽灵"和结尾的"发抖"是一回事

首尾必须对照着背，因为它是刻意的闭合：

| | 引言 | 结尾 |
|---|---|---|
| 主语 | 共产主义是一个**幽灵**（飘忽、被敌人命名） | 共产党人**公开宣布**目的（实体、自我命名） |
| 敌人 | 一切旧势力**联合围剿**幽灵 | 让统治阶级在共产主义革命面前**发抖** |
| 我们 | 需要公开说明、拿出宣言 | 失去的只是锁链，获得的将是整个世界 |

**中间发生了什么？** 第一章到第四章把"幽灵"变成了"物质力量"：一个被谣传的东西，经 `1` 论证为历史必然、经 `2` 落实为纲领、经 `3` 划清了边界、经 `4` 变成了可以执行的策略——于是它不再是飘忽的幽灵，而是一支已经排好了阵位的力量。**从谣言到判决书，就是《宣言》的运动轨迹。**
