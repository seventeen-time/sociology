## 三条贯穿全书的钥匙（先记住这些，再去读别的）

1. **WHY → WHAT → WHO → HOW**：引言解决"凭什么"，第一章解决"为什么必然"，第二章解决"主张什么+如何答辩"，第三章解决"我们不是谁"，第四章解决"现在怎么做"。
2. **恩格斯 1883 年序言概括的三层基本思想**：经济生产是基础 → 全部历史是阶级斗争史 → 无产阶级不同时解放全社会就不能解放自己。（这一层与 `01` 的 `1.1`／`1.9`／`1.12`／`2.14` 一一对应）
3. **作者自述的任务定位**："《共产主义宣言》的任务，是宣告现代资产阶级所有制必然灭亡。"（1882 年俄文版序言，1890 年德文版重申）
