# 引子：这本书背起来有什么不一样？

《国家与革命》和《共产党宣言》的背诵难度不同：

| | 《共产党宣言》 | 《国家与革命》 |
|---|---|---|
| 记忆线索 | 排比、口号多，节奏强 | **配对结构**多，逻辑强 |
| 主要抓手 | 金句 | **命题对子** |
| 难点 | 十段排比顺序 | 第五章的"民主三形态"、四个"消亡"阶段 |

**所以这本书的背诵钥匙是：记住配对。**

全书最重要的配对只有五组，任何一组记住了一半，另一半会自动出来：

```
① 打碎（资产阶级国家）  ↔  消亡（无产阶级国家）
② 少数镇压多数（资本主义）↔  多数镇压少数（过渡时期）
③ 量（每一项民主措施）  ↔  质（国家不再是国家）
④ 目的（都主张废除国家）↔  手段（是否暂时利用国家）
⑤ 资产阶级权利还在     ↔  资产阶级已经没有
```

> **练法建议**：这本书更适合**先背命题、再背原文**（和《宣言》相反）。因为它是一本论证性著作，不是宣言体。

# L0｜五字钥匙（全书方向感）

## 五字：**定 · 碎 · 替 · 亡 · 清**

```
定   第一章   国家是什么？
碎   第二章   怎么对待它（上）：必须打碎
替   第三章   怎么对待它（下）：用什么代替
亡   第四章   新国家是什么性质（已不是原来意义上的国家）
     第五章   它为什么终将消亡
清   第六章   谁在歪曲
```

**连成一句话（第一行熟）：**
> **"定碎替亡清"** —— 或者更好记的说法：
> **"先说清国家是什么，再证明必须打碎它，然后给出替代物，接着说明替代物为什么会消亡，最后清算那些歪曲者。"**

## 一句话流：把全书讲成一个故事（通背时的导航）

> 先**下定义**：国家是阶级矛盾不可调和的产物 → 它是**特殊的武装队伍**，是**剥削的工具** → 于是得出：资产阶级国家**只能被暴力革命消灭**，无产阶级国家才会**自行消亡** → 马克思从 1848—51 年法国百年革命中看出：**过去一切革命都在使机器完备，所以必须打碎** → 并且**承认专政**才是真马克思主义 → 1871 年**巴黎公社**终于给出了替代物：**武装的人民、可撤换的公仆、工人工资、实干的机构** → 推到极致就**量转化为质**：镇压者从少数变多数，国家就不再是国家 → 恩格斯补充说它**已不是原来意义上的国家**，而**民主共和国是捷径**、要**防止公仆变主人** → **国家消亡＝民主消亡** → 而这最终靠**经济基础**：过渡时期是专政，第一阶段还保留**资产阶级权利**（所以还有"没有资产阶级的资产阶级国家"），到**各尽所能按需分配**才完全消亡 → 最后**清算**普列汉诺夫的回避和考茨基的抹杀，给出与无政府主义的**三条区别**，以**决裂**收尾。

**练法**：先念熟这一长句。**背书最大的恐惧是不知道下一句是什么，而不是忘了这一句。**

## 【序】〔补，你的笔记未收录〕
> **触发句**：国家这个问题，无论在理论方面、或在实际政治方面，现在都有特别重大的意义。
> **中间**：帝国主义战争加速垄断资本主义变为国家垄断资本主义 → 先进各国变成工人的军事苦役监狱 → 机会主义在各国社会党内占统治
> **落点句**：**首先**研究马恩的国家学说（特别是被忘记/被曲解的部分）；**其次**研究曲解的主要代表考茨基；**最后**总结俄国 1905、1917 年革命经验。

## 【1】阶级社会和国家

### 1.1 国家是阶级矛盾不可调和的产物
- **触发句**：国家是承认：这个社会陷入了不可解决的自我矛盾，分裂为不可调和的对立面而又无力摆脱这些对立面。
- **中间**：需要一种表面上凌驾于社会之上的力量缓和冲突 → 这种从社会中产生又自居于社会之上并日益同社会相异化的力量，就是国家
- **落点句**：**国家是阶级矛盾不可调和的产物和表现……反过来说，国家的存在证明阶级矛盾不可调和。**
- **必带的一句**：被压迫阶级要求得解放，不仅非进行暴力革命不可，而且非消灭……国家政权机构不可。

> 🧠 **记法**：这一节是"定义 + 立刻打人"。**定义三句、歪曲两种**，记住这个 3-2 结构。

### 1.2 特殊的武装队伍、监狱等等
- **触发句**：这种力量主要是什么呢？
- **落点句**：**主要是拥有监狱等等的特殊的武装队伍。**
- **关键反证**：如果没有阶级分裂，"居民的自动的武装组织"是可能的；**之所以不可能，是因为文明社会已分裂为敌对的而且是不可调和地敌对的阶级。**
- **物质支撑**：为了维持特殊的、凌驾于社会之上的公共权力，就需要**捐税和国债**。

### 1.3 国家是剥削被压迫阶级的工具
- **触发句**：由于国家是从控制阶级对立的需要中产生的……
- **落点句**：**民主共和制是资本主义所能采用的最好的政治外壳**，所以资本一掌握这个最好的外壳，就能十分巩固十分可靠地确立自己的权力。
- **普选制那句**：普选制是**测量工人阶级成熟性的标尺**。在现今的国家里，普选制不能而且永远不会提供更多的东西。

### 1.4 国家"自行消亡"和暴力革命（**全书发动机，五点必背**）
- **触发句**：国家不是"被废除"的，它是自行消亡的。（然后列宁说：这句被削剪成了机会主义）
- **五点口诀**：**谁消亡 / 什么性质 / 什么时候 / 反谁 / 暴力**
  ```
  第一：资产阶级国家被消灭；消亡的是无产阶级国家（半国家）
  第二：国家是"特殊的镇压力量"——另一种特殊力量代替它，决不能靠自行消亡
  第三：消亡指社会主义革命以后；而且消亡的是民主（最完全的民主）
  第四：既反机会主义又反无政府主义，且首位是反机会主义——但反机会主义那半被"忘记了"
  第五：同一本著作里还有对暴力革命的颂扬——两者联成一个严密整体
  ```
- **落点句（必背，全书最重要的两句之一）**：
  > **无产阶级国家代替资产阶级国家，非通过暴力革命不可。无产阶级国家的消灭，即任何国家的消灭，只能通过"自行消亡"。**
- **附**：资产阶级的国家只有革命才能"消灭"。国家本身，就是说最完全的民主，只能"自行消亡"。

> 🧠 **记法**：把五点压成五个字——**谁 / 质 / 时 / 敌 / 暴**。

## 【2】1848—1851 年的经验

### 2.1 革命的前夜
- **触发句**：工人阶级在发展进程中将创造一个消除阶级和阶级对抗的联合体来代替旧的资产阶级社会。
- **落点句**：**国家即组织成为统治阶级的无产阶级。**（加上限定：无产阶级所需要的只是**逐渐消亡的国家**，即组织得能**立刻开始消亡而且不能不消亡**的国家）

### 2.2 革命的总结
- **触发句**：一切变革都是使这个机器更加完备，而不是把它摧毁。
- **落点句**：**过去一切革命都是使国家机器更加完备，而这个机器是必须打碎，必须摧毁的。**
- **方法论那句**：马克思这样提出任务，**不是根据逻辑的推论，而是根据事变的实际发展**。
- **留下的悬念**：1852 年还只能说"**集中自己的一切破坏力量**"来反对国家政权，即"摧毁"的任务。

### 2.3 1852 年马克思对问题的提法 ★第二版增补
- **触发句**：至于讲到我，无论是发现现代社会中有阶级存在或发现各阶级间的斗争，都不是我的功劳。
- **中间三点**：(1) 阶级的存在仅仅同生产发展的一定历史阶段相联系；(2) **阶级斗争必然导致无产阶级专政**；(3) 这个专政不过是达到消灭一切阶级和进入无阶级社会的过渡。
- **落点句（试金石，必背）**：**只有承认阶级斗争、同时也承认无产阶级专政的人，才是马克思主义者。**
- **形式推论**：资产阶级国家形式多样，本质都是资产阶级专政；过渡时期政治形式丰富多样，本质都是**无产阶级专政**。

### 2.4 寄生物与帝国主义
- **触发句**：最能表明这个国家机器特征的有两种机构，即**官吏和常备军**。
- **落点句**：**官吏和常备军是资产阶级社会身上的"寄生物"**，是使这个社会分裂的内部矛盾所产生的寄生物，而且正是"阻塞"生命的毛孔的寄生物。
- **接到当代**：帝国主义使国家机器大大强化 → 全世界历史正在把无产阶级革命引向"破坏"国家机器
- **最终任务句**：**不是去改善国家机器，而是破坏它、消灭它。**

## 【3】1871 年巴黎公社的经验

### 3.1 公社社员的英雄主义何在
- **触发句**：马克思并没有固执己见，学究式地非难运动"不合时宜"。（对比普列汉诺夫："本来就用不着拿起武器"）
- **落点句**：**"把官僚军事国家机器打碎"这几个字，已经简要地表明了马克思主义关于无产阶级在革命中在对待国家方面的任务问题的主要教训。**

### 3.2 用什么东西来代替被打碎的国家机器（**本章核心**）
- **四项措施口诀**：**军 / 选 / 薪 / 教**
  ```
  ① 废除常备军而代之以武装的人民（第一个法令）
  ② 一切公职人员由选举产生、对选民负责、随时可以撤换
  ③ 警察和一切行政官员同样处理（免除政治职能）
  ④ 一切公职人员只领取相当于工人工资的报酬，取消一切特权与津贴
  ```
- **落点句（必背）**：**民主实行到一般所能想象的最完全最彻底的程度，就由资产阶级民主转化成无产阶级民主，即由国家转化成一种已经不是原来意义上的国家的东西。**（这就是"量转化为质"）
- **理由句**：**既然是人民这个大多数自己镇压他们的压迫者，实行镇压的"特殊力量"也就不需要了！**
- **被忘得最干净的一条**：**把报酬减到"工人工资"的水平**（"原始民主"的回归）
- **廉价政府**：公社取消了两个最大的开支项目，即**军队和国家官吏**。

### 3.3 取消议会制
- **触发句**：公社是一个**实干的而不是议会式的**机构，它既是行政机关，同时也是立法机关。
- **议会制的本质**：每隔几年决定一次由统治阶级中什么人在议会里**镇压人民、压迫人民**。
- **落点句**：**摆脱议会制的出路，当然不在于取消代表机构和选举制，而在于把代表机构由清谈馆变为"实干的"机构。**
- **分寸句**：没有代表机构，我们不可能想象什么民主，即使是无产阶级民主；**而没有议会制，我们却能够想象和应该想象**。

### 3.4 组织起民族的统一
- **触发句**：民族的统一不是应该破坏，相反地应该借助于公社制度组织起来。
- **落点句**：**旧政府权力的纯属压迫性质的机关予以铲除，而旧政府权力的合理职能则……归还给社会的负责的公仆。**
- **集中制那句**：**自愿的、民主的、无产阶级的集中制** vs 资产阶级的、军阀的、官吏的集中制。
- **方法论**：马克思特意使用"组织起民族的统一"这样的说法，是为了提出自觉的、民主的、无产阶级的集中制来同后者对立。

### 3.5 消灭寄生虫式的国家
- **触发句**：公社实现了所有资产阶级革命都提出的**廉价政府**这一口号。
- **不是空想**：我们并不"幻想"一下子就可以不要任何管理，不要任何服从。
- **落点句**：**国家官吏的特殊"长官职能"可以并且应该立即开始、在一天之内就开始用"监工和会计"的简单职能来代替。**
- **前景**：日益简化的监督职能将由**所有的人轮流行使**，然后将成为一种**习惯**，最后就不再成其为特殊阶层的特殊职能了。

### 3.6 公社是"终于发现的"政治形式
- **落点句（必背）**：**公社的真正秘密就在于：它实质上是工人阶级的政府……是终于发现的可以使劳动在经济上获得解放的政治形式。**
- **方法**：马克思**并没有去发现**这个未来的政治形式，他只是对法国历史作了精确的观察。
- **接到俄国**：俄国 1905 年和 1917 年革命在另一个环境和另一种条件下**继续着公社的事业**。

## 【4】恩格斯的补充说明

### 4.1 《住宅问题》
- **落点句**：这一切都需要有一定的国家形式，**但决不需要那种公职人员享有特权地位的特殊的军事和官僚机构**。
- **消亡条件**：至于过渡到免费分配住宅，那是与国家的**完全"消亡"**联系着的。

### 4.2 同无政府主义者的论战（**最需要精确记忆的一节**）
- **共同点**：在废除国家是目的这个问题上，我们和无政府主义者**完全没有分歧**。
- **分歧点**：为了达到这个目的，就必须**暂时**利用国家权力的工具、手段、方法去反对剥削者。
- **恩格斯的两条**：
  ```
  ① 权威和自治都是相对的概念，应用范围随社会发展阶段而改变
  ② "只要改变一下某一事物的名称，就可以改变这一事物本身"（讽刺反权威主义者）
  ```
- **落点句（必背）**：**革命无疑是天下最权威的东西。** 革命就是一部分人用枪杆、刺刀、大炮，即用非常权威的手段强迫另一部分人接受自己的意志。
- **反问句**：要是巴黎公社面对资产者**没有运用武装人民这个权威，它能支持哪怕一天吗**？反过来说，难道我们没有理由责备公社把这个权威用得太少了吗？

### 4.3 给倍倍尔的信
- **落点句（必背）**：**"巴黎公社已经不是原来意义上的国家"，——这是恩格斯在理论上最重要的论断。**
- **配套金句**：当无产阶级还需要国家的时候，它需要国家**不是为了自由，而是为了镇压自己的敌人**，一到有可能谈自由的时候，国家本身就不再存在了。
- **消亡机制**：国家机构将**无事可做而逐渐失去其作用**。

### 4.4 对爱尔福特纲领草案的批判
- **落点句**：**民主共和国是走向无产阶级专政的捷径。**（因为斗争会扩大、展开、明朗化和尖锐化）
- **集中制 vs 联邦制**：**真正民主的集中制共和国赋予的自由比联邦制共和国要多。**
- **方法句**：弄清各该场合的过渡形式是**从什么到什么的过渡**。
- **附**："'真诚的'机会主义也许比其他一切机会主义更危险。"

### 4.5 1891 年为《内战》写的导言
- **落点句（必背，两个办法）**：为了防止国家和国家机关**由社会公仆变为社会主人**——公社采取了**两个可靠的办法**：**第一**……普选选出的人担任，选举者可以随时撤换被选举者；**第二**……不论职位高低，都只付给跟其他工人同样的工资。
- **界限句**：在这个界限上，**彻底的民主变成了社会主义**，同时也要求实行社会主义。
- **防止诡辩**："一个人掉了一根头发，他是否就成了秃子呢？"
- **辩证句**：任何单独存在的民主制度都不会产生社会主义，但民主制度永远不会是"单独存在"，而总是"共同存在"的……这就是**活生生的历史辩证法**。

### 4.6 恩格斯论民主制的消除（**最反直觉的一节**）
- **触发句**：老是忘记**国家的消灭也就是民主的消灭，国家的消亡也就是民主的消亡**。
- **精确区分（必背）**：**民主和少数服从多数的原则不是一个东西。民主就是承认少数服从多数的国家**，即一个阶级对另一个阶级、一部分居民对另一部分居民使用有系统的暴力的组织。
- **澄清**：我们并不期待一个不遵守少数服从多数原则的社会制度。
- **消亡机制**：人们将习惯于遵守公共生活的起码规则，而**不需要暴力，不需要强制，不需要服从**。
- **对国家迷信**：国家再好也不过是……获胜的无产阶级所继承下来的**一个祸害**。

### 4.7 迷信与党的名称 〔补〕
- **落点句**：对真正的政党说来，名称总是不完全符合的；**党在发展，名称却不变**。
- **拉回主线**：但是党的名称问题**远不及**革命无产阶级对国家的态度问题重要。

## 【5】国家消亡的经济基础（**最难，但结构最清楚**）

### 5.1 马克思如何提出问题
- **落点句（必背）**：同这个时期相适应的也有一个政治上的过渡时期，这个时期的国家**只能是无产阶级的革命专政**。
- **专政 ≠ 只扩大民主**：无产阶级专政……**不能仅仅只是扩大民主**。除了把民主制度大规模地扩大……还要对压迫者、剥削者、资本家采取一系列剥夺自由的措施。

### 5.2 民主三形态（**全章骨架，务必成对背**）
- **形态一（资本主义）**：**极少数人享受民主，富人享受民主**，——这就是资本主义社会的民主制度。
  - 马克思的概括：容许被压迫者每隔几年决定一次究竟由压迫阶级中什么人在议会里**代表和镇压他们**！
- **形态二（过渡时期）**：**人民这个大多数享有民主，对人民的剥削者、压迫者实行强力镇压**，即把他们排斥于民主之外。
  - 关键对比：**多数镇压少数** → 很容易、很简单、很自然、流血少得多、几乎不需要特殊机器
- **形态三（共产主义）**：只有共产主义才能提供真正完全的民主，而**民主愈完全，它也就愈迅速地成为不需要的东西，愈迅速地自行消亡**。
- **"消亡"这个词**：既表明了过程的**渐进性**，又表明了过程的**自发性**。

> 🧠 **记法**：三形态 = **少数人民主 → 多数人民主+镇压少数 → 完全民主然后消亡**。注意第二形态里的"多数 vs 少数"翻转。

### 5.3 共产主义社会的第一阶段（**悖论句所在地**）
- **触发句**：它在各方面，在经济、道德和精神方面都还**带着它脱胎出来的那个旧社会的痕迹**。
- **分配**：每个劳动者从社会领回的正好是他给予社会的（**扣除了社会基金之后**）。
- **资产阶级权利**：这里确实有"平等的权利"，但这仍然是"**资产阶级权利**"，这个"资产阶级权利"同任何权利一样，**是以不平等为前提的**。
- **为什么不可避免**：**权利决不能超出社会的经济结构以及由经济结构制约的社会的文化发展。**
- **两个原则**："**不劳动者不得食**"已实现；"**对等量劳动给予等量产品**"已实现——但这还不是共产主义。
- **落点句（必背，三句递进）**：
  > 国家**正在消亡**，因为资本家已经没有了，阶级已经没有了……
  > **但是，国家还没有完全消亡**，因为还要保卫那个确认事实上的不平等的"资产阶级权利"。
  > **要使国家完全消亡，必须有完全的共产主义。**
- **悖论句（必背）**：**在共产主义下，在一定的时期内，不仅会保留资产阶级权利，甚至还会保留资产阶级国家，——但没有资产阶级！**

### 5.4 共产主义社会的高级阶段
- **三个"在……之后"（必背，按序）**：
  ```
  ① 迫使个人奴隶般地服从分工的情形已经消失 → 脑力劳动和体力劳动的对立消失
  ② 劳动已经不仅仅是谋生的手段，而且本身成了生活的第一需要
  ③ 生产力增长起来，集体财富的一切源泉都充分涌流
  ```
- **落点句（必背）**：只有在那个时候，才能完全超出资产阶级权利的狭隘眼界，社会才能在自己的旗帜上写上：**"各尽所能，按需分配"**！
- **经济基础句**：**国家完全消亡的经济基础就是共产主义的高度发展。**
- **方法论**：我们只能谈国家消亡的**必然性**……而把消亡的日期或消亡的具体形式问题**作为悬案**。
- **自由与国家**：**还有国家的时候就没有自由。到有自由的时候就不会有国家了。**

### 5.5 计算和监督
- **落点句**：**计算和监督**，——这就是把共产主义社会第一阶段"调整好"，使它能正常地运转所必需的主要条件。
- **资本主义准备好的前提**：人人识字；千百万工人在邮局、铁路、大工厂等机构里**受了训练并养成了遵守纪律的习惯**。
- **工厂纪律（带限定）**：整个社会将成为一个管理处，成为一个**劳动平等和报酬平等的工厂**。但是……这种"工厂"纪律，**决不是我们的理想，也决不是我们的最终目的**，而只是……一个阶段。
- **最终机制**：人们对于人类一切公共生活的简单的基本规则就会很快**从必须遵守变成习惯于遵守**了。
- **民主的定位**：民主决不是不可逾越的极限，它只是……**道路上的阶段之一**。
- **形式平等 vs 事实平等**：从**形式上的平等**进到**事实上的平等**（各尽所能，按需分配）。

## 【6】马克思主义被机会主义者庸俗化

### 6.1 普列汉诺夫 〔补〕
- **落点句**：这不是反驳……实际上是向他让步，是把阵地让给机会主义，因为机会主义者现在所需要的，恰恰是把……一切根本问题都"**十分放心地留待将来去解决**"。

### 6.2 考茨基
- **他的拖延术**：现在我们是反对党，到夺取政权以后我们再专门来谈。→ **革命不见了！**
- **落点句（必背）**：革命不应当是新的阶级利用旧的国家机器来指挥、管理，而应当是新的阶级**打碎这个机器，利用新的机器**来指挥、管理，——这就是考茨基所抹杀或者完全不理解的**马克思主义的基本思想**。
- **官僚制实质**：在资本家被剥夺以前，在资产阶级被推翻以前，甚至**无产阶级的公职人员也免不了在一定程度上"官僚化"**。
- **三条对抗措施**：① 随时撤换 ② 报酬减到工人平均工资 ③ 实干的（既是行政又是立法的）机构代替议会式机构

### 6.3 三条区别（**按号背**）
```
(1) 何时消灭：马克思主义者——阶级消灭之后；无政府主义者——一天之内
(2) 用什么代替 + 怎样利用：马克思主义者——彻底破坏旧的，用公社类型的新的代替它，
                           并利用革命政权；无政府主义者——主张破坏，
                           但完全没弄清用什么代替，甚至否定无产阶级专政
(3) 怎样准备：马克思主义者——通过利用现代国家来准备革命；无政府主义者——否定
```

### 6.4 决裂
- **落点句**：马克思教导我们要**避免这两种错误**，教导我们要以敢于舍身的勇气去破坏全部旧的国家机器，同时又教导我们要**具体地提问题**。
- **最后一句**：我们却要同机会主义者决裂……不是去争取"力量对比的变动"，而是去**推翻资产阶级**……建立**无产阶级的革命专政**。
- **收尾金句**：在社会主义下，所有的人将**轮流来管理**，因此很快就会**习惯于不要任何人来管理**。

# 卡壳急救：10 个最容易断的地方

| # | 容易断在哪 | 破解 |
|---|---|---|
| 1 | 1.4 的五点顺序记不全 | 五字口诀：**谁 / 质 / 时 / 敌 / 暴** |
| 2 | "消亡"和"打碎"张冠李戴 | 配对记：**资产阶级国家被消灭，无产阶级国家自行消亡**。想画面：敌人是被打倒的，自己人是慢慢退场的 |
| 3 | 2.2 和 2.3 混在一起 | 2.2 =《雾月十八日》→"打碎"；2.3 = 给魏德迈的信 →"专政"（而且它是第二版才加的） |
| 4 | 第三章四项措施顺序 | 口诀 **军 / 选 / 薪 / 教** |
| 5 | 4.2 里"我们和无政府主义者的分歧"说错 | 记住：**目的没分歧，手段才有分歧**（废除国家是共同目的，暂时利用国家是分歧） |
| 6 | 4.6 "民主也要消亡"记不住 | 想配对：**民主是一种国家形式** → 国家消亡，民主自然消亡；但"少数服从多数"这个**原则**不等于民主 |
| 7 | 5.2 三形态记乱 | 只记"谁享受民主"：资本主义=**极少数富人**；过渡=**人民大多数**（同时镇压少数）；共产主义=**所有人**（然后消亡） |
| 8 | 5.3 的悖论句说反 | 是"保留资产阶级**权利**"和"资产阶级**国家**"，但"**没有资产阶级**"。三句递进：正在消亡 → 还没完全消亡 → 完全消亡需要共产主义 |
| 9 | 5.4 三个条件顺序 | ① 分工消失/脑体对立消失 ② 劳动成为第一需要 ③ 生产力增长、财富涌流 |
| 10 | 6.3 三条区别只记得两条 | 三条按时间分：**何时消灭 / 用什么代替 / 怎样准备** |
