# 【初版序言】为什么现在必须谈国家问题 〔补〕

## 这一步干什么
说明**为什么在 1917 年 8 月，国家问题成了最急迫的问题**。

## 论证结构
```
【现实①】帝国主义战争大大加速并加剧了垄断资本主义变为国家垄断资本主义的过程
         与资本家同盟日益密切融合的国家，对劳动群众的压迫日益严重
         → 先进各国（指它们的"后方"）都变成了工人的军事苦役监狱
【现实②】战争造成的惨祸使群众愤怒增长，国际无产阶级革命显然在生长
【现实③】几十年和平发展积累的机会主义，在各国正式社会党内造成统治地位的
         社会沙文主义思潮——口头的社会主义、实际的社会沙文主义
【关键判断】要使劳动群众摆脱资产阶级影响，不同机会主义对"国家"的偏见作斗争是不可能的
【全书计划】首先研究马恩的国家学说（特别是被忘记/被曲解的部分）
            其次研究曲解的主要代表考茨基
            最后总结俄国 1905、1917 年革命经验
```

## 逻辑要害
**序言把全书锁定为"论战 + 行动"双重性质：**
- 敌人不是抽象的错误，而是**当时各国工人党内占统治地位的机会主义**（考茨基是头号代表）
- 目的不是学术澄清，而是**向群众说明他们在最近的将来应该做什么**

> 这也解释了为什么全书从头到尾骂人不断——**因为每一条被忘记的原理，都有人在现场歪曲它。**

## 1.1 国家是阶级矛盾不可调和的产物

### 这一步干什么
立**全书公理**，并且**立刻用它来打人**。

### 论证结构
```
【恩格斯的原文】（《起源》）
   国家是社会在一定发展阶段上的产物
   国家是承认：这个社会陷入了不可解决的自我矛盾，分裂为不可调和的对立面而又无力摆脱
   为了使这些对立面不致在无谓的斗争中把自己和社会消灭
   → 需要一种表面上凌驾于社会之上的力量，缓和冲突，把冲突保持在"秩序"范围以内
   → 这种从社会中产生但又自居于社会之上并日益同社会相异化的力量，就是国家
【列宁提炼的两个命题】
   国家是阶级矛盾不可调和的产物和表现
   在阶级矛盾客观上不能调和的地方、时候和条件下，便产生国家
   反过来说：国家的存在证明阶级矛盾不可调和
【马克思的补充】
   国家是阶级统治的机关，是一个阶级压迫另一个阶级的机关
   是建立一种"秩序"来缓和阶级冲突，使这种压迫合法化、固定化
【立刻推出结论】
   被压迫阶级要解放，不仅非进行暴力革命不可，
   而且非消灭统治阶级所建立的、体现这种"异化"的国家政权机构不可
```

### 逻辑要害：定义立起来，立刻去打两种歪曲

这是本章最值得学的一手——**定义不是摆设，是武器**。列宁紧接着点名两种歪曲：

| 歪曲者 | 他们的说法 | 错在哪 |
|---|---|---|
| **小资产阶级思想家**（社会革命党、孟什维克） | 国家是**阶级调和**的机关 | 按马克思，如果阶级调和可能，国家就既不能产生也不能存在。他们把"缓和"偷换成了"调和" |
| **考茨基主义**（更巧妙） | 理论上不否认国家是阶级统治机关，也不否认矛盾不可调和 | **但抹杀了由此得出的结论**——必须暴力革命、必须消灭国家机器。他们"忘记"了这一条 |

> **为什么第二种更危险？** 因为第一种是公开的错误，第二种是**承认前提、抹杀结论**——表面上没说错话，实际上把最要害的东西抽掉了。这是全书贯穿的批判范式。

**还有一个精准的细节：**
- 马克思说国家建立"秩序"来使压迫**合法化、固定化**
- 小资产阶级说"秩序就是阶级调和"
- **同一个词"秩序"，两种理解。** 列宁抓住这个词做文章——这正是后来第二章反复用的"重新定义"手法。

### 抓手句
> **国家是阶级矛盾不可调和的产物和表现。** 在阶级矛盾客观上不能调和的地方、时候和条件下，便产生国家。反过来说，**国家的存在证明阶级矛盾不可调和**。

> 在马克思看来，国家是阶级统治的机关，是一个阶级压迫另一个阶级的机关，是建立一种"秩序"来缓和阶级冲突，使这种压迫合法化、固定化。

> 被压迫阶级要求得解放，不仅非进行暴力革命不可，而且非消灭统治阶级所建立的、体现这种"异化"的国家政权机构不可。

### 为什么放在这里
它是**公理**。后面"必须打碎国家机器""无产阶级专政""国家消亡"全部依赖这个定义。不先立它，全书无处着力。

## 1.2 特殊的武装队伍、监狱等等

### 这一步干什么
回答"国家靠什么维持"——**国家之所以是国家，是因为它有一支脱离人民的武装。**

### 论证结构
```
【恩格斯的观察】国家的第二个特点是"公共权力"的建立
                     这个公共权力"不再直接就是"武装的居民，即居民的"自动的武装组织"
【列宁追问】为什么必须有特殊的、居于社会之上、同社会相异化的武装队伍？
【庸人的答案】社会生活复杂化、职能分化……（借用斯宾塞或米海洛夫斯基）
【列宁的反驳】这种说法似乎"科学"，很能迷惑人
               但它掩盖了主要的基本事实：社会分裂为不可调和地敌对的阶级
【反证法】如果没有阶级分裂，"居民的自动的武装组织"是可能有的
           ——只是复杂程度、技术水平不同于猿猴/原始人/克兰社会，但可能有
           之所以不可能有，是因为文明社会已分裂为敌对的、不可调和的阶级
           如果这些阶级都有"自动的"武装，就会导致它们之间的武装斗争
【于是】国家形成了，特殊的武装队伍建立起来了
【经验佐证】每次大革命破坏国家机构时，都看到赤裸裸的阶级斗争：
            统治阶级力图恢复替它服务的特殊武装队伍
            被压迫阶级力图建立不替剥削者服务而替被剥削者服务的新型组织
【国家的物质支撑】为了维持这种凌驾于社会之上的公共权力，就需要捐税和国债
```

### 逻辑要害

**（1）"特殊"两个字是全部关键。**
不是"有没有武装"的问题，而是**武装是不是脱离人民**的问题。这一句直接预告了第三章公社的第一条措施：**废除常备军而代之以武装的人民**。

**（2）列宁用了一个漂亮的反证：** "如果没有阶级分裂，自动武装组织是可能的"——**用假设的"可能"反衬现实的"不可能"，从而把原因锁定在阶级分裂上。** 这叫**排除法**：不是因为技术复杂，不是因为职能分化，唯一的解释是阶级分裂。

**（3）"每次大革命"那句是伏笔。** 它把"特殊的武装队伍 vs 人民的自动武装"这个问题，从理论问题变成了**每次革命都要现场回答的实践问题**——而这正是后面第二、三章要展开的。

### 抓手句
> 这种力量主要是什么呢？主要是拥有监狱等等的**特殊的武装队伍**。

> 常备军和警察是国家政权的主要强力工具。

> 这样的组织所以不可能有，是因为文明社会已分裂为敌对的而且是不可调和地敌对的阶级。

> 为了维持特殊的、凌驾于社会之上的公共权力，就需要捐税和国债。

### 为什么放在这里
承接 1.1 的定义（国家是"力量"），接着问"这个力量是什么"——**从抽象定义到具体特征**，顺序不可倒。

## 1.3 国家是剥削被压迫阶级的工具

### 这一步干什么
回答"这个力量替谁服务"。

### 论证结构
```
【恩格斯的论述】由于国家是从控制阶级对立的需要中产生的，又是在这些阶级的冲突中产生的
                所以照例是最强大的、在经济上占统治地位的阶级的国家
                这个阶级借助国家在政治上也成为占统治地位的阶级
                因而获得了镇压和剥削被压迫阶级的新手段
【历史举例】古代国家 = 剥削奴隶的机关
            封建国家 = 剥削农奴的机关
            现代的代议制国家 = 资本剥削雇佣劳动的工具
【例外】互相斗争的各阶级势均力敌时，国家权力作为表面上的调停人
        暂时得到对两个阶级的某种独立性（但只是例外）
【列宁推进到"民主制"——本节点最锋利的一刀】
        "财富"的无限权力在民主共和制下更可靠
        因为它不依赖政治机构的某些缺陷，不依赖资本主义的不好的政治外壳
        → 民主共和制是资本主义所能采用的最好的政治外壳
        → 资本一掌握这个最好的外壳，就能十分巩固可靠地确立自己的权力
        → 无论人员、机构、政党的任何更换，都不会使这个权力动摇
【普选制】恩格斯十分肯定地认为，普选制是资产阶级统治的工具
          是"测量工人阶级成熟性的标尺。在现今的国家里，普选制不能而且永远不会提供更多的东西"
```

### 逻辑要害

**（1）"最好的政治外壳"是全书最著名的比喻之一。**
它的杀伤力在于：**它把民主共和国从"进步成果"重新定位为"资本的更可靠的统治形式"。**

推理很硬：
```
君主制下：财富直接运用权力（政治地位按地产排列）
民主制下：财富间接但更可靠地运用权力
          → 因为它不依赖机构的缺陷、不依赖政治外壳的好坏
          → 所以换人换党换机构，权力都不动摇
```
**结论：民主共和国不是更接近社会主义，而是更稳固的资本主义。** 这就堵死了"我们可以利用现成的民主国家和平过渡到社会主义"这条路。

**（2）"普选制是测量工人阶级成熟性的标尺"——这句话是双刃的。**
它承认普选制有**认识价值**（能看出工人阶级成熟到什么程度），但明确否认它有**解放价值**（不能提供更多东西）。**这种"精确划线"的手法是列宁的招牌**（后面 `4.5` 讲"民主共和国是捷径"时还会用）。

**（3）"例外"那句不能漏。** 列宁照抄了恩格斯关于"势均力敌时国家暂时独立"的论述——**这是防止被对手抓住反驳**：你说国家永远是统治阶级的工具？那历史上的"波拿巴主义"怎么解释？列宁预先堵住。

### 抓手句
> "现代的代议制的国家"也"是资本剥削雇佣劳动的工具"。

> 民主共和制是资本主义所能采用的**最好的政治外壳**。

> 在资产阶级民主共和国中，无论人员、无论机构、无论政党的任何更换，都不会使这个权力动摇。

> 普选制是**测量工人阶级成熟性的标尺**。在现今的国家里，普选制不能而且永远不会提供更多的东西。

### 为什么放在这里
1.1 定义 → 1.2 特征（武装）→ 1.3 归属（替谁服务），**三层递进，一层比一层具体**。而且这一节必须落在"民主共和国"上，因为**当时的论敌就是把民主共和国当作终点**的。

## 1.4 国家"自行消亡"和暴力革命（**本章高潮，全书发动机**）

### 这一步干什么
处理恩格斯那句被歪曲得最厉害的名言——**"国家不是'被废除'的，它是自行消亡的"**。

### 论证结构（这是全书最精密的一段）

**第一步：先摆出被歪曲的现象**
```
马克思主义被"削剪"成：
       和无政府主义的国家"废除"说不同，按马克思的观点，国家是"自行消亡"的
【列宁的判定】这样削剪，无异于把马克思主义变成机会主义
              因为这样"解释"就只会留下一个模糊的观念：
              似乎变化是缓慢的、平稳的、逐渐的，没有飞跃和风暴，没有革命
              → 这种理解意味着回避革命，甚至否定革命
              → 这是对马克思主义最粗暴的、仅仅有利于资产阶级的歪曲
```

**第二步：用"五点"把完整的恩格斯还原出来**

| | 要点 | 内容 |
|---|---|---|
| **第一** | **谁消亡、谁被消灭** | 恩格斯说的是：无产阶级取得政权"这样一来也消灭了作为国家的国家"。<br>→ **资产阶级国家不是"自行消亡"的，而是由无产阶级在革命中"消灭"的**；<br>→ 在这个革命以后，自行消亡的是**无产阶级的国家或半国家** |
| **第二** | **国家是"特殊的镇压力量"** | 资产阶级对无产阶级的"特殊镇压力量"，应由无产阶级对资产阶级的"特殊镇压力量"（无产阶级专政）来代替<br>→ **以一种特殊力量代替另一种特殊力量，这种更替决不能通过"自行消亡"实现** |
| **第三** | **消亡指的是什么时候** | 指的是"国家以整个社会的名义占有生产资料"**以后**，即社会主义革命以后的时期<br>→ 这时"国家"的政治形式是**最完全的民主**<br>→ 恩格斯说的其实是**民主的"自行停止"和"自行消亡"**<br>→ 只有没想过"民主也是国家"的人才会觉得不可理解<br>→ **资产阶级的国家只有革命才能"消灭"；国家本身，就是说最完全的民主，只能"自行消亡"** |
| **第四** | **这个原理反对谁** | 恩格斯提出"自行消亡"后，**立刻**说明它既反对机会主义者又反对无政府主义者<br>→ 而且**放在首位的是反对机会主义者的结论**<br>→ 但现实是：反对无政府主义者的结论被千百次重复、变成固执偏见；<br>**反对机会主义者的结论，却被抹杀和"忘记了"** |
| **第五** | **暴力革命** | 同一本著作中还有对暴力革命的颂扬："暴力……是每一个孕育着新社会的旧社会的助产婆"<br>→ 但"谁都不记得"这一点<br>→ 这些思想同国家"自行消亡"论是**紧紧联在一起、联成一个严密整体的** |

**第三步：批判"折中主义"的结合方式**
```
问题：怎么把"颂扬暴力革命"和"自行消亡"结合在一个学说里？
庸人的办法：折中主义 —— 随心所欲地时而抽出这个论述时而抽出那个论述
            而且100次中有99次是把"自行消亡"论摆在首位
【列宁的判定】用折中主义代替辩证法，是正式社会民主党书刊中最常见最普遍的现象
              它最容易欺骗群众，能使人感到似是而非的满足
              似乎考虑到了一切方面、一切趋势、一切矛盾影响
              但实际上并没有对社会发展过程作出任何完整的革命的解释
```

**第四步：结论**
> **无产阶级国家代替资产阶级国家，非通过暴力革命不可。**
> **无产阶级国家的消灭，即任何国家的消灭，只能通过"自行消亡"。**

### 逻辑要害（四条，全部要吃透）

**（1）"第一点"是整个全书的枢纽。**
> 资产阶级国家：被**消灭**（暴力革命）
> 无产阶级国家：**自行消亡**

**这两个动作的对象完全不同。** 机会主义的全部伎俩就是把这两个对象混为一谈。列宁用一句话把它拆开——**这就是全书最重要的那句区分。**

**（2）"第三点"是全书最反直觉的一击：民主也要消亡。**
> "只有那些没有想到**民主也是国家**、因而在国家消失时民主也会消失的人，才会觉得这是'不可理解'的。"

这句之所以锋利，是因为它把论敌逼到一个尴尬境地：**你们整天讲民主，可你们连民主是什么都不知道——民主是一种国家形式，所以国家消亡时民主也消亡。**（后面 `4.6` 会专门展开。）

**（3）"第四点"揭露的是一种选择性的记忆。**
恩格斯的话里明明有两个对手，为什么反对无政府主义的那一半被记住了、反对机会主义的那一半被忘了？列宁没明说原因，但答案很清楚——**因为反对机会主义会得罪当权者和社会党内的主流。** 这个观察本身就是一种社会学分析。

**（4）"折中主义 vs 辩证法"是方法论层面的判决。**
列宁不只是说"你引错了"，而是说**你的思维方式坏了**：
```
辩证法：完整把握过程，指出哪个方面在什么条件下是主要的
折中主义：把各个方面平列，看似全面，实则取消了革命
```
**这一击的意义超出国家问题本身**——它给了读者一个识别机会主义的通用工具。

### 抓手句（本章结论，务必逐字背）
> 资产阶级国家不是"自行消亡"的，而是由无产阶级在革命中来"消灭"的。在这个革命以后，自行消亡的是无产阶级的国家或半国家。

> 以一种（无产阶级的）"特殊力量"来代替另一种（资产阶级的）"特殊力量"，这样一种更替是决不能通过"自行消亡"来实现的。

> **资产阶级的国家只有革命才能"消灭"。国家本身，就是说最完全的民主，只能"自行消亡"。**

> 用折中主义代替辩证法，这就是目前正式的社会民主党书刊中在对待马克思主义的态度上最常见最普遍的现象。

> 无产阶级国家代替资产阶级国家，非通过暴力革命不可。无产阶级国家的消灭，即任何国家的消灭，只能通过"自行消亡"。

### 为什么放在这里
**因为它是第一章的落点，也是全书的发动机。** 后面五章全是在回答它提出的两件事：
- "打碎、消灭资产阶级国家" → 第二、三章
- "无产阶级国家自行消亡" → 第四、五章

> **第一章的这一节，把全书后面所有章节的任务一次性分配完毕。**

## 2.1 革命的前夜（1847：《哲学的贫困》《共产党宣言》）

### 这一步干什么
**先看起点**——马克思在革命前夜对国家的提法有多抽象。这样的铺垫是为了让 2.2 的"前进了一大步"有对照物。

### 论证结构
```
【引文一】《哲学的贫困》
   "工人阶级在发展进程中将创造一个消除阶级和阶级对抗的联合体来代替旧的资产阶级社会；
    从此再不会有原来意义的政权了。因为政权正是资产阶级社会内部阶级对抗的正式表现。"
【引文二】《共产党宣言》
   "工人革命的第一步就是使无产阶级转化成（上升为）统治阶级，争得民主。
    无产阶级将利用自己的政治统治，一步一步地夺取资产阶级的全部资本，
    把一切生产工具集中在国家即组织成为统治阶级的无产阶级手里，
    并且尽可能快地增加生产力的总量。"
【列宁的两个发现】
   ① 这里有"无产阶级专政"思想的表述（马恩在巴黎公社以后才这样叫）
   ② 还有一个"被忘记的言论"：国家即组织成为统治阶级的无产阶级
【为什么被忘记】这个定义在正式社会民主党的宣传中从来没有解释过，恰巧被人忘记了
                因为它同改良主义根本不相容，直接打击了"民主的和平发展"的幻想
【进一步澄清】无产阶级需要国家，机会主义者都这样重复，但"忘记"补充：
   第一，无产阶级所需要的只是逐渐消亡的国家，即组织得能立刻开始消亡而且不能不消亡的国家
   第二，劳动者所需要的"国家"，"即组织成为统治阶级的无产阶级"
【这一步还留了什么】还没有提出：究竟应当怎样以无产阶级国家来代替资产阶级国家
```

### 逻辑要害

**（1）"国家即组织成为统治阶级的无产阶级"——这是《宣言》里那句话的第二次出场。**
注意列宁怎么用它：**它不是书斋定义，而是"直接打击了民主和平发展的幻想"**。所以它被忘记了。**"被忘记"不是偶然，是被选择的。**（这和 `1.4` 第四点"反对机会主义的结论被抹杀"是同一个观察。）

**（2）"立刻开始消亡而且不能不消亡"这个限定语极重要。**
无产阶级国家不是一般的国家，它**从第一天起就带着自己的墓志铭**。这是理解第四章"半国家"的钥匙。

**（3）列宁在本节末尾还补了一段对"小资产阶级民主派"的批判**：他们把改造想象为"少数和平地服从那已经理解到本身任务的多数"——**用阶级妥协的幻想代替阶级斗争**。这是为第六章考茨基做的铺垫。

### 抓手句
> 我们看到马克思主义在国家问题上一个最卓越最重要的思想即"**无产阶级专政**"……其次我们还看到给国家下的一个非常引人注意的定义……"**国家即组织成为统治阶级的无产阶级**。"

> 无产阶级所需要的只是**逐渐消亡的国家**，即组织得能**立刻开始消亡而且不能不消亡**的国家。

> 在这里还没有提出究竟应当怎样（从历史发展的观点来看）以无产阶级国家来代替资产阶级国家的问题。

## 2.2 革命的总结（1852：《雾月十八日》——**"必须打碎"**）

### 这一步干什么
**本章的核心。** 用马克思对 1848—1851 年法国革命的总结，得出那句著名的结论。

### 论证结构
```
【马克思的原文】（《路易·波拿巴的雾月十八日》）
   革命先使议会权力臻于完备，为的是能够推翻这个权力
   现在它使行政权臻于完备，使之孤立，以便集中一切破坏力量来反对行政权
   这个行政权有庞大的官僚机构和军事机构，有复杂而巧妙的国家机器
   有50万人的官吏大军和50万人的军队
   这个俨如密网一般缠住法国社会全身并阻塞其一切毛孔的可怕的寄生机体
       是在专制君主时代、在封建制度崩溃时期产生的
   第一次法国革命发展了中央集权，同时扩大了政府权力的容量、属性和走卒数目
   拿破仑完成了这个国家机器；正统王朝和七月王朝不过扩大了分工
   议会制共和国……不得不加强政府权力的工具和中央集权
   → 一切变革都是使这个机器更加完备，而不是把它摧毁
   → 那些相继争夺统治权的政党，都把这个庞大国家建筑物的夺得视为胜利者的主要战利品
【列宁的判定】
   马克思主义在这一段里，与《共产党宣言》相比，向前迈进了一大步
   在那里，国家问题还提得非常抽象，只用了最一般的概念和说法
   在这里，问题提得具体了，并且作出了非常准确、明确、实际而具体的结论：
   → 过去一切革命都是使国家机器更加完备，而这个机器是必须打碎，必须摧毁的
【方法论】马克思这样提出任务，不是根据逻辑的推论，
          而是根据事变的实际发展，根据1848-1851年的生动经验
【还留了什么】马克思在1852年还没有具体提出用什么东西来代替这个必须消灭的国家机器
              因为那时经验还没有提供材料
              能以观察自然历史那样的精确性下断语的，只能是：
              无产阶级革命已面临"集中自己的一切破坏力量"来反对国家政权的任务
              即"摧毁"国家机器的任务
```

### 逻辑要害

**（1）"一切变革都是使这个机器更加完备，而不是把它摧毁"——这是全书的经验基石。**
它的力量来自**它是历史事实，不是推论**：法国从第一次革命到拿破仑到正统王朝到七月王朝到议会制共和国，**百年之内换了无数政权，但机器越换越强**。列宁要点出的规律是：**换主人不等于换机器。**

**（2）列宁特意强调"不是根据逻辑的推论，而是根据事变的实际发展"。**
这是**唯物主义的自我声明**，也是防止对手说"这是你的演绎"。马克思的结论是从经验里长出来的。

**（3）"还留了什么"这个交代极重要。**
列宁明确说：1852 年只能说到"摧毁"，**说不出"用什么代替"**，因为经验没给材料。**这句话是第三章的引子**——1871 年历史才把这个问题提到日程上。

> **这就是全书的节奏感**：每一章都先说"能说什么"，再说"还说什么不了"，然后下一章把它解决。**这是"历史叙述"和"逻辑论证"的同步推进。**

**（4）马克思原文的修辞也值得注意：**
"这个俨如密网一般缠住法国社会全身并阻塞其一切毛孔的**可怕的寄生机体**"
→ **"寄生物"这个比喻在后文（`2.4`、`3.5`）反复出现**，成为指称国家机器的固定词。

### 抓手句
> 一切变革都是使这个机器更加完备，**而不是把它摧毁**。

> 那些相继争夺统治权的政党，都把这个庞大国家建筑物的夺得视为**胜利者的主要战利品**。

> **过去一切革命都是使国家机器更加完备，而这个机器是必须打碎，必须摧毁的。**

> 马克思这样提出任务，不是根据逻辑的推论，而是根据事变的实际发展，根据1848-1851年的生动经验。

> 在1852年，要以观察自然历史那样的精确性下断语，还能说，无产阶级革命已面临"**集中自己的一切破坏力量**"来反对国家政权的任务，即"**摧毁**"国家机器的任务。

## 2.3 1852 年马克思对问题的提法（给魏德迈的信）★第二版增补

> 你的笔记收录了这一段（P34—36），但它**是 1918 年 12 月第二版才加进去的**（见 `00` 钥匙四）。

### 这一步干什么
拿出马克思**亲笔写下的、最无可争辩的**那段话，把"无产阶级专政"钉死为马克思主义的试金石。

### 论证结构
```
【马克思的原文】（1852年3月5日给魏德迈的信）
   "至于讲到我，无论是发现现代社会中有阶级存在或发现各阶级间的斗争，都不是我的功劳。
    在我以前很久，资产阶级历史编纂学家就已经叙述过阶级斗争的历史发展，
    资产阶级经济学家也已经对各个阶级作过经济上的分析。
    我所加上的新内容就是证明了下列几点：
    (1) 阶级的存在仅仅同生产发展的一定历史阶段相联系；
    (2) 阶级斗争必然导致无产阶级专政；
    (3) 这个专政不过是达到消灭一切阶级和进入无阶级社会的过渡。"
【列宁指出这段话表达了两点】
   ① 他的学说同先进的资产阶级思想家的学说之间的主要的根本的区别
   ② 他的国家学说的实质
【列宁的关键推论——"试金石"】
   "马克思学说中的主要之点是阶级斗争。人们时常这样说，这样写。但这是不正确的。"
   → 因为阶级斗争学说不是马克思创立的，是资产阶级在马克思以前创立的
     一般说来是资产阶级可以接受的
   → 谁要是仅仅承认阶级斗争，那他还不是马克思主义者，
     他还可以不超出资产阶级思想和资产阶级政治的范围
   → 把马克思主义局限于阶级斗争学说，就是阉割马克思主义
   → 只有承认阶级斗争、同时也承认无产阶级专政的人，才是马克思主义者
   → 必须用这块试金石来检验是否真正理解和承认马克思主义
【验证】当欧洲历史在实践上向工人阶级提出这个问题时
        不仅一切机会主义者和改良主义者，而且所有"考茨基主义者"
        （动摇于改良主义和马克思主义之间的人）
        都成了否认无产阶级专政的可怜的庸人和小资产阶级民主派
【推论到国家形式】这个时期必然是阶级斗争空前残酷、形式空前尖锐的时期
                  因而这个时期的国家不可避免地应当是
                      新型民主的（对无产者和一般穷人是民主的）
                      新型专政的（对资产阶级是专政的）国家
                  资产阶级国家形式虽多样，本质一样：都是资产阶级专政
                  从资本主义向共产主义过渡，政治形式会非常丰富多样
                  但本质必然是一样的：都是无产阶级专政
```

### 逻辑要害

**（1）"阶级斗争不是马克思的主要之点"——这是全节最反直觉、也最有力的一击。**
它把当时（以及现在）最流行的"马克思主义=阶级斗争学说"这个理解直接判为错误。推理极硬：
```
前提：阶级斗争学说是资产阶级创立的、资产阶级可以接受
结论：只承认阶级斗争 → 你还可能在资产阶级思想范围内
推论：把马克思主义局限于阶级斗争 = 阉割马克思主义
```

**（2）"试金石"这个比喻的战术价值。**
列宁不满足于"专政很重要"，他给了读者一个**可操作的检验标准**：随便找一个自称马克思主义者的人，问他承不承认无产阶级专政，就知道了。**把一个理论分歧变成一个二元判断题**，这在论战中是致命的简化。

**（3）"所有考茨基主义者都成了否认无产阶级专政的可怜的庸人"——这就是 1918 年增补这一节的原因。**
考茨基本人就在 1918 年写《无产阶级专政》攻击布尔什维克。**这一节是"引文策略"（`00` 钥匙二）的实战应用：你要否认专政？那你自己看马克思这封信。**

**（4）"新型民主 + 新型专政"这一对，是第五章"民主三形态"的前身。**
注意它的表述结构：**对谁民主、对谁专政，永远成对出现。** 这是列宁谈民主的固定语法。

### 抓手句
> (1) 阶级的存在仅仅同生产发展的一定历史阶段相联系；(2) **阶级斗争必然导致无产阶级专政**；(3) 这个专政不过是达到消灭一切阶级和进入无阶级社会的过渡。

> **谁要是仅仅承认阶级斗争，那他还不是马克思主义者**，他还可以不超出资产阶级思想和资产阶级政治的范围。

> **只有承认阶级斗争、同时也承认无产阶级专政的人，才是马克思主义者。**

> 资产阶级国家的形式虽然多种多样，但本质是一样的：所有这些国家，不管怎样，归根到底一定都是**资产阶级专政**。从资本主义向共产主义过渡……本质必然是一样的：都是**无产阶级专政**。

## 2.4 寄生物与帝国主义（国家机器在当代的强化）

### 这一步干什么
把 1852 年的结论**接到 1917 年的现实**上——证明"打碎"不是历史陈迹，而是**眼下的任务**。

### 论证结构
```
【马克思的观察】最能表明国家机器特征的两种机构：官吏和常备军
                这两种机构恰巧同资产阶级有千丝万缕的联系
                → 官吏和常备军是资产阶级社会身上的"寄生物"
                  是使这个社会分裂的内部矛盾所产生的寄生物
                  而且正是"阻塞"生命毛孔的寄生物
【机制】小资产阶级被吸引到大资产阶级方面去并受它支配，很大程度上就是通过这个机构
        这个机构给农民、小手工业者、商人的上层分子以舒适、安闲、荣耀的职位
        使这些职位的占有者居于人民之上
【列宁的当代观察一：19世纪末20世纪初】
        一方面，无论共和制（法、美、瑞）还是君主制（英、德、意、斯堪的纳维亚）
                都逐渐形成"议会权力"
        另一方面，各资产阶级政党和小资产阶级政党瓜分着和重新瓜分着官吏职位这种"战利品"
        最后，"行政权"、它的官吏和军事机构日益完备和巩固起来
        → 这是一般资本主义国家现代整个演变过程的共同特征
【列宁的当代观察二：帝国主义】
        帝国主义即银行资本时代、垄断资本主义时代、垄断资本主义转变为国家垄断资本主义的时代
        表明：无论君主制还是最自由的共和制国家
              由于要加强高压手段对付无产阶级，"国家机器"大大强化了
              它的官吏和军事机构空前膨胀起来
        → 全世界的历史正在比1852年广阔得无比的范围内
          把无产阶级革命引向"集中自己的一切力量"去"破坏"国家机器
【列宁的当代观察三：1917年俄国实例】
        1917年2月27日以后半年：以前优先给予黑帮分子的官吏位置
        现已成为立宪民主党人、孟什维克和社会革命党人猎取的对象
        各种改革都延期了，官吏职位已经瓜分了
        → 这就是1917年2月27日—8月27日这半年的总结，客观的总结
【由此得出】各被压迫阶级以无产阶级为首，愈清楚地认识到自己同整个资产阶级社会的敌对性
            因此一切资产阶级政党都必须加强高压手段来对付革命无产阶级，巩固原有国家机器
            → 这样的事变进程迫使革命提出这样的任务：
              不是去改善国家机器，而是破坏它、消灭它
```

### 逻辑要害

**（1）"寄生物"这个比喻是全节的骨架。**
它把"官吏 + 常备军"从"必要的公共机构"重新描述为**寄生在社会身上的赘瘤**。一旦这么描述，"打碎它"就不再是破坏秩序，而是**切除病灶**。

**（2）"战利品"这个词是第二次出现。**
2.2 里马克思说各政党把国家机器视为"胜利者的主要战利品"，这里列宁接过来用在 1917 年俄国——**同一个词，跨越 65 年，证明规律没变。**

**（3）1917 年俄国实例是全书最狠的现实批判。**
列宁专门点名立宪民主党、孟什维克、社会革命党：**他们嘴上改革，实际在抢官位。** 这一段之所以有力，是因为它**用刚刚发生的事**作证——读者是当事人，无法否认。

**（4）一个重要的理论判断：**
> "这样提出任务，不是根据逻辑的推论，而是根据事变的实际发展"（`2.2`）
> 而这里，列宁做了同样的事：**把"打碎"这个任务，再一次建立在 19 世纪末到 1917 年的事实上，而不是建立在推论上。**

### 抓手句
> 最能表明这个国家机器特征的有两种机构，即**官吏和常备军**。

> 官吏和常备军是资产阶级社会身上的"**寄生物**"，是使这个社会分裂的内部矛盾所产生的寄生物，而且正是"阻塞"生命的毛孔的寄生物。

> 由于要加强高压手段来对付无产阶级，"国家机器"就大大强化了，它的官吏和军事机构就空前膨胀起来了。

> 不是去改善国家机器，而是**破坏它、消灭它**。

**整章写法**：围绕马克思《法兰西内战》的引文，逐条分析公社的措施，然后提炼出"量转化为质"。

## 3.1 公社社员的英雄主义何在

### 这一步干什么
**先讲马克思对待群众运动的态度**——为全章定下"向经验学习"的方法论。

### 论证结构
```
【事实】1870年秋，马克思曾告诫巴黎工人：推翻政府的企图将是绝望的蠢举
【转折】但当1871年3月工人被迫决战、起义已成为事实时
        马克思还是以极其欢欣鼓舞的心情来迎接无产阶级革命
        他没有固执己见，没有学究式地非难运动"不合时宜"
        （对比：普列汉诺夫在1905年11月鼓励斗争，12月以后却大叫什么
          "本来就用不着拿起武器"）
【马克思的任务】分析这个经验、从中得到策略教训、根据它来重新审查自己的理论
【马克思的结论（引自给库格曼的信，1871年4月12日）】
   "……如果你查阅一下我的《雾月十八日》的最后一章，你就会看到，
    我认为法国革命的下一次尝试不应该再像以前那样把官僚军事机器
    从一些人的手里转到另一些人的手里，而应该把它打碎，
    这正是大陆上任何一次真正的人民革命的先决条件。
    这也正是我们英勇的巴黎党内同志们的尝试。"
【列宁的判定】
   "把官僚军事国家机器打碎"这几个字，已经简要地表明了
   马克思主义关于无产阶级在革命中在对待国家方面的任务问题的主要教训
   而正是这个教训，不仅被人完全忘记了
   而且被现时对马克思主义所作的流行的即考茨基主义的"解释"公然歪曲了
【补充："人民革命"的含义】
   马克思说打碎官僚军事机器是"任何一次真正的人民革命的先决条件"
   → 1905-1907年俄国革命是"真正的人民"革命
     因为人民群众、大多数、社会最"底层"曾经独立奋起
   → 1871年，只有把无产阶级和农民都包括进来的革命才是"人民"革命
     这两个阶级都受官僚军事国家机器的压迫而联合起来
   → 打碎这个机器，是贫苦农民同无产者自由联盟的"先决条件"
     没有这个联盟，民主就不稳固，社会主义改造就没有可能
```

### 逻辑要害

**（1）马克思的态度本身就是论证。**
列宁先讲"马克思曾告诫不要起义，但起义一发生他就欢欣鼓舞"——**这不是轶事，这是方法论示范**：真正的马克思主义者**向活的运动学习，而不是拿理论去训诫运动**。

（对比普列汉诺夫那个"本来就用不着拿起武器"——这句话在全书被当作反面典型反复引用。）

**（2）"打碎"这个词的德语原文被特别标出（zerbrechen）。**
列宁连德文都标了，说明他在**扣字眼**——对手可以说"打碎是比喻"，列宁说：不，马克思用的就是这个词。

**（3）"人民革命"的定义是策略性的。**
1871 年无产阶级还没占人口多数，所以"人民"= 工人 + 农民。**这个定义为后来的"工农联盟"埋下伏笔。**

### 抓手句
> 马克思并没有固执己见，学究式地非难运动"不合时宜"。

> 无产阶级革命的下一次尝试不应该再像以前那样把官僚军事机器从一些人的手里转到另一些人的手里，而应该**把它打碎**，这正是大陆上任何一次真正的人民革命的先决条件。

> "把官僚军事国家机器打碎"这几个字，已经简要地表明了马克思主义关于无产阶级在革命中在对待国家方面的任务问题的**主要教训**。

## 3.2 用什么东西来代替被打碎的国家机器（**本章核心**）

### 这一步干什么
列出公社的四项措施，然后**把它们连起来看**，得出"量转化为质"。

### 论证结构

**第一步：先交代方法——马克思不陷于空想**
```
在《共产党宣言》（1847）中，回答还十分抽象：以"无产阶级组织成为统治阶级"来代替，
以"争得民主"来代替 —— 这只是指出了任务，没有指出解决任务的方法
马克思并没有陷于空想，而是期待群众运动的经验来解答
```

**第二步：摆出公社的措施（马克思《法兰西内战》的引文）**
```
① 废除常备军而代之以武装的人民（公社的第一个法令）
② 公社由巴黎各区普选选出的市政委员组成，对选民负责，随时可以撤换
   其中大多数自然都是工人或公认的工人阶级代表
③ 警察不再是中央政府的工具，立刻被免除政治职能
   变为公社的承担责任的、随时可以撤换的工作人员
   其他各行政部门的官员也是一样
④ 从公社委员起，自上至下一切公职人员，都只能领取相当于工人工资的报酬
   从前国家的高官显宦所享有的一切特权以及公务津贴，都随着这些人物本身的消失而消失了
⑤ 摧毁作为压迫工具的精神力量即僧侣势力；法官的虚假独立性被取消
   今后均由选举产生，对选民负责，并且可以撤换
```

**第三步：列宁的提炼——"量转化为质"**
```
公社用来代替被打碎的国家机器的，似乎"仅仅"是更完全的民主
       ↓
但是这个"仅仅"，事实上意味着两类根本不同的机构的大更替
       ↓
在这里恰巧看到了一个"量转化为质"的例子：
民主实行到一般所能想象的最完全最彻底的程度
       → 就由资产阶级民主转化成无产阶级民主
       → 即由国家（＝对一定阶级的特殊的镇压力量）
         转化成一种已经不是原来意义上的国家的东西
       ↓
【为什么】镇压资产阶级及其反抗仍然必要（公社失败的原因之一就是这方面做得不够坚决）
          但实行镇压的机关在这里已经是居民的多数
          而不像过去奴隶制、农奴制、雇佣奴隶制时代那样总是居民的少数
       ↓
既然是人民这个大多数自己镇压他们的压迫者，实行镇压的"特殊力量"也就不需要了！
       ↓
国家就在这个意义上开始消亡
       ↓
大多数人可以代替享有特权的少数人的特殊机构，自己来直接行使这些职能
国家政权职能的行使愈是全民化，这个国家政权就愈不需要了
```

**第四步：为什么"薪金 = 工人工资"这一条最被忘记**
```
马克思着重指出的这项措施：取消公务津贴和金钱特权，把报酬减到"工人工资"水平
→ 这里最明显地表现出转变：
   从资产阶级民主 → 无产阶级民主
   从压迫者的民主 → 被压迫阶级的民主
   从国家这个"特殊力量" → 由大多数人用共同力量镇压压迫者
→ 正是在这最重要的一点上，人们把马克思的教训忘得最干净
→ 通俗的解释不提这一点，把它看作过时的"幼稚的东西"
   正如基督教徒在获得国教地位以后，把早期基督教的"幼稚的东西""忘记了"一样
【为什么是"原始的"民主？】
   伯恩施坦嘲笑"原始的"民主制度，他完全不懂得：
   第一，如果不在某种程度上"返回"到"原始的"民主制度，从资本主义过渡到社会主义
         是不可能的（否则怎么过渡到由大多数居民乃至全体居民行使国家职能？）
   第二，以资本主义和资本主义文化为基础的"原始民主制度"，
         同原始时代或资本主义以前时代的原始民主制度是不一样的
         ——资本主义文化创立了大生产（工厂、铁路、邮政、电话等）
           在这个基础上，旧的"国家政权"的大多数职能已经变得极其简单
           可以简化为登记、记录、检查这样一些极其简单的手续
           以致每一个识字的人都完全能够胜任
           行使这些职能只须付给普通的"工人工资"
```

### 逻辑要害（四个，全部重要）

**（1）"量转化为质"是本章的解释引擎。**
单看每一项措施，都"只不过"是民主改革——废除常备军、选举撤换、降低薪金。**但列宁问的是：这些加起来意味着什么？**

> 答案是：**镇压者从少数变成多数了。**
> 少数人镇压多数人 → 必须有一支脱离人民的特殊武装和官吏队伍
> 多数人镇压少数人 → 不需要特殊机器，武装的人民自己就够了

**这就是"质"的变化。** 国家之所以是国家，靠的就是那支"特殊的力量"（`1.2`）；一旦不需要它了，就"不是原来意义上的国家"了。

**（2）"基督教在获得国教地位以后"这个类比极狠。**
它把"忘记马克思教训"解释为**一种有规律的社会现象**：革命学说一旦被接纳为主流，它的革命棱角就会被磨掉。这和第一章开头"把他们变为无害的神像，赋予他们的名字某种荣誉"是同一个观察。

**（3）"返回原始民主"这个说法，是预先堵住"这是倒退"的指责。**
列宁自己提出这个质疑（伯恩施坦的嘲笑），然后分两点回答：① 不返回不行；② 但此"原始"非彼"原始"，因为有大生产的技术基础。**这是列宁最典型的"自己设问—自己回答"节奏。**

**（4）注意"邮政"这个比喻的地位。**
```
邮政 = 按国家资本主义垄断组织样式组成的经济
     → 管理社会事务的机构在这里已经准备好了
     → 只要推翻资本家、粉碎反抗、摧毁官僚机器
     → 我们就有一个除掉了"寄生物"而技术装备程度很高的机构
     → 它完全可以由联合起来的工人自己使用
```
**这个例子的战术作用**：它证明"取消官吏"不是空想——**因为资本主义自己已经把管理简化到"任何一个识字的人都能胜任"了。**

### 抓手句
> 公社的第一个法令就是**废除常备军而代之以武装的人民**。

> 从公社委员起，自上至下一切公职人员，都只能领取**相当于工人工资**的报酬。

> 这个"仅仅"，事实上意味着两类根本不同的机构的大更替。在这里恰巧看到了一个"**量转化为质**"的例子：民主实行到一般所能想象的最完全最彻底的程度，就由资产阶级民主转化成无产阶级民主，即由国家转化成一种已经不是原来意义上的国家的东西。

> **既然是人民这个大多数自己镇压他们的压迫者，实行镇压的"特殊力量"也就不需要了！**

> 国家政权职能的行使愈是全民化，这个国家政权就愈不需要了。

> 公社实现了所有资产阶级革命都提出的**廉价政府**这一口号，因为它取消了两个最大的开支项目，即军队和国家官吏。

## 3.3 取消议会制

### 这一步干什么
处理公社的第三项制度变革——**用"实干的机构"代替清谈馆**。

### 论证结构
```
【马克思的原文】
   "公社是一个实干的而不是议会式的机构，它既是行政机关，同时也是立法机关。
    普选制不是为了每三年或六年决定一次由统治阶级中什么人在议会里代表和镇压人民，
    而是为了服务于组织在公社里的人民，
    正如个人选择权服务于任何一个为自己企业招雇工人、监工和会计的雇主一样。"
【列宁的两点说明】
   ① 马克思善于无情地摒弃无政府主义
      ——鄙视它甚至不会利用资产阶级议会这个"畜圈"，特别在显然不具备革命形势的时候
   ② 同时马克思又善于给议会制一种真正革命无产阶级的批评
【资产阶级议会制的本质】
   每隔几年决定一次由统治阶级中什么人在议会里镇压人民、压迫人民
   ——不仅在议会制立宪君主国内是这样，在最民主的共和国内也是这样
   → 真正的"国家"工作是在幕后做的，由各部、官厅和司令部进行
     议会专门为了愚弄"老百姓"而从事空谈
【出路何在】
   不在于取消代表机构和选举制
   而在于把代表机构由清谈馆变为"实干的"机构
   → 议员必须亲自工作，亲自执行自己通过的法律
     亲自检查实际执行的结果，亲自对自己的选民直接负责
   → 代表机构仍然存在，然而议会制这种特殊的制度、
     这种立法和行政的分工、这种议员们享有的特权地位，在这里是不存在的
【关键原则】
   没有代表机构，我们不可能想象什么民主，即使是无产阶级民主
   而没有议会制，我们却能够想象和应该想象
【马克思的比喻】拿"任何一个雇主"招雇"工人、监工和会计"来比喻
   → 这说明马克思没有丝毫的空想主义
     他没有虚构"新"社会，而是把从旧社会诞生新社会的过程作为自然历史过程来研究
【分寸】要一下子、普遍地、彻底地取消官吏，是谈不到的。这是空想
        但是一下子打碎旧的官吏机器，立刻开始建立一个新的机器来逐步取消任何官吏
        ——这并不是空想，这是公社的经验
```

### 逻辑要害

**（1）"不是取消代表机构，而是改变它的性质"——又是"重新定义"战术。**
对手会问："你要取消议会？那不是无政府主义吗？" 列宁答：**我们要的是代表机构，不是议会制。** 一字之差，指控就落空了。

**（2）列宁同时打击两个方向的对手：**
- 对无政府主义者：你们连议会这个"畜圈"都不会利用，在革命形势不具备时白白放弃阵地
- 对机会主义者：你们把议会当成一切，看不到它只是清谈馆

**"左右开弓"是列宁论战的常态。**

**（3）"一下子打碎旧的 vs 一下子取消官吏"这个分寸极重要。**
```
立刻做：打碎旧的官吏机器        ── 可以做，且必须做
空想  ：一下子普遍彻底取消官吏  ── 做不到，也不该想
中间路：打碎旧的 + 立刻开始建新的 + 逐步取消任何官吏
```
**这是全书最精密的一处"分寸"**，它同时回击了机会主义（不敢打碎）和无政府主义（想一天取消）。

### 抓手句
> 公社是一个**实干的而不是议会式的**机构，它既是行政机关，同时也是立法机关。

> 每隔几年决定一次由统治阶级中什么人在议会里**镇压人民、压迫人民**，——这就是资产阶级议会制的真正本质。

> 摆脱议会制的出路，当然不在于取消代表机构和选举制，而在于**把代表机构由清谈馆变为"实干的"机构**。

> 没有代表机构，我们不可能想象什么民主，即使是无产阶级民主；**而没有议会制，我们却能够想象和应该想象**。

> 要一下子打碎旧的官吏机器，立刻开始建立一个新的机器来逐步取消任何官吏，这并不是空想，这是公社的经验。

## 3.4 组织起民族的统一

### 这一步干什么
**预先驳斥一个必来的指责**：你们要打碎国家机器，那不是要破坏民族统一、搞分裂吗？

### 论证结构
```
【马克思的原文】
   "仍须留待中央政府履行的为数不多但很重要的职能，则不会像有人故意胡说的那样加以废除，
    而应该交给公社的官吏，即交给那些严格负责的官吏。
    民族的统一不是应该破坏，相反地应该借助于公社制度组织起来……"
   "旧政府权力的纯属压迫性质的机关予以铲除，
    而旧政府权力的合理职能则从僭越和凌驾于社会之上的当局那里夺取过来，
    归还给社会的负责的公仆。"
【列宁的推进：集中制 vs 联邦制】
   马克思同蒲鲁东和巴枯宁不同的地方，恰巧就在联邦制问题上
   → 联邦制在原则上是从无政府主义的小资产阶级观点产生出来的
   → 马克思是主张集中制的，他在上述论述中丝毫没有离开集中制
   → 只有对国家充满市侩"迷信"的人，才会把消灭资产阶级国家机器看成消灭集中制
【正面的集中制是什么】
   无产阶级和贫苦农民把政权掌握在自己手中，十分自由地按公社体制组织起来
   把所有公社的行动统一起来去打击资本，粉碎资本家的反抗
   把铁路、工厂、土地以及其他私有财产交给整个民族、整个社会
   → 难道这不是集中制吗？难道这不是最彻底的民主集中制、而且是无产阶级的集中制吗？
【伯恩施坦的误解】他根本不会想到可能有自愿的集中制
                   以为集中制只能从上面、只能由官吏和军阀强迫实行和维持
【马克思为什么用"组织起民族的统一"这个说法】
   马克思似乎预料到会有人歪曲他的观点，所以特意着重指出
   如果非难公社要破坏民族统一、废除中央政权，那就是故意捏造
   他特意使用"组织起民族的统一"这样的说法
   以便提出自觉的、民主的、无产阶级的集中制
   来同资产阶级的、军阀的、官吏的集中制相对立
```

### 逻辑要害

**（1）"铲除压迫机关"与"归还合理职能"——这组区分是核心。**
```
被铲除：旧政府权力的纯属压迫性质的机关
被保留：合理职能（从僭越的当局那里夺取，归还给社会的负责的公仆）
```
**这就把"打碎"从"无政府主义的破坏"精确定义为"有选择的改造"。**

**（2）"自愿的集中制 vs 官吏军阀的集中制"——又是一对重新定义。**
对手把集中制等同于"官僚强制"，列宁说：**集中制有两种。** 无产阶级的集中制是各公社**自愿**统一为一个民族。

**（3）"马克思似乎预料到会有人歪曲"——这是列宁常用的陈述方式。**
它暗示：**马克思的话本身就是为反驳今天的歪曲而写的。** 这是一种极强的论证姿态：不是我在辩解，是马克思早就防着你们了。

**（4）马克思的一句方法论名言也在这里：**
> "全新的历史创举都要遭到被误解的命运，即只要这种创举与旧的、甚至已经死亡的社会生活形式可能有某些相似之处，它就会被误认为是那些社会生活形式的翻版。"

→ 公社被误认为"中世纪公社的再现""许多小邦的联盟"。**这句话同时也是一个普遍规律：新事物总被用旧范畴理解。**

### 抓手句
> **民族的统一不是应该破坏，相反地应该借助于公社制度组织起来。**

> 旧政府权力的**纯属压迫性质的机关予以铲除**，而旧政府权力的**合理职能**则从僭越和凌驾于社会之上的当局那里夺取过来，归还给社会的负责的公仆。

> 只有对国家充满市侩"迷信"的人们，才会把消灭资产阶级国家机器看成是**消灭集中制**！

> 马克思特意使用"组织起民族的统一"这样的说法，以便提出**自觉的、民主的、无产阶级的集中制**来同**资产阶级的、军阀的、官吏的集中制**相对立。

## 3.5 消灭寄生虫式的国家

### 这一步干什么
把前面的措施归结到"廉价政府"和"消灭寄生物"这个总账上，并落到**俄国革命的直接任务**。

### 论证结构
```
【马克思的原话】
   "公社实现了所有资产阶级革命都提出的廉价政府这一口号
    因为它取消了两个最大的开支项目，即军队和国家官吏。"
【为什么农民也支持这个】
   农民同小资产阶级其他阶层一样，只有极少数人能"上升"、"出人头地"
   大多数农民是受政府压迫而渴望推翻这个政府、渴望有一个"廉价"政府的
   → 能够实现这一要求的只有无产阶级
     无产阶级实现了这一要求，也就是向国家的社会主义改造迈进了一步
【资本主义准备好的技术条件】
   资本主义使"国家"管理的职能简化了，使我们有可能抛弃"长官职能"
   把全部问题归结为无产者组织起来（成为统治阶级）以全社会名义招雇"工人、监工和会计"
【拒绝无政府主义幻想】
   我们不是空想主义者，并不"幻想"一下子就可以不要任何管理、不要任何服从
   这种无政府主义幻想与马克思主义根本不相容
   实际上只会把社会主义革命拖延到人们变成另一种人的时候
   → 我们希望由现在的人来实行社会主义革命
     而现在的人没有服从、没有监督、没有"监工和会计"是不行的
   → 但所需要的服从，是对一切被剥削劳动者的武装先锋队——无产阶级的服从
【具体任务】
   国家官吏的特殊"长官职能"可以并且应该立即开始、在一天之内就开始
   用"监工和会计"的简单职能来代替
   这些职能现在只要有一般市民的水平就完全能够胜任
   行使这些职能只须付给"工人工资"就完全可以了
【目标】我们工人自己将以资本主义创造的成果为基础，依靠自己的工人的经验
        建立由武装工人的国家政权维护的最严格的铁的纪律，来组织大生产
        把国家官吏变成我们的委托的简单执行者
【前景】在大生产的基础上，这个开端自然会导致任何官吏逐渐"消亡"
        使一种不带引号的、与雇佣奴隶制不同的秩序逐渐建立起来
        在这种秩序下，日益简化的监督职能和填制表报的职能将由所有的人轮流行使
        然后将成为一种习惯，最后就不再成其为特殊阶层的特殊职能了
```

### 逻辑要害

**（1）"廉价政府"这个口号是战术性的。**
它出自资产阶级革命，公社实现了它。**列宁用它来争取农民**——农民不懂国家学说，但懂"廉价政府"。**这是把抽象纲领翻译成群众听得懂的话。**

**（2）"不是空想主义者"这一整段是全书最务实的一段。**
列宁明确划界：
```
空想：一下子不要任何管理、任何服从
现实：由现在的人（不是改造过的人）来革命
     所以还需要监督、监工、会计、铁的纪律
     但服从的对象换了——服从无产阶级的武装先锋队
```
**这段同时在打无政府主义和打机会主义（后者连"打碎"都不敢）。**

**（3）"由所有的人轮流行使 → 成为一种习惯"——这是"消亡"机制的具体描述。**
国家消亡不是某一天宣布的，而是：
```
职能简化 → 人人能做 → 轮流做 → 成为习惯 → 不再是特殊职能
```
**这个链条在第五章还会再讲一次（`5.5`），是全书关于"消亡"的落地说明。**

### 抓手句
> 公社实现了所有资产阶级革命都提出的**廉价政府**这一口号，因为它取消了两个最大的开支项目，即军队和国家官吏。

> 我们不是空想主义者。我们并不"幻想"一下子就可以不要任何管理，不要任何服从。

> 国家官吏的特殊"长官职能"可以并且应该立即开始、在一天之内就开始用"**监工和会计**"的简单职能来代替。

## 3.6 公社是"终于发现的"政治形式

### 这一步干什么
**收束全章**，给公社定性，并把它接到俄国革命上。

### 论证结构
```
【马克思的原话】
   "公社的真正秘密就在于：它实质上是工人阶级的政府，
    是生产者阶级同占有者阶级斗争的产物，
    是终于发现的可以使劳动在经济上获得解放的政治形式。"
【马克思没有做什么】
   马克思并没有去发现这个未来的政治形式
   他只是对法国历史作了精确的观察、进行了分析
   → 事情已到了破坏资产阶级国家机器的地步（1851年的结论）
   → 当群众革命运动已经爆发的时候，他就来研究这个运动究竟发现了什么样的形式
      虽然这个运动遭到了挫折、为期很短而且有显著的弱点
【对比三种态度】
   空想主义者：致力于"发现"可以对社会进行社会主义改造的各种政治形式
   无政府主义者：根本不考虑政治形式问题
   机会主义者：把议会制民主国家的资产阶级政治形式当作不可逾越的极限
               宣布摧毁这些形式的任何意图都是无政府主义
   马克思：不从先验出发，而从实际运动的经验中看出形式
【列宁的定性】
   公社就是无产阶级革命"终于发现的"可以使劳动在经济上获得解放的形式
   公社就是无产阶级革命打碎资产阶级国家机器的第一次尝试
   和"终于发现的"、可以而且应该用来代替已被打碎的国家机器的政治形式
【接到俄国】
   俄国1905年革命和1917年革命在另一个环境和另一种条件下继续着公社的事业
   证实着马克思这种天才的历史的分析
```

### 逻辑要害

**这一节最重要的，是"马克思没有去发现政治形式"这一句。**
它确立了一个方法论原则，也划清了三条界线：

| | 对政治形式的态度 |
|---|---|
| 空想主义者 | 自己**发明**形式 |
| 无政府主义者 | **不考虑**形式 |
| 机会主义者 | 把资产阶级形式当作**极限** |
| **马克思** | 从**群众运动的实际经验**中看出形式 |

> **这和《共产党宣言》里"我们不提出任何特殊的原则来塑造无产阶级运动"是同一条原则：** 理论不发明，只表述。

**"终于发现的"这四个字的分量：** 它不是说公社是完美的，而是说**它是历史第一次提供的答案**——所以才有 1905、1917 的"继续"。

### 抓手句
> 公社的真正秘密就在于：它实质上是**工人阶级的政府**，是生产者阶级同占有者阶级斗争的产物，是**终于发现的可以使劳动在经济上获得解放的政治形式**。

> 马克思并没有去发现这个未来的政治形式。他只是对法国历史作了精确的观察，对它进行了分析。

> 公社就是无产阶级革命打碎资产阶级国家机器的**第一次尝试**和"终于发现的"、可以而且应该用来代替已被打碎的国家机器的政治形式。

## 第三章逻辑回顾

```
3.1  方法论  ── 马克思向群众运动学习，不作学究式训诫；"打碎"是主要教训
3.2  四项措施 ── 废常备军 / 选举+随时撤换 / 工人工资 / 摧毁精神压迫工具
              → 量转化为质：镇压者由少数变多数 → 不需要特殊力量 → 开始消亡
3.3  取消议会制 ── 清谈馆 → 实干机构；不是取消代表机构
3.4  民族的统一 ── 铲除压迫机关、保留合理职能；自愿的集中制 vs 军阀的集中制
3.5  廉价政府  ── 消灭寄生物；不是空想（需要监工会计）；职能简化 → 习惯 → 消亡
3.6  定性      ── 公社是"终于发现的"政治形式；马克思不发明，只从经验中看出
```

**一句话串起来**：公社的答案不是一项新发明，而是把民主推到极致——武装人民、可撤换的公仆、工人工资、实干的机构——推到极致之后，压��者就从少数变成了多数，国家就不再是国家了。

# 【4】续前·恩格斯的补充说明

**整章任务**：**亡**（上）——回答"这个新国家是什么性质"。
**整章写法**：**按文献逐篇梳理**恩格斯的补充（住宅问题 → 反无政府主义 → 给倍倍尔的信 → 爱尔福特纲领批判 → 1891 年导言 → 论民主制消除）。

> **为什么要有这一章？** 因为马克思在 1871 年只给出了"公社做了什么"，还需要在理论上说清：**这个新东西还算不算国家？** 恩格斯在不同场合的补充回答了这个问题。

## 4.1 《住宅问题》：过渡时期仍需要国家形式

### 论证结构
```
【恩格斯的原文】
   "社会革命将怎样解决住宅问题呢？这不仅要以当时的情况为转移
    而且也同一些意义深远的问题有关，其中最重要的问题之一就是消灭城乡对立。
    既然我们不必为构建未来社会臆造种种空想方案，探讨这个问题也就是完全多余的了。
    但有一点是肯定的，现在各大城市中有足够的住房，只要合理使用
    就可以立即解决现实的住房短缺问题。
    当然，要实现这一点，就必须剥夺现在的房主……
    只要无产阶级取得了政权，这种具有公共福利形式的措施
    就会像现代国家剥夺其他东西和征用民宅那样容易实现了。"
【列宁的分析】
   这里没有考察国家政权形式的改变，只谈到国家政权活动的内容
   剥夺和占据住宅是根据现今国家的命令进行的
   无产阶级的国家，从形式上来讲，也会"下令"占据住宅和剥夺房屋
   但是很明显，旧的执行机构，即同资产阶级相联系的官吏机构
   是根本不能用来执行无产阶级国家的命令的
【关于出租】
   恩格斯非常谨慎，他说无产阶级国家"至少在过渡时期难以"免费分配住宅
   把属于全民的住宅租给单个家庭，就既要征收租金，又要实行一定的监督
   还要规定分配住宅的某种标准
   → 这一切都需要有一定的国家形式
     但决不需要那种公职人员享有特权地位的特殊的军事和官僚机构
   → 至于过渡到免费分配住宅，那是与国家的完全"消亡"联系着的
【关于占有】
   "由劳动人民实际占有全部劳动工具和拥有全部工业，是同蒲鲁东主义的'赎买'完全相反的"
   "消灭地产并不要求消灭地租，而是要求把地租——虽然形式发生变化——转交给社会"
   → 所以，由劳动人民实际占有全部劳动工具，决不排除保存租赁关系
```

### 逻辑要害

**（1）这一节的作用是"降温"。**
前面第三章刚讲完公社的光辉措施，这一节立刻说：**过渡时期还得收租金、还得监督、还得有国家形式。** 列宁是在防止读者把"打碎国家机器"理解成"明天就无政府了"。

**（2）"需要一定的国家形式，但决不需要那种特殊的军事和官僚机构"——这是全章的总判词。**
```
需要：国家形式（因为有分配、有监督、有强制）
不需要：官吏的特权地位、特殊的军事和官僚机构
```
**这个区分就是"半国家"的确切含义**，后面 `4.3` 会给出正式命名。

**（3）注意"恩格斯非常谨慎"这个评价。**
列宁反复强调恩格斯的谨慎（"至少在过渡时期难以"），是在**树立一个标杆**：连恩格斯都不敢空想，那些空谈的人算什么。这与第五章"我们只能谈消亡的必然性，把日期作为悬案"是一贯的。

### 抓手句
> 旧的执行机构，即同资产阶级相联系的官吏机构，是根本不能用来执行无产阶级国家的命令的。

> 这一切都需要有一定的国家形式，但**决不需要那种公职人员享有特权地位的特殊的军事和官僚机构**。

> 至于过渡到免费分配住宅，那是与国家的完全"消亡"联系着的。

## 4.2 同无政府主义者的论战：权威、自治与革命

### 这一步干什么
**定义"我们和无政府主义者的分歧到底在哪"**——这是全书最容易被误解的一节。

### 论证结构
```
【先划清共同点】
   国家会随着阶级的废除而废除，马克思主义向来就是这样教导的
   《反杜林论》里关于"国家消亡"的论述，并不是简单地斥责无政府主义者主张废除国家
   而是斥责他们鼓吹可以"在一天之内"废除国家
【马克思的分歧点】
   马克思完全不是反对国家将随阶级消失而消失
   而是反对要工人拒绝使用武器、拒绝使用有组织的暴力
   即拒绝使用应为"粉碎资产阶级的反抗"这一目的服务的国家
   → 马克思故意着重指出无产阶级所必需的国家具有"革命的暂时的形式"
   【精确表述】
   在废除国家是目的这个问题上，我们和无政府主义者完全没有分歧
   我们所断言的是，为了达到这个目的，就必须暂时利用国家权力的工具、手段、方法
   去反对剥削者，正如为了消灭阶级，就必须实行被压迫阶级的暂时专政一样
   → 马克思的问题提得非常尖锐：工人在推翻资本家的压迫时
     应当"放下武器"呢，还是应当利用它来反对资本家以粉碎他们的反抗？
     一个阶级有系统地利用武器反对另一个阶级，这不是国家的"暂时的形式"又是什么呢？
【恩格斯的展开：权威与自治】
   先讥笑"反权威主义者"否认任何权威、任何服从、任何权力
   → 拿工厂、铁路、在汪洋大海上航行的轮船来说
     这是一些使用机器的、很多人有计划地共同工作的复杂技术设施
     如果没有一定的服从，因而没有一定的权威或权力，那就没有一样能够开动起来
   → 反权威主义者说：我们说的不是权威，而是"委托"
   → 恩格斯：这些先生以为，只要改变一下某一事物的名称，就可以改变这一事物本身
   【恩格斯的精确立场】
   权威和自治都是相对的概念，它们的应用范围是随着社会发展阶段的不同而改变的
   把它们看做绝对的东西是荒谬的
   → 如果自治论者仅仅是想说，未来的社会组织将只在生产条件所必然要求的限度内
     允许权威存在，那也许还可以同他们说得通
     但是他们闭眼不看使权威成为必要的种种事实，只是拼命反对字眼
【关键一击】
   "为什么反权威主义者不只限于高喊反对政治权威，反对国家呢？
    所有的社会主义者都认为，国家以及政治权威将由于未来的社会革命而消失……
    但是，反权威主义者却要求在产生政治国家的各种社会条件消除以前
    一举把政治国家废除。他们要求把废除权威作为社会革命的第一个行动。
    这些先生见过革命没有？
    革命无疑是天下最权威的东西。革命就是一部分人用枪杆、刺刀、大炮，
    即用非常权威的手段强迫另一部分人接受自己的意志。
    获得胜利的政党迫于必要，不得不凭借它以武器对反动派造成的恐惧来维持自己的统治。
    要是巴黎公社面对资产者没有运用武装人民这个权威，它能支持哪怕一天吗？
    反过来说，难道我们没有理由责备公社把这个权威用得太少了吗？
    总之，二者必居其一。或者是反权威主义者自己不知所云……
    或者他们是知道的，如果是这样，那他们就背叛了无产阶级的事业。
    在这两种情况下，他们都只是为反动派效劳。"
【列宁的总结】
   无政府主义者不愿看见的，正是革命的产生和发展
   正是革命在对待暴力、权威、政权、国家方面的特殊任务
   现代社会民主党人对无政府主义的批评，可以归结为十足的市侩式庸俗论调：
   "我们承认国家，而无政府主义者不承认！"
   → 恩格斯就不是这样谈问题的
     他着重指出，所有的社会主义者都承认国家的消失是社会主义革命的结果
     然后他具体地提出革命的问题
     （这个问题恰巧是机会主义的社会民主党人通常避而不谈
       而可以说是把它留给无政府主义者去专门"研究"的）
   → 恩格斯一提出这个问题就抓住了关键：
     公社难道不应该更多地运用国家即武装起来并组织成为统治阶级的无产阶级这个革命政权吗？
```

### 逻辑要害（本节极重要，四条）

**（1）"目的上没有分歧，手段上才有分歧"——这是列宁论战的定式。**
```
共同：都主张废除国家（目的）
分歧：是否要暂时利用国家（手段）
```
**这个句式把对手拉进了半程**：你说要废除国家？好，我们也这么想。那问题就只剩"怎么达到"了——而在这个问题上，无政府主义站不住脚。

**（2）"只要改变一下某一事物的名称，就可以改变这一事物本身"——这句讽刺值得单独记。**
它是对"换名词"式理论（叫"委托"就不叫权威了）的经典驳斥，可以用在很多场合。

**（3）"革命无疑是天下最权威的东西"——这是全书传播最广的句子之一。**
**它的论证力量在于把"权威"从抽象概念拉回到具体场景**：你反对权威？那你告诉我，公社靠什么维持了一天？

**（4）列宁最后那一笔极狠：机会主义者把"革命问题"留给无政府主义者去"研究"。**
意思是：**正牌社会民主党人不敢谈革命，于是只有无政府主义者在谈暴力、权威、政权——这就把工人推给了无政府主义。** 这解释了为什么无政府主义在工人中有影响：**不是因为它对，是因为正统派放弃了这块阵地。**

### 抓手句
> 在废除国家是目的这个问题上，我们和无政府主义者**完全没有分歧**。我们所断言的是，为了达到这个目的，就必须**暂时**利用国家权力的工具、手段、方法去反对剥削者。

> 马克思故意着重指出无产阶级所必需的国家具有"**革命的暂时的形式**"。

> 这些先生以为，只要改变一下某一事物的名称，就可以改变这一事物本身。

> **革命无疑是天下最权威的东西。** 革命就是一部分人用枪杆、刺刀、大炮，即用非常权威的手段强迫另一部分人接受自己的意志。

> 要是巴黎公社面对资产者**没有运用武装人民这个权威，它能支持哪怕一天吗**？反过来说，难道我们没有理由责备公社把这个权威用得太少了吗？

## 4.3 给倍倍尔的信："巴黎公社已经不是原来意义上的国家"

### 这一步干什么
**给新国家正式定性。** 这是第四章的核心判断。

### 论证结构
```
【恩格斯的原话】（1875年给倍倍尔的信，批判"自由的人民国家"）
   "自由的人民国家变成了自由国家。从字面上看，自由国家就是可以自由对待本国公民的国家
    即具有专制政府的国家。应当抛弃这一切关于国家的废话
    特别是出现了已经不是原来意义上的国家的巴黎公社以后。
    无政府主义者用'人民国家'这个名词把我们挖苦得很够了……
    既然国家只是在斗争中、在革命中用来对敌人实行暴力镇压的一种暂时的设施
    那么，说自由的人民国家，就纯粹是无稽之谈了：
    当无产阶级还需要国家的时候，它需要国家不是为了自由，而是为了镇压自己的敌人
    一到有可能谈自由的时候，国家本身就不再存在了。
    因此，我们建议把国家一词全部改成'共同体'(Gemeinwesen)
    这是一个很好的古德文词，相当于法文的'公社'。"
【列宁的阐释】
   "巴黎公社已经不是原来意义上的国家"，——这是恩格斯在理论上最重要的论断
   看了上文以后，这个论断是完全可以理解的：
   ① 公社所要镇压的不是大多数居民，而是少数居民（剥削者）
   ② 它已经打碎了资产阶级的国家机器
   ③ 居民已经自己上台来代替特殊的镇压力量
   → 所有这一切都已经不是原来意义上的国家了
【消亡的机制】
   如果公社得到巩固，那么公社的国家痕迹就会自行"消亡"
   它就用不着"废除"国家机构，因为国家机构将无事可做而逐渐失去其作用
```

### 逻辑要害

**（1）"已经不是原来意义上的国家"——这是全书给新国家的正式命名。**
列宁后来的术语是"**半国家**"（`1.4` 已用过这个说法）。这个"半"字极其精确：
```
是：还要镇压（剥削者还在反抗）→ 还有强制
不是：镇压的是少数、执行者是多数、没有特权官吏 → 不需要特殊力量
```

**（2）"当无产阶级还需要国家的时候，它需要国家不是为了自由，而是为了镇压自己的敌人"——这句是全书最锋利的一句之一。**
它把"自由"和"国家"彻底对立起来：**有国家就没有自由，有自由就没有国家。** 这一句在第五章末尾还会再响一次（见 `5.4`）。

**（3）恩格斯建议改词："共同体"（Gemeinwesen，相当于法文"公社"）。**
**这不是文字游戏。** 列宁把它作为"巴黎公社已不是原来意义上的国家"的证据：**连恩格斯都觉得该换个词了。**

### 抓手句
> 特别是出现了**已经不是原来意义上的国家的巴黎公社**以后。

> 当无产阶级**还需要**国家的时候，它需要国家**不是为了自由，而是为了镇压自己的敌人**，一到有可能谈自由的时候，国家本身就不再存在了。

> "巴黎公社已经不是原来意义上的国家"，——这是恩格斯在理论上最重要的论断。

> 它就用不着"废除"国家机构，因为**国家机构将无事可做而逐渐失去其作用**。

## 4.4 对爱尔福特纲领草案的批判：民主共和国与集中制

### 论证结构
```
【恩格斯的原文】
   "……如果说有什么是毋庸置疑的，那就是，我们的党和工人阶级
    只有在民主共和国这种政治形式下，才能取得统治。
    民主共和国甚至是无产阶级专政的特殊形式，法国大革命已经证明了这一点。……"
   （恩格斯还批评了把"一般的抽象的政治问题提到首要地位"
     从而掩盖紧迫的具体问题的做法
     并指出"'真诚的'机会主义也许比其他一切机会主义更危险"）
【列宁的阐释】
   恩格斯特别明确地重申了贯穿在马克思一切著作中的基本思想：
   民主共和国是走向无产阶级专政的捷径
   因为这样的共和国虽然丝毫没有消除资本的统治
   因而也丝毫没有消除对群众的压迫和阶级斗争
   但是，它必然会使这个斗争扩大、展开、明朗化和尖锐化
   以致一旦出现满足被压迫群众根本利益的可能性
   这种可能性就必然通过而且只有通过无产阶级专政即无产阶级对这些群众的领导得到实现
【集中制 vs 联邦制（接第三章 3.4）】
   恩格斯同马克思一样，从无产阶级和无产阶级革命的观点出发
   坚持民主集中制，坚持单一而不可分的共和国
   他认为联邦制共和国或者是一种例外、是发展的障碍
   或者是由君主国向集中制共和国的过渡，是在一定的特殊条件下的"一个进步"
   而在这些特殊条件中，民族问题占有突出的地位
   → 恩格斯对国家形式问题不但不抱冷淡态度
     相反，他非常细致地努力去分析的正是过渡形式
     以便根据每一个别场合的具体历史特点来弄清各该场合的过渡形式是从什么到什么的过渡
【推翻一个流行偏见】
   非常流行的偏见（特别是在小资产阶级民主派中间）：
   认为联邦制共和国一定要比集中制共和国自由
   → 这种看法是不正确的
   → 恩格斯所举的1792-1798年法兰西集中制共和国和瑞士联邦制共和国的事实推翻了这种偏见
   → 真正民主的集中制共和国赋予的自由比联邦制共和国要多
【恩格斯建议的党纲条文】
   "省（省或州）、县和市镇通过依据普选制选出的官员实行完全的自治。
    取消由国家任命的一切地方的和省的政权机关。"
【方法论】
   恩格斯对国家形式问题不但不抱冷淡态度
   相反，他非常细致地努力去分析的正是过渡形式
   以便根据每一个别场合的具体历史特点
   来弄清各该场合的过渡形式是从什么到什么的过渡
```

### 逻辑要害

**（1）"民主共和国是走向无产阶级专政的捷径"——注意"捷径"，不是"终点"。**
这和 `1.3` 的"民主共和制是资本主义最好的政治外壳"是**配套的一对**：
```
对资产阶级：民主共和国是最好的外壳（最稳固）
对无产阶级：民主共和国是捷径（阶级斗争最明朗、最尖锐）
```
**同一个制度，两种评价，取决于站在哪一边。** 这正是列宁"两步走"论证的典型（`1.4` 附）。

**（2）"'真诚的'机会主义也许比其他一切机会主义更危险"——这句话值得单独记。**
它点出一个规律：**动机真诚不等于路线正确**。恩格斯的原话是针对"为了眼前暂时的利益而忘记根本大计，为了运动的现在而牺牲运动的未来"。

**（3）"从什么到什么的过渡"——这是列宁提炼的恩格斯方法。**
```
不问：哪种形式最好？
要问：在这个具体历史场合，这是从什么到什么的过渡？
```
**这句话是理解全书"过渡形式"思路的钥匙**，也是第五章讲"过渡时期"的前奏。

**（4）"真正民主的集中制共和国赋予的自由比联邦制共和国要多"——这是反直觉的结论。**
列宁特意拿出历史事实（1792—1798 法兰西 vs 瑞士）来支撑。**它的作用是：把"集中制"从"官僚强制"的联想里解救出来。**

### 抓手句
> 民主共和国是**走向无产阶级专政的捷径**。

> 它必然会使这个斗争**扩大、展开、明朗化和尖锐化**。

> 真正民主的集中制共和国赋予的自由**比联邦制共和国要多**。

> 恩格斯……非常细致地努力去分析的正是**过渡形式**，以便根据每一个别场合的具体历史特点来弄清各该场合的过渡形式是从什么到什么的过渡。

## 4.5 1891 年为《法兰西内战》写的导言：防止公仆变主人

### 论证结构
```
【恩格斯的原文】
   "……工人阶级一旦取得统治权，就不能继续运用旧的国家机器来进行管理；
    工人阶级为了不致失去刚刚争得的统治
    一方面应当铲除全部旧的、一直被利用来反对工人阶级的压迫机器
    另一方面还应当保证本身能够防范自己的代表和官吏
    即宣布他们毫无例外地可以随时撤换。……"
【两个可靠的办法】
   "为了防止国家和国家机关由社会公仆变为社会主人
    ——这种现象在至今所有的国家中都是不可避免的——公社采取了两个可靠的办法。
    第一，它把行政、司法和国民教育方面的一切职位交给由普选选出的人担任
          而且规定选举者可以随时撤换被选举者。
    第二，它对所有公职人员，不论职位高低，都只付给跟其他工人同样的工资。
          公社所曾付过的最高薪金是6000法郎。
    这样，即使公社没有另外给代表机构的代表签发限权委托书
    也能可靠地防止人们去追求升官发财了。……"
【列宁的提炼：一个"有趣的界限"】
   恩格斯在这里接触到了一个有趣的界限
   在这个界限上，彻底的民主变成了社会主义，同时也要求实行社会主义
   因为：
   ① 要消灭国家就必须把国家机关的职能变为非常简单的监督和计算的手续
      使大多数居民，而后再使全体居民，都能够办理，都能够胜任
   ② 而要完全消除升官发财的思想，就必须使国家机关中那些无利可图但是"荣耀的"职位
      不能成为在银行和股份公司内找到肥缺的桥梁
      ——像在一切最自由的资本主义国家内所经常看到的那样
【一个必须避免的诡辩】
   有些马克思主义者说：民族自决权在资本主义下不可能实现，在社会主义下是多余的
   → 这种似乎很巧妙但实际上并不正确的论断
     对于任何一种民主制度（包括给官吏发微薄薪金的办法在内）都可以套得上
     因为在资本主义下彻底的民主制度是不可能的，而在社会主义下任何民主都是会消亡的
   → 这是一种诡辩，正像一句古老的笑话所说的：
     一个人掉了一根头发，他是否就成了秃子呢？
   【正确的态度】
   彻底发展民主，找出彻底发展的种种形式，用实践来检验这些形式等等
   这一切都是为社会革命进行斗争的基本任务之一
   任何单独存在的民主制度都不会产生社会主义
   但在实际生活中民主制度永远不会是"单独存在"，而总是"共同存在"的
   它也会影响经济，推动经济的改造，受经济发展的影响等等
   → 这就是活生生的历史辩证法
【"宗教对国家而言是私事"】
   恩格斯故意强调"对国家而言"这几个字
   目的是要击中德国机会主义的要害
   因为德国机会主义宣布宗教对党而言是私事
   这样也就把革命无产阶级政党降低到最庸俗的"自由思想派"那班市侩的水平
   ——这种市侩可以容许不信宗教
     但是拒绝执行对麻醉人民的宗教鸦片进行党的斗争的任务
```

### 逻辑要害

**（1）"防止社会公仆变为社会主人"——这是公社措施的理论内核。**
注意恩格斯的表述：**"这种现象在至今所有的国家中都是不可避免的"**。也就是说，**官僚化不是失误，是规律**——所以必须有制度性的对抗措施（选举撤换 + 工人工资）。

**（2）"彻底的民主变成了社会主义"——这是 `3.2` 那个"量转化为质"的第二次表述。**
```
民主推到彻底 → 职能简化到人人能做 → 消除升官发财的桥梁 → 就是社会主义
```
**注意这里多了一条新理由**：不只是"镇压者变成多数"，还有"**消除了升官发财的桥梁**"。

**（3）"一个人掉了一根头发，他是否就成了秃子呢？"——这个反驳值得单独记。**
它驳斥的是一类诡辩：**用"这个要求在资本主义下做不到、在社会主义下不需要"来否认定下的民主任务。** 列宁说：真正的民主从来不是"单独存在"的，它总是与经济改造交互作用。**这是"活生生的历史辩证法"对折中主义的又一次胜利**（对比 `1.4` 的折中主义批判）。

**（4）"宗教对国家而言是私事"中"对国家而言"五个字——这是列宁扣字眼的经典范例。**
同一个公式，加不加这五个字，含义完全相反：
```
对国家而言是私事  → 正确的（国家不干涉信仰）
对党而言是私事    → 背叛（党放弃反宗教斗争）
```

### 抓手句
> 为了防止国家和国家机关**由社会公仆变为社会主人**——这种现象在至今所有的国家中都是不可避免的——公社采取了**两个可靠的办法**。

> 恩格斯在这里接触到了一个有趣的界限，在这个界限上，**彻底的民主变成了社会主义**，同时也要求实行社会主义。

> 这是一种诡辩，正像一句古老的笑话所说的：一个人掉了一根头发，他是否就成了秃子呢？

> 任何单独存在的民主制度都不会产生社会主义，但在实际生活中民主制度永远不会是"单独存在"，而总是"共同存在"的……这就是**活生生的历史辩证法**。

## 4.6 恩格斯论民主制的消除：国家消亡 = 民主消亡

### 这一步干什么
**处理全书最反直觉的一个命题：民主也会消亡。**

### 论证结构
```
【列宁先指出普遍的错误】
   人们通常在谈论国家问题的时候，老是犯恩格斯所告诫的那个错误
   这就是：老是忘记国家的消灭也就是民主的消灭，国家的消亡也就是民主的消亡
【预设的反驳】
   这样的论断似乎是极端古怪而难于理解的
   甚至也许有人会担心：是不是我们在期待一个不遵守少数服从多数原则的社会制度
   因为民主也就是承认这个原则
【列宁的解答——一个精确的区分】
   不是的。民主和少数服从多数的原则不是一个东西。
   民主就是承认少数服从多数的国家，即一个阶级对另一个阶级、
   一部分居民对另一部分居民使用有系统的暴力的组织。
   → 我们的最终目的是消灭国家，也就是消灭任何有组织有系统的暴力
     消灭任何加在人们头上的暴力
   → 我们并不期待一个不遵守少数服从多数原则的社会制度
     但是，我们在向往社会主义的同时深信：社会主义将发展为共产主义
     而对人们使用暴力，使一个人服从另一个人、使一部分居民服从另一部分居民
     的任何必要也将随之消失
     因为人们将习惯于遵守公共生活的起码规则，而不需要暴力和服从
【恩格斯的支撑：新的一代】
   为了强调这个习惯的因素，恩格斯就说到了新的一代
   他们是"在新的自由的社会条件下成长起来的一代，有能力把这国家废物全部抛掉"
   ——这里所谓国家是指任何一种国家，其中也包括民主共和制的国家
【恩格斯的另一段（对国家迷信的批判）】
   "……按照哲学概念，国家是'观念的实现'
     或是译成了哲学语言的尘世的上帝王国
     也就是永恒的真理和正义所借以实现或应当借以实现的场所
     由此就产生了对国家以及一切同国家有关的事物的盲目崇拜……
     实际上，国家无非是一个阶级镇压另一个阶级的机器
     而且在这一点上民主共和国并不亚于君主国
     国家再好也不过是在争取阶级统治的斗争中获胜的无产阶级所继承下来的一个祸害
     胜利了的无产阶级也将同公社一样，不得不立即尽量除去这个祸害的最坏方面
     直到在新的自由的社会条件下成长起来的一代有能力把这国家废物全部抛掉。"
【一个必须的分寸】
   恩格斯说，在民主共和国，国家之为"一个阶级压迫另一个阶级的机器"
   "丝毫不亚于"在君主国
   但这决不等于说，压迫的形式对于无产阶级是无所谓的
   ——像某些无政府主义者所"教导"的那样
```

### 逻辑要害

**（1）"民主和少数服从多数的原则不是一个东西"——这是全书最需要精确记忆的一句。**
```
少数服从多数    → 是一个组织原则，共产主义下可能仍有类似的协调方式
民主            → 是一种国家，即"一个阶级对另一个阶级使用有系统的暴力的组织"
```
**这个区分一下子把"难道你们反对少数服从多数？"这个反问化解了。**

**（2）"民主共和国并不亚于君主国"——这是暗线 B 的关键节点。**
它把"民主"从"好东西"降格为"一种统治形式"：**形式上最民主的共和国，本质上和君主国一样是阶级压迫机器。**

**（3）但列宁立刻加了分寸："这决不等于说，压迫的形式对于无产阶级是无所谓的。"**
这是**左右开弓**的又一例：
- 向左（无政府主义）：压迫形式无所谓 → 错，形式很重要
- 向右（机会主义）：民主共和国就够了 → 错，本质没变

**（4）"习惯于遵守公共生活的起码规则"——这是"消亡"的心理学机制。**
```
不是：宣布废除国家
而是：人们习惯了遵守规则 → 不需要暴力 → 不需要强制机构 → 国家消亡
```
**这个机制在第五章 `5.5` 会更完整地展开。**

### 抓手句
> 老是忘记**国家的消灭也就是民主的消灭，国家的消亡也就是民主的消亡**。

> 民主和少数服从多数的原则不是一个东西。**民主就是承认少数服从多数的国家**，即一个阶级对另一个阶级、一部分居民对另一部分居民使用有系统的暴力的组织。

> 我们并不期待一个不遵守少数服从多数原则的社会制度。

> 人们将习惯于遵守公共生活的起码规则，而**不需要暴力，不需要强制，不需要服从**，不需要所谓国家这种实行强制的特殊机构。

> 国家再好也不过是在争取阶级统治的斗争中获胜的无产阶级所继承下来的**一个祸害**。

## 4.7 对国家迷信的批判 + 党的名称问题 〔补〕

### 论证结构
```
【党的名称】
   恩格斯指出："对真正的政党说来，名称总是不完全符合的；党在发展，名称却不变。"
   → 马克思和他有过一个科学上很确切的党的名称
     可是当时没有一个真正的即群众性的无产阶级政党
     现在（19世纪末）真正的政党是有了，可是它的名称在科学上是不正确的
   → 但这不要紧，"可以过得去"
     只要党在发展，只要党意识到它的名称在科学上不确切
     不让这一点妨碍它朝着正确的方向发展就行
【列宁的推进】
   辩证法家恩格斯到临终时仍然忠于辩证法
   → 但是党的名称问题远不及革命无产阶级对国家的态度问题重要
```

### 逻辑要害
**这一节看起来是岔开的话题，其实作用很明确：**

1. **它示范了"辩证地看待名与实"**——名称不确切不要紧，只要不妨碍正确方向。这和他处理"自由的人民国家"那个口号是同一个逻辑（`1.4` 附：恩格斯从鼓动观点上同意"暂时"替它辩护，但它归根到底不科学）。
2. **它用一句"远不及……重要"把话题拉回主线**，再次点明全书主旨是国家问题。

> 🧠 **你笔记里的批注抓住了要点**：名称不符合是**形式问题、手段问题**，只要不影响实质和目的，就"过得去"。这和恩格斯对"自由的人民国家"的处理是同一条原则：**把形式与实质分开，按阶段判断。**

### 抓手句
> 对真正的政党说来，名称总是不完全符合的；党在发展，名称却不变。

> 但是党的名称问题**远不及**革命无产阶级对国家的态度问题重要。

## 5.1 马克思如何提出问题：过渡时期的国家只能是无产阶级专政

### 论证结构
```
【马克思的原文】（《哥达纲领批判》）
   "在资本主义社会和共产主义社会之间，有一个从前者变为后者的革命转变时期。
    同这个时期相适应的也有一个政治上的过渡时期
    这个时期的国家只能是无产阶级的革命专政。"
【为什么必须专政】
   向前发展，即向共产主义发展，必须经过无产阶级专政，不可能走别的道路
   因为再没有其他人也没有其他道路能够粉碎剥削者资本家的反抗
【专政意味着什么】
   无产阶级专政，即被压迫者先锋队组织成为统治阶级来镇压压迫者
   → 不能仅仅只是扩大民主
   → 除了把民主制度大规模地扩大，使它第一次成为穷人的、人民的
     而不是富人的民主制度之外
   → 无产阶级专政还要对压迫者、剥削者、资本家采取一系列剥夺自由的措施
   → 为了使人类从雇佣奴隶制下面解放出来，我们必须镇压这些人
     必须用强力粉碎他们的反抗
   → 显然，凡是实行镇压和使用暴力的地方，也就没有自由，没有民主
```

### 逻辑要害

**（1）"过渡时期的国家只能是无产阶级的革命专政"——这句是第五章的起点。**
注意它的句式是**"只能"**，不是"最好是"。

**（2）"不能仅仅只是扩大民主"——这句话是防止把专政稀释成民主。**
列宁明确指出专政包含两项内容：
```
① 把民主大规模扩大（穷人、人民第一次享有）
② 对剥削者采取剥夺自由的措施
```
**两者缺一不可。** 只讲第一条的是机会主义，只讲第二条的是无政府主义式粗暴。

**（3）"凡是实行镇压和使用暴力的地方，也就没有自由，没有民主"——这是一句极其坦率的承认。**
列宁不回避专政的代价，而是**把它说清楚**：对谁没有自由？对剥削者。**这种坦率反而增强了说服力。**

### 抓手句
> 同这个时期相适应的也有一个政治上的过渡时期，这个时期的国家只能是**无产阶级的革命专政**。

> 向前发展，即向共产主义发展，**必须经过无产阶级专政，不可能走别的道路**。

> 无产阶级专政……**不能仅仅只是扩大民主**。除了把民主制度大规模地扩���……还要对压迫者、剥削者、资本家采取一系列剥夺自由的措施。

## 5.2 从资本主义到共产主义的过渡：民主的三种形态

### 论证结构（**本章骨架，务必成对记**）
```
【形态一：资本主义社会】
   最顺利的发展条件下，比较完全的民主制度就是民主共和制
   但这种民主始终受到资本主义剥削制度狭窄框子的限制
   → 实质上始终是少数人的即只是有产阶级的、只是富人的民主制度
   → 资本主义社会的自由始终与古希腊共和国的自由即奴隶主的自由大致相同
   → 现代雇佣奴隶被贫困压得喘不过气，结果都"无暇过问民主"、"无暇过问政治"
     大多数居民在通常的平静局势下都被排斥在社会政治生活之外
   【"限制"的清单】
     选举权的"微小"细节（居住年限、妇女被排斥等）
     代表机构的办事手续
     行使集会权的实际障碍（公共建筑物不准"叫花子"使用）
     纯粹资本主义的办报原则……
     → 这些限制看起来微小，但加在一起就把穷人排斥和推出政治生活之外
   【马克思的概括】
     容许被压迫者每隔几年决定一次究竟由压迫阶级中什么人在议会里代表和镇压他们

【形态二：无产阶级专政（过渡时期）】
   人民这个大多数享有民主
   对人民的剥削者、压迫者实行强力镇压，即把他们排斥于民主之外
   → 这就是民主在从资本主义向共产主义过渡时改变了的形态
   【为什么镇压变"容易"了】
     在资本主义下：剥削者少数镇压被剥削者多数
                   → 必须极凶狠极残酷的镇压、造成大量流血
     过渡时期：被剥削者多数镇压剥削者少数
               → 这是一件很容易、很简单和很自然的事情
                 所流的血会比镇压奴隶、农奴和雇佣工人起义流的少得多
                 人类为此付出的代价要小得多
               → 而且在镇压的同时，还把民主扩展到绝大多数居民身上
                 以致对实行镇压的特殊机器的需要就开始消失
               → 人民镇压剥削者只需要很简单的"机器"，几乎可以不要"机器"
                 只需要有简单的武装群众的组织

【形态三：共产主义】
   只有当资本家的反抗已经彻底粉碎、资本家已经消失、阶级已经不存在的时候
   ——即社会各个成员在同社会生产资料的关系上已经没有差别的时候
   → 只有在那个时候，"国家才会消失，才有可能谈自由"
   → 只有在那个时候，真正完全的、真正没有任何例外的民主才有可能，才会实现
   → 也只有在那个时候，民主才开始消亡
   【为什么】人们既然摆脱了资本主义奴隶制……就会逐渐习惯于遵守
             多少世纪以来人们就知道的、千百年来在一切行为守则上反复谈到的
             起码的公共生活规则，而不需要暴力，不需要强制，不需要服从
             不需要所谓国家这种实行强制的特殊机构

【"消亡"这个词为什么选得恰当】
   "国家消亡"这个说法选得非常恰当
   因为它既表明了过程的渐进性，又表明了过程的自发性
   → 只有习惯才能够发生而且一定会发生这样的作用
```

### 逻辑要害（三条，这是全书理论最密的段落）

**（1）"民主愈完全，它愈迅速地成为不需要的东西"——这是全章的悖论式结论。**
```
资本主义：残缺的民主（少数人）
         ↓
过渡时期：多数人的民主 + 镇压少数
         ↓
共产主义：真正完全的民主 → 然后开始消亡
```
**注意这个"然后"**：不是民主被废除，而是**民主完成了自己就退场了**。

**（2）"极少数人享受民主，富人享受民主，——这就是资本主义社会的民主制度"——这是全书对资本主义民主最凝练的概括。**
配合 `1.3` 的"民主共和制是最好的政治外壳"和 `5.2` 的"每隔几年决定一次由谁镇压人民"，构成完整的批判。

**（3）列宁在这一节做了一个重要的量化对比：镇压的"成本"不同。**
```
少数镇压多数 → 需要极凶狠残酷镇压 + 大量流血 + 庞大的机器
多数镇压少数 → 简单、自然、流血少、几乎不需要特殊机器
```
**这个对比把"专政"从恐怖的联想里拉出来**：无产阶级专政之所以"代价小"，恰恰因为它是**多数对少数**。

> **这是本书对"专政"最有力的辩护，也是理解第五章的关键。**

### 抓手句
> **极少数人享受民主，富人享受民主**，——这就是资本主义社会的民主制度。

> 容许被压迫者每隔几年决定一次究竟由压迫阶级中什么人在议会里**代表和镇压他们**！

> **人民这个大多数享有民主，对人民的剥削者、压迫者实行强力镇压**，即把他们排斥于民主之外，——这就是民主在从资本主义向共产主义过渡时改变了的形态。

> 只有共产主义才能提供真正完全的民主，而**民主愈完全，它也就愈迅速地成为不需要的东西，愈迅速地自行消亡**。

> 人民镇压剥削者却只需要有很简单的"机器"，即几乎可以不要"机器"，不要特殊的机构，而只需要有**简单的武装群众的组织**。

> "国家消亡"这个说法选得非常恰当，因为它既表明了**过程的渐进性**，又表明了**过程的自发性**。

## 5.3 共产主义社会的第一阶段：还有资产阶级权利，还有资产阶级国家（但没有资产阶级）

### 论证结构
```
【马克思的设定】
   "我们这里所说的是这样的共产主义社会，它不是在它自身基础上已经发展了的
    恰好相反，是刚刚从资本主义社会中产生出来的
    因此它在各方面，在经济、道德和精神方面都还带着它脱胎出来的那个旧社会的痕迹。"
   → 马克思称之为共产主义社会的"第一"阶段或低级阶段
【这个阶段的经济关系】
   生产资料已经不是个人的私有财产，它们已归全社会所有
   社会的每个成员完成一定份额的社会必要劳动
   就从社会领得一张凭证，证明他完成了多少劳动量
   他根据这张凭证从消费品的社会储存中领取相应数量的产品
   → 扣除了用做社会基金的那部分劳动量
     每个劳动者从社会领回的正好是他给予社会的
   → 马克思先从整个社会劳动中扣除：后备基金、扩大生产的基金、机器"磨损"的补偿
     然后从消费品中还要扣除：管理费用、学校、医院、养老院等等的基金
【拉萨尔的错误】
   拉萨尔把这样的社会说成是"公平的分配"、说成"每人有获得同等劳动产品的平等权利"
   → 马克思对他的错误进行了分析
【马克思的分析——"资产阶级权利"】
   这里确实有"平等的权利"，但这仍然是"资产阶级权利"
   这个"资产阶级权利"同任何权利一样，是以不平等为前提的
   → 任何权利都是把同一标准应用在不同的人身上
     即应用在事实上各不相同、各不同等的人身上
     因而"平等的权利"就是破坏平等，就是不公平
   → 的确，每个人付出与别人同等份额的社会劳动，就能领取同等份额的社会产品
     然而各个人是不同等的：有的强些，有的弱些；
     有的结了婚，有的没有结婚，有的子女多些，有的子女少些，如此等等
   → "因此，在提供的劳动相同、从而由社会消费基金中分得的份额相同的条件下
      某一个人事实上所得到的比另一个人多些，也就比另一个人富些，如此等等。
      要避免所有这些弊病，权利就不应当是平等的，而应当是不平等的。"
【为什么不可避免】
   "但是这些弊病，在经过长久阵痛刚刚从资本主义社会产生出来的共产主义社会第一阶段
    是不可避免的。权利决不能超出社会的经济结构以及由经济结构制约的社会的文化发展。"
【第一阶段的两个原则】
   "不劳动者不得食" —— 已经实现了
   "对等量劳动给予等量产品" —— 也已经实现了
   → 但是，这还不是共产主义
     还没有消除对不同等的人的不等量（事实上是不等量的）劳动
     给予等量产品的"资产阶级权利"
【关键结论——国家为什么还没完全消亡】
   除了"资产阶级权利"以外，没有其他准则
   → 所以就这一点说，还需要有国家在保卫生产资料公有制的同时
     来保卫劳动的平等和产品分配的平等
   → 国家正在消亡，因为资本家已经没有了，阶级已经没有了
     因而也就没有什么阶级可以镇压了
   → 但是，国家还没有完全消亡，因为还要保卫那个确认事实上的不平等的"资产阶级权利"
   → 要使国家完全消亡，必须有完全的共产主义
【那句著名的悖论】
   "可见，在共产主义下，在一定的时期内，不仅会保留资产阶级权利
    甚至还会保留资产阶级国家，——但没有资产阶级！"
【马克思为什么不空想】
   如果不愿陷入空想主义，那就不能认为
   在推翻资本主义之后，人们立即就能学会不要任何权利准则而为社会劳动
   况且资本主义的废除不能立即为这种变更创造经济前提
```

### 逻辑要害（本节是全书最精彩的理论段落之一，五条）

**（1）"任何权利都是以不平等为前提的"——这是马克思分析"平等"的核心洞见。**
```
权利 = 把同一标准应用于不同的人
     = 无视人的实际差异
     = 平等权利本身制造不平等
```
**这个推理是理解"按劳分配为什么还不平等"的关键。**

**（2）"权利决不能超出社会的经济结构以及由经济结构制约的社会的文化发展"——这是历史唯物主义最精练的表述之一。**
它说明：**共产主义第一阶段保留资产阶级权利，不是因为设计得不好，而是因为做不到。** 权利是被经济结构和文化水平限定的。

**（3）"没有资产阶级的资产阶级国家"——这是全书最著名的悖论句。**
它的逻辑是：
```
国家还在 → 因为还需要保卫"按劳分配"这种权利准则（即强制）
但不是资产阶级国家 → 因为资产阶级已经没有了，生产资料已公有
```
**这个悖论的作用是：把"国家消亡"从一次性的革命事件，变成一个长期的经济过程。**

**（4）扣除的顺序要记清楚**（这是马克思《哥达纲领批判》的经典内容）：
```
社会总劳动 → 扣除①后备基金 ②扩大生产基金 ③机器磨损补偿
剩余消费品 → 再扣除④管理费用 ⑤学校医院养老院等基金
然后      → 按劳动凭证分配
```
**这个扣除顺序本身就是论证**：不是"全部劳动所得"，而是"扣除之后"——这是批拉萨尔"不折不扣的劳动所得"的要点。

**（5）注意这一节的推进语法：**
```
国家正在消亡，因为……（阶级没有了）
但是，国家还没有完全消亡，因为……（还要保卫资产阶级权利）
要使国家完全消亡，必须有完全的共产主义
```
**"正在消亡 / 还没有完全消亡 / 完全消亡的条件"**——三句层层推进，是背诵这一节的最佳抓手。

### 抓手句
> 它在各方面，在经济、道德和精神方面都还**带着它脱胎出来的那个旧社会的痕迹**。

> 这里确实有"平等的权利"，但这仍然是"**资产阶级权利**"，这个"资产阶级权利"同任何权利一样，**是以不平等为前提的**。

> **权利决不能超出社会的经济结构以及由经济结构制约的社会的文化发展。**

> 国家**正在消亡**，因为资本家已经没有了，阶级已经没有了，因而也就没有什么阶级可以镇压了。**但是，国家还没有完全消亡**，因为还要保卫那个确认事实上的不平等的"资产阶级权利"。**要使国家完全消亡，必须有完全的共产主义。**

> **在共产主义下，在一定的时期内，不仅会保留资产阶级权利，甚至还会保留资产阶级国家，——但没有资产阶级！**

## 5.4 共产主义社会的高级阶段：各尽所能，按需分配

### 论证结构
```
【马克思的原文】
   "在共产主义社会高级阶段，在迫使个人奴隶般地服从分工的情形已经消失
    从而脑力劳动和体力劳动的对立也随之消失之后；
    在劳动已经不仅仅是谋生的手段，而且本身成了生活的第一需要之后；
    在随着个人的全面发展，生产力也增长起来
    而集体财富的一切源泉都充分涌流之后，
    ——只有在那个时候，才能完全超出资产阶级权利的狭隘眼界
    社会才能在自己的旗帜上写上：'各尽所能，按需分配'!"
【列宁的阐释：国家完全消亡的经济基础】
   "国家完全消亡的经济基础就是共产主义的高度发展
    那时脑力劳动和体力劳动的对立已经消失
    因而现代社会不平等的最重要的根源之一也就消失
    而这个根源光靠把生产资料转为公有财产，光靠剥夺资本家，是决不能立刻消除的"
   → 这种剥夺会使生产力有蓬勃发展的可能
     我们可以绝对有把握地说，剥夺资本家一定会使人类社会的生产力蓬勃发展
   → 但是，生产力将以什么样的速度向前发展
     将以什么样的速度发展到打破分工、消灭脑力劳动和体力劳动的对立
     把劳动变为"生活的第一需要"
     ——这都是我们所不知道而且也不可能知道的
   【因此的方法论结论】
     我们只能谈国家消亡的必然性
     同时着重指出这个过程是长期的
     指出它的长短将取决于共产主义高级阶段的发展速度
     而把消亡的日期或消亡的具体形式问题作为悬案
     因为现在还没有可供解决这些问题的材料
【"资产阶级权利的狭隘眼界"是什么】
   超出这种使人像夏洛克那样冷酷地斤斤计较
   不愿比别人多做半小时工作，不愿比别人少得一点报酬的狭隘眼界
   → 那时，分配产品就无需社会规定每人应当领取的产品数量
     每人将"按需"自由地取用
【驳斥资产阶级的嘲讽】
   资产阶级说这是"纯粹的乌托邦"
   冷嘲热讽地说社会主义者许诺每个人都可以领取任何数量的巧克力糖、汽车、钢琴
   → 说他们愚昧无知，是因为没有一个社会主义者想到过要"许诺"
     共产主义高级发展阶段的到来
     而伟大的社会主义者在预见这个阶段将会到来时所设想的前提
     既不是现在的劳动生产率，也不是现在的庸人
   → 在共产主义的"高级"阶段到来以前
     社会主义者要求社会和国家对劳动量和消费量实行极严格的监督
   → 说他们替资本主义自私辩护，正是因为他们一味争论和空谈遥远的未来
     而不谈目前政治上的迫切问题：剥夺资本家，把全体公民变为一个大"辛迪加"
     并使这整个辛迪加的全部工作完全服从真正民主的国家，即工兵代表苏维埃国家
【科学与空想的分界】
   马克思没有经院式地臆造和"虚构"种种定义
   没有从事毫无意义的字面上的争论（什么是社会主义，什么是共产主义）
   而是分析了可以称为共产主义在经济上成熟程度的两个阶段的东西
【回到"自由与国家"】
   只是现在我们才可以充分地认识到
   恩格斯无情地讥笑那种把"自由"和"国家"这两个名词连在一起的荒谬见解，是多么正确
   → 还有国家的时候就没有自由。到有自由的时候就不会有国家了
```

### 逻辑要害（四条）

**（1）马克思用了三个"在……之后"的排比，然后才说"只有在那个时候"。**
```
① 迫使个人奴隶般地服从分工的情形已经消失 → 脑力劳动和体力劳动对立消失
② 劳动本身成了生活的第一需要
③ 生产力增长起来，集体财富一切源泉充分涌流
   ↓
只有在那个时候 → 才能完全超出资产阶级权利的狭隘眼界 → 各尽所能，按需分配
```
**这三条是"国家完全消亡"的三个条件，背诵时按这个顺序。**

**（2）"把消亡的日期作为悬案"——这是列宁拒绝空想的标志性表态。**
```
能谈的：消亡的必然性（这是科学）
不能谈的：消亡的日期、具体形式（这是空想，因为"还没有可供解决这些问题的材料"）
```
**这一句和 `4.1` 恩格斯"至少在过渡时期难以"、以及第三章"不是空想主义者"是同一条原则。** 全书反复强调这一点，是因为对手最常攻击的正是"你们在画乌托邦"。

**（3）驳斥资产阶级嘲讽的那一整段，是"把问题拉回当下"的典范操作。**
资产阶级说"按需分配是乌托邦" → 列宁答：**我们现在要谈的不是那个，是剥夺资本家。** 你说的那个"根本无法'实施'"——**因为谁也没许诺过要实施它。**
→ **这是"转移话题"的反击**：你用未来的困难来回避现在的任务。

**（4）"民主愈完全，它愈迅速地成为不需要的东西"在这里得到了经济学说明。**
消亡的经济基础 = 共产主义高度发展，而其核心是**"人们习惯于遵守公共生活规则"（习惯）+ 生产力高度发展（物质）**两条。

### 抓手句
> 在劳动已经不仅仅是谋生的手段，而且**本身成了生活的第一需要**之后……只有在那个时候，才能完全超出资产阶级权利的狭隘眼界，社会才能在自己的旗帜上写上：**"各尽所能，按需分配"**！

> **国家完全消亡的经济基础就是共产主义的高度发展**。

> 这个根源**光靠把生产资料转为公有财产，光靠剥夺资本家，是决不能立刻消除的**。

> 我们只能谈国家消亡的**必然性**……而把消亡的日期或消亡的具体形式问题**作为悬案**。

> **还有国家的时候就没有自由。到有自由的时候就不会有国家了。**

## 5.5 计算和监督：从推翻资本家到"习惯于遵守"

### 这一步干什么
**把"消亡"从理论落到可操作的东西上**——这也是本书最接近"施政纲领"的部分。

### 论证结构
```
【资本主义准备好的前提】
   在一些最先进的资本主义国家中已经做到的人人都识字
   其次是千百万工人已经在邮局、铁路、大工厂、大商业企业、银行业等等
   巨大的、复杂的、社会化的机构里"受了训练并养成了遵守纪律的习惯"
【可能做的事】
   在这种经济前提下，完全有可能在推翻了资本家和官吏之后

### 逻辑要害（四条）

```
**这个论证把"人民自己管理"从空想变成了工程问题。**

**（3）"从必须遵守变成习惯于遵守"——这是"消亡"的最终机制，和 `4.6` 完全呼应。**

**（5）本节还有一个关于"形式平等 vs 事实平等"的区分：**

各尽所能，按需分配                     = 事实上的平等

**这是理解"共产主义两个阶段"差别的另一条线索**，和 5.3 的"资产阶级权利"讲的是同一件事的两个角度。

### 抓手句
> **计算和监督**，——这就是把共产主义社会第一阶段"调整好"，使它能正常地运转所必需的主要条件。

> 人们对于人类一切公共生活的简单的基本规则就会很快**从必须遵守变成习惯于遵守**了。

> 民主决不是不可逾越的极限，它只是从封建主义到资本主义和从资本主义到共产主义的**道路上的阶段之一**。

## 6.3 考茨基与潘涅库克的论战：三条区别

### 这一步干什么
**给出全书最系统的"正误对照表"**——马克思主义与无政府主义的三条区别。

### 论证结构（**三条，务必按序号背**）
```
【第(1)条：关于消灭国家的条件】
   马克思主义者：目的是完全消灭国家
                 但他们认为，只有在社会主义革命把阶级消灭之后
                 即导向国家消亡的社会主义建立起来之后，这个目的才能实现
   无政府主义者：希望在一天之内完全消灭国家
                 他们不懂得实现这个消灭的条件

【第(2)条：关于用什么代替、怎样利用】
   马克思主义者：认为无产阶级在夺得政权之后，必须彻底破坏旧的国家机器
                 用武装工人的组织组成的、公社那种类型的新的国家机器来代替它
   无政府主义者：主张破坏国家机器
                 但是，他们完全没有弄清楚无产阶级将用什么来代替它
                 以及无产阶级将怎样利用革命政权
                 他们甚至否定革命无产阶级应利用国家政权
                 否定无产阶级的革命专政

【第(3)条：关于利用现代国家进行准备】
   马克思主义者：主张通过利用现代国家来使无产阶级进行革命的准备
   无政府主义者：否定这一点
```

### 逻辑要害

**（1）这三条是一个完整的"诊断表"，覆盖了国家问题的三个时刻：**
```
(1) 什么时候消灭？ → 条件问题
(2) 消灭之后/同时用什么？ → 替代问题
(3) 消灭之前怎么办？ → 准备问题
```
**三个时刻，马克思主义都有答案，无政府主义都有空缺。** 这种"对照表"式的总结，是全书的收官之作。

**（2）三条里最关键的是第(2)条。**
因为无政府主义者也说"破坏国家机器"——**和马克思主义者说的是同一句话**（列宁在 `3.4` 已经承认过这一点："马克思和蒲鲁东相同的地方，就在于他们两人都主张'打碎'现代国家机器"）。
**区别全在"用什么代替"和"怎样利用"上。**
> **所以列宁在第三章反复强调"公社是终于发现的可以用来代替的政治形式"——那个"代替"二字，正是与无政府主义的分水岭。**

### 抓手句
> (1) 马克思主义者的目的是完全消灭国家，但他们认为，只有在社会主义革命把阶级消灭之后……这个目的才能实现；无政府主义者则希望在一天之内完全消灭国家，他们不懂得实现这个消灭的条件。

> (2) 马克思主义者认为无产阶级在夺得政权之后，必须彻底破坏旧的国家机器，用武装工人的组织组成的、公社那种类型的新的国家机器来代替它；无政府主义者主张破坏国家机器，但是，他们**完全没有弄清楚无产阶级将用什么来代替它**。

> (3) 马克思主义者主张通过利用现代国家来使无产阶级进行革命的准备；无政府主义者则否定这一点。

## 6.4 决裂：帝国主义军事怪物

### 这一步干什么
**全书的最后一句**，把全部论证收回到"现在"。

### 论证结构
```
【最后的现实判断】
   当着国家，当着军事机构由于帝国主义竞赛而强化的国家已经变成军事怪物
   为着解决究竟由英国还是德国、由这个金融资本还是那个金融资本来统治世界的争执
   而去屠杀千百万人的时候
   → 在这样的时候歪曲和避而不谈无产阶级革命对国家的态度问题
     就不能不产生极大的影响
【两种错误的并列批评】
   机会主义者："根本用不着考虑破坏旧的国家机器，我们没有各部和官吏可不行啊！"
              → 他们满身庸人气，实际上不但不相信革命和革命的创造力
                而且还对革命害怕得要死
   无政府主义者："只需要考虑破坏旧的国家机器，用不着探究以往无产阶级革命的具体教训
                 用不着分析应当用什么来代替和怎样代替要破坏的东西。"
              → 所以他们就采取拼命的策略
                 而不是为完成具体的任务以大无畏的精神
                 同时考虑到群众运动的实际条件来进行革命的工作
【马克思的教导】
   马克思教导我们要避免这两种错误
   → 教导我们要以敢于舍身的勇气去破坏全部旧的国家机器
   → 同时又教导我们要具体地提问题
     看，公社就是通过实行上述种种措施来扩大民主制度和根绝官僚制
     得以在数星期内开始建立新的无产阶级的国家机器
   → 我们要学习公社战士的革命勇气
     要把他们的实际措施看做是具有实际迫切意义并立即可行的那些措施的一个轮廓
【最后一句】
   我们却要同机会主义者决裂；整个觉悟的无产阶级将同我们一起进行斗争
   不是去争取"力量对比的变动"
   而是去推翻资产阶级，破坏资产阶级的议会制
   建立公社类型的民主共和国或工兵代表苏维埃共和国，建立无产阶级的革命专政
【补充：社会主义下"原始"民主的复活】
   在社会主义下，"原始"民主的许多东西都必然会复活起来
   因为人民群众在文明社会史上破天荒第一次站起来了
   不仅独立地参加投票和选举，而且独立地参加日常管理
   → 在社会主义下，所有的人将轮流来管理，因此很快就会习惯于不要任何人来管理
```

### 逻辑要害

**（1）结尾的"左右开弓"是全书的结构性收尾。**

| | 不敢打碎 | 只谈打碎 |
|---|---|---|
| **谁** | 机会主义者 | 无政府主义者 |
| **心态** | 害怕革命、不相信革命创造力 | 急躁、不考虑具体条件 |
| **马克思的教导** | 要有敢于舍身的勇气去破坏 | 要具体地提问题、要研究用什么代替 |

**列宁最后给出的正解是"勇气 + 具体"的统一**——这正好呼应了他对马克思的评价（`3.1`）：**既不学究式训诫，也不空想。**

**（2）"所有的人将轮流来管理，因此很快就会习惯于不要任何人来管理"——这句是全书的最后落点。**
它把"国家消亡"这个宏大命题，落到了一个朴素的机制上：**轮流 → 习惯 → 不需要管理**。

**（3）第六章没有"总结全书"，而是以"决裂"收尾。**
**这本身就是写作意图的证明**：这本书不是为学术而写，是为行动而写。它的终点是一句政治决断。

### 抓手句
> 当着国家……已经变成**军事怪物**，为着解决究竟由英国还是德国……来统治世界的争执而去**屠杀千百万人**的时候，在这样的时候歪曲和避而不谈无产阶级革命对国家的态度问题，就不能不产生极大的影响。

> 马克思教导我们要**避免这两种错误**，教导我们要以敢于舍身的勇气去破坏全部旧的国家机器，同时又教导我们要**具体地提问题**。

> 在社会主义下，所有的人将**轮流来管理**，因此很快就会**习惯于不要任何人来管理**。
