## 先读这三行

1. **你那 4 个 docx 是读书笔记，不是全译本。** 覆盖面是第一章 P80–137、第二章第二节到第五节 P159–198。**第二章第一节「方法」——全书方法论心脏——笔记里完全没有**，我已据权威原文补足，全标 `〔补〕`。详见 `_记录/源文本说明·三层文本与批注辑录.md`。
2. **八字钥匙：`值 币 余` · `法 器 争 租 盟`**（前三字第一章，后五字第二章）。八节对八字，一一对应。
3. **全书最大一个结构决定：马克思先破蒲鲁东的"科学"，再破蒲鲁东的"哲学"。** 第一章在蒲鲁东自称科学的地方（经济学）用经济学家的武器打败他；第二章在蒲鲁东自称哲学的地方（黑格尔辩证法）用哲学家的武器打败他。这个顺序不能倒。

## 三条暗线

1. **"历史性"**——分工、机器、竞争、垄断、所有权、地租、同盟，被一个一个地从"永恒范畴"降格为"历史的、暂时的产物"。
2. **"坏的方面引起斗争、产生历史"**——第七个说明立下的命题，一路贯到地租、贯到罢工。
3. **"从范畴到阶级"**——全书从最抽象的"价值"走到最具体的"自为阶级"，最后一句落到政治结论。

## 与另外两套的关系

本套装与桌面 `共产党宣言`、`国家与革命` 两个文件夹是同一规格、同一编号思路。
马克思自己在 1880 年说过：读《哲学的贫困》和《共产党宣言》，"可以作为研究《资本论》……的入门"。
所以建议顺序是：**《哲学的贫困》（1847）→《共产党宣言》（1848）→《国家与革命》（1917）**。
